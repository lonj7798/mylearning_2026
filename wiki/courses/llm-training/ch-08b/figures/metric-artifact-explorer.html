Metric artifact explorer

One model family, one set of per-token probabilities, two scores. Per-token cross-entropy falls as a power law in parameters N, L_CE(N) = (N/c)^α; the probability that one token is correct is p = exp(−L_CE). Exact match on an L-token target scores p^L; token edit distance scores L·(1 − p). The controls change the target length and the test-set size, so the same model outputs can be compared under a thresholded score and a linear score.

Formulas: Schaeffer, Miranda, Koyejo, "Are Emergent Abilities of Large Language Models a Mirage?", arXiv:2304.15004v2 §2 (the paper uses the power-law form for illustration and assumes independent tokens, which it states is not true). Constants c = 108 and α = −0.5 are chosen by this course for arithmetic convenience; they are not fitted to any model. The horizontal axis runs from 107 to 1011 parameters. With L = 5 the markers at 108, 109, 1010, 1011 show accuracy 0.007, 0.206, 0.607, 0.854 and token edit distance 3.16, 1.36, 0.48, 0.16, the values in ch-08b §6.

Resolution: chance that a finite test set scores zero

A model with expected exact-match accuracy a, evaluated on n independent items, scores exactly zero with probability (1 − a)n.

Test-set size n

Uses the target length chosen above. ch-08b §6 worked example: L = 5, n = 100, N = 108 gives expected correct 100 × 0.0067 = 0.67 and P(zero) = (1 − 0.0067)100 = 0.51; with n = 1,000 it is 0.0012. Resolution as a cause of apparent emergence: arXiv:2304.15004v2 §2 and §3 (Fig. 4).
