Formulas. h_paired = 1.96 · sqrt((b + c) / n), where b is the share of tasks the reproduced model solves and the reference does not, c the reverse, and n the number of tasks. h_unpaired = 1.96 · sqrt(2 · p · (1 − p) / n), where p is the accuracy of either model under the null that the two are equal.

Both expressions assume one scored trial per task. Averaging several trials per task lowers the within-task component but not the task-to-task component, so the curves above are an upper bound on what more trials can buy. The chapter's worked example is the default state of this figure: n = 200, b + c = 0.20, p = 0.40, giving 6.2 points paired and 9.6 points unpaired.
