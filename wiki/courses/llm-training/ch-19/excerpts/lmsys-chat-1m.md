# Excerpt: LMSYS-Chat-1M: A Large-Scale Real-World LLM Conversation Dataset

Authors: Lianmin Zheng, Wei-Lin Chiang, Ying Sheng, Tianle Li, Siyuan Zhuang, Zhanghao Wu, et al. (UC Berkeley, UC San Diego, CMU, Stanford, MBZUAI). Checked against the v4 PDF on 2026-09-15. Used by ch-19 `read.md` §11.

## Collection (Abstract, §3)
> "a large-scale dataset containing one million real-world conversations with 25 state-of-the-art LLMs. This dataset is collected from 210K unique IP addresses in the wild on our Vicuna demo and Chatbot Arena website."

Collected April to August 2023 (§3.1). Table 1: 1,000,000 conversations; 25 models; 210,479 users; 154 languages; 2.0 turns per sample; 69.5 tokens per prompt; 214.5 tokens per response (Llama 2 tokenizer). The dataset keeps unsafe conversations and includes OpenAI moderation API output for each message (§3.1).

## Topic distribution (§3.2, Fig. 3)
> "From 100K randomly sampled English conversations, we extract user prompts, which include both the initial and follow-up turns. We remove prompts that are either too short (fewer than 32 characters) or too long (more than 1536 characters). Next, we compute the sentence embeddings of these prompts using the all-mpnet-base-v2 model from SentenceTransformers. We then employ k-means clustering to form 20 clusters."

> "The majority of questions are related to coding and software (Clusters 1, 2, 6, 16, 18) ... Additionally, there is a significant number of unsafe topics (Cluster 9, 15, 17)."

Cluster shares used in ch-19: 1 software errors and solutions 10.43%; 2 AI tools, software design, and programming 7.29%; 6 Python coding assistance 6.14%; 16 SQL queries 3.50%; 18 Python coding examples and outputs 2.28%; 9 explicit and erotic storytelling 5.71%; 15 explicit sexual fantasies and role-playing 3.91%; 17 toxic behavior across identities 2.66%.

Fig. 3 caption: "certain clusters (Cluster 14, Cluster 20) contain numerous similar samples with the same template. These may have been generated by scripts and batch submitted to our website. While this figure represents the distribution of sampled conversations, it might not reflect the real-world topic distributions."

## Unsafe content (§3.3)
"a non-negligible portion (5%) of the conversations have potentially harmful content" by the OpenAI moderation API.

## Instruction tuning use case (§4.3, Table 6)
> "The first, named 'HighQuality,' uses 45K conversations from OpenAI and Anthropic's models. The second, named 'Upvote', selects 39K conversations based on user votes from open models, without any data from proprietary models. We fine-tune Llama2-7B on these two subsets"

| Model | Fine-tuning tokens | MMLU (5-shot) | MT-Bench |
|---|---|---|---|
| Llama2-7B | - | 42.4 | 3.95 |
| Llama2-7B-chat | - | 45.8 | 6.27 |
| Vicuna-7B-v1.5 | 370M | 49.8 | 6.17 |
| HighQuality-7B | 33M | 47.7 | 6.03 |
| Upvote-7B | 19M | 45.0 | 5.86 |

The authors interpret the Upvote result as "the quality of answers from open models is still lacking" (§4.3).
