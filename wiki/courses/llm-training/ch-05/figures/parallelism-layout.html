From a parallelism layout to tokens per optimizer step

Set the four parallel degrees and the batch definition. The page computes the world size, how many sequences each data-parallel group holds per step, and how many gradient-accumulation micro-steps that implies. These are the quantities that reach the learning outcome; per-GPU memory is not modelled here.
