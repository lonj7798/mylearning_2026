Length reward explorer

Set the response limit, the soft-punishment buffer and one group of eight rollouts, then read the reward and the group-normalized advantage each rollout receives under four treatments of length. Default values are the DAPO settings: maximum generation 20,480 tokens = 16,384 expected + 4,096 buffer (arXiv:2503.14476 §4.1).

Left: the correctness-only rule R(ŷ, y) = 1 if equivalent, −1 otherwise (arXiv:2503.14476 Eq. 7); a truncated response has no answer, so it takes the −1 branch. Middle: the same rule plus soft overlong punishment (Eq. 13), which is 0 below L_max − L_cache and falls linearly to −1 at L_max. Right: the cosine reward CosFn(t, T, η_min, η_max) = η_min + 0.5(η_max − η_min)(1 + cos(tπ/T)) with the hyperparameters from arXiv:2502.03373 App. E.5.1 (r0ᶜ = +2, rLᶜ = +1, r0ʷ = −10, rLʷ = 0).

One group of eight rollouts

RolloutLengthAnswer correct Punitive rPunitive A Filtered rFiltered A Soft rSoft A Kimi λ

Advantages are A_i = (r_i − mean(r)) / std(r) over the group, with the population standard deviation (arXiv:2402.03300 GRPO). Punitive keeps truncated rollouts in the group with the wrong-answer reward. Filtered is DAPO's Overlong Filtering: truncated rollouts are removed from the loss, so they have no advantage and the group statistics are computed from the remaining rollouts. Soft adds the Eq. 13 penalty to the correctness reward. Kimi λ is the group-relative length reward λ = 0.5 − (len(i) − min_len)/(max_len − min_len), given as λ for correct responses and min(0, λ) for wrong ones (arXiv:2501.12599 §2.3.3); it is a separate term, not one of the three treatments. A rollout whose length equals L_max is treated as truncated: the "Answer correct" box then marks reasoning that was on track but never produced an answer.
