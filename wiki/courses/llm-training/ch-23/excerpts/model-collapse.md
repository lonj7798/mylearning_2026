# Excerpt: AI models collapse when trained on recursively generated data (Shumailov et al., Nature 2024)

**Paper:** Ilia Shumailov, Zakhar Shumaylov, Yiren Zhao, Nicolas Papernot, Ross Anderson, Yarin Gal. Nature 631, 755–759 (published 2024-07-24); preprint arXiv:2305.17493 (v1 2023-05); Author Correction Nature 640, E6 (2025-03). Source type: paper.

> This file replaces the 2026-04 excerpt, which contained a generation-by-generation perplexity table and a claim that average perplexity falls under collapse. Neither is in the paper.

## Definitions ("What is model collapse?")
- Model collapse: a degenerative process across generations in which data generated by models pollute the training set of the next generation (Definition 2.1).
- Early collapse loses information about the tails; late collapse converges to a distribution with little resemblance to the original, often with much reduced variance.
- Three error sources: statistical approximation error (finite samples; the primary type), functional expressivity error, functional approximation error.

## Theory ("Theoretical intuition"; SI §3.1)
- Data mixture: p_{i+1} = α_i p_{θ_{i+1}} + β_i p_i + γ_i p_0; the mathematical models use β_i = γ_i = 0.
- Discrete distribution with exact fit: with sample size M, a state with probability q ≤ 1/M has fewer than one expected sample per generation, so its information is lost; the chain converges to a delta function with probability 1.
- Gaussian refitting with fixed sample size (Theorem 3.1): E[W_2²(N(μ_n, Σ_n), D_0)] → ∞ and Σ_n → 0 almost surely.
- 1D Gaussian (SI §3.1.1): Var(X_j^n) = σ²(1 + n/M) + O(2).
- Pooling all past data in the 1D Gaussian model: estimate variance falls as the pool grows (SI Fig. 5); drawing a fixed-size sample from the pool: parameters "jump around quite significantly" (SI Fig. 4); the SI calls the changes "inevitable, although attenuated".

## OPT-125m experiment ("Model collapse in language models")
- Fine-tune OPT-125m on wikitext2; generate with five-way beam search; 64-token blocks, the model predicts the next 64 tokens for each block; the generated set has the same size as the original training set; 5 runs per experiment.
- Real-data fine-tune: 34 mean perplexity from a zero-shot baseline of 115.
- Setting 1, five epochs, no original data retained: performance loss "from 20 to 28 perplexity points" (Fig. 1b).
- Setting 2, ten epochs, a random 10% of the original data points sampled at each generation: "only minor degradation" (Fig. 1c).
- Fig. 1 caption: evaluation uses the original wikitext2 test set; mean perplexity increases across generations ("as seen from the increase in perplexity"); per-sequence perplexity of generated data, scored by the generation-0 model, shifts toward more probable sequences while a longer high-perplexity tail appears.
- Repetition penalty 2.0 doubles perplexity relative to the original, and models "remain as susceptible to model collapse, if not more" ("Ablation: Repetitions").
- Example 1: generation 9 output repeats a phrase pattern ("black @-@ tailed jackrabbits, white @-@ tailed jackrabbits, …").
- Not reported: learning rate, batch size, optimizer, total number of LLM generations.

## Discussion
- Low-probability events are often relevant to marginalized groups and to understanding complex systems ("Discussion").
