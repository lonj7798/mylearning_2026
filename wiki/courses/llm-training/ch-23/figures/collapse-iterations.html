A. Discrete resampling: replace, accumulate, and 10% original data

Simulation of the discrete model with exact fit in Shumailov et al. (Nature 2024), "Discrete distributions with exact approximation": each generation fits empirical frequencies and samples M points. The 10% mode mimics the data mix of the paper's OPT-125m setting 2; the paper's LLM experiment is not reproduced here.

replace accumulate 90% synthetic + 10% original, each generation

y-axis: states with non-zero fitted probability (60 = all). A state with probability q ≤ 1/M has fewer than one expected sample per generation; once it gets zero samples under replace, it cannot return.

B. Linear regression: replace vs accumulate test error

Gerstgrasser et al., arXiv:2404.01413v2, Theorem 2 (Eq. 3) and Eq. 4: E_replace = σ²d/(T−d−1)·n; E_accum = σ²d/(T−d−1)·Σ 1/i² ≤ σ²d/(T−d−1)·π²/6.

C. Strong model collapse: error floor from a fixed synthetic share

Dohmatob et al., arXiv:2410.04840v2, Corollary 1, Eq. 12 (isotropic ridge regression, small d/n): E ≈ σ²d/n + p₂²c². Plotted for n ≥ 10d.

p₂ = 0 (real only) p₂ = 0.001 p₂ = 0.01 p₂ = 0.1

In the paper's GPT-2 runs with quality-filtered synthetic stories, synthetic data delayed scaling; a plateau was expected by the authors but not shown (§4.2).

D. Verifier breakdown point and the two reject pools

Feng et al., arXiv:2406.07515v2, Theorem 4.2: p* = 1/(1 + ψ/ϕ), where ϕ = P(keep | correct), ψ = P(keep | wrong), p = generator error rate. Pool counts are arithmetic for N = 1,000 generated answers.

correct answers wrong answers

The theorem is an infinite-data limit for a linear classifier. Correct answers in the reject pool are verifier false negatives: discarding them loses data; using them as negative gradients lowers the likelihood of correct behavior.
