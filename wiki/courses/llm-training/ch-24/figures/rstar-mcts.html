Panel A — Terminal-guided Q-value annotation (rStar-Math, arXiv:2501.04519 §3.2–3.4)

Problem (the paper's Fig. 2 example): Bill walks 1/2 mile south, 3/4 mile east, then 1/2 mile south. Distance from the start, to the nearest hundredth? Reference answer 1.25. Each rollout selects children by UCT(s) = Q(s) + c·sqrt(ln Nparent / N(s)), with Q = q/N and c = 2 (Eq. 1, App. A.1); unvisited children are taken first, in listed order. The leaf answer scores +1 if it equals 1.25 and −1 otherwise, and that score is added to q of every step on the path (Eq. 2). Candidate E raised an execution error, so it never became a node (§3.2). The tree and its answers were written for this figure; they are not from the paper.

Panel B — Monte-Carlo step labels: false negatives, false positives, and cost

A step label is ct = (rollouts from the prefix that reach the reference answer) / k (OmegaPRM Eq. 1); the hard label is 1[ct > 0] (Math-Shepherd §3.3). With independent rollouts: P(label 0 | correct prefix) = (1 − p)k and P(label 1 | wrong prefix) = 1 − (1 − w)k (derived). p and w are inputs, not measured values. OmegaPRM uses k = 8 and 16 pieces per solution (§4, §4.2).

Panel C — Pushing down one token, and which steps receive the negative gradient

One gradient-descent step on log py with step size η changes each logit by −η(1[j = y] − pj), because ∂ log py / ∂ zj = 1[j = y] − pj. The rejected token is y; a and b are alternatives. With (0.80, 0.15, 0.05) and η = 1 the result is (0.902, 0.088, 0.010), the worked example in ch-24.

Whole-answer DPO with an independently sampled chosen answer puts every step of the rejected answer in the rejected term. Step-DPO conditions the chosen and the rejected step on the same correct prefix, so no prefix token appears in either log-ratio, and only the first wrong step is in the rejected term (arXiv:2406.18629 §3.1, Eq. 2).
