# Excerpt: Llama 3 — the six-round post-training loop

**Source library:** `wiki/raw-data/llm-training/model-reports/llama-3.md`
**Artifact:** Six iterative rounds of SFT → Rejection Sampling → DPO with per-round RM retrain

---

## Why this source anchors ch-33

Llama 3's topology contrast with Tülu 3 is the chapter's central pedagogical move. A linear pipeline and a closed loop are two ways to solve the same problem; neither is strictly better. This excerpt locks in what the *loop* actually is — what each round does, what carries over, and what is deliberately discarded — so §3 has an unambiguous source.

---

## The attested six-round structure

From the source (line 35):

> Six rounds of: (a) Reward Model (RM) training, (b) Rejection Sampling to build the round's SFT pool, (c) SFT on curated pool, (d) DPO on preference data collected with the latest RM-ranked generations. Each round uses a fresh batch of ~human preference annotations plus synthetic data resampled from the round-N-1 best model.

So each round has four inner steps, executed in order. The round-*N+1* RM is trained on fresh preference annotations (not the RM from round *N* re-used); the round-*N+1* SFT pool is regenerated by rejection-sampling from the round-*N* best chat model; the round-*N+1* DPO pairs come from the latest RM-ranked generations. Six iterations of this yields the released instruct model.

---

## Rejection sampling — the loop's SFT data generator

From the source (lines 38–41):

> Data sources: rejection-sampled outputs from prior round (dominant), human-annotated prompts, filtered synthetic data for code/math/reasoning/multilingual/long-context/tool use.
> Rejection sampling: for each prompt, sample K=10–30 completions from the best round-(N-1) chat model at temperature T=0.6–1.0, then keep the top by RM score.
> Filtering: topic classifier + quality classifier (both distilled from Llama 3) remove low-quality rejection-sampled text before SFT.
> Training: LR 1e-5 (405B), cosine decay, context 8K-32K (extended), loss on response tokens only.

The *dominance* of rejection-sampled data is the key point: each round's SFT pool is mostly outputs from the prior round's best chat checkpoint, filtered by the fresh RM. Human demonstrations are present but are not the dominant source after round 1.

---

## DPO with NLL-on-chosen stabilizer

From the source (lines 49–53):

> Learning rate: 1e-5
> Beta (KL coefficient): 0.1
> Auxiliary NLL loss on chosen sequences: coefficient 0.2 — added to stabilize training by preventing chosen-logprob decay.
> Single epoch per round; masks prompts from loss.
> Most-recent-batch preference data only (older batches cause format drift).

Two loadbearing constraints here: **NLL coefficient 0.2 prevents chosen-logprob decay** (a documented failure mode in vanilla DPO where the chosen-logprob can drop in absolute terms while the preference margin still increases); **most-recent-batch preference data only** guards against format drift.

---

## Per-round data mix

From the source (lines 55–57):

> ~50–80% synthetic rejection-sampled data
> Remainder: human SFT demonstrations, preference data, capability-specific synthetic (code-exec-filtered code, math with verifier, multi-turn tool use traces, long-context QA).

The 50–80% range is the attested band for the synthetic share. Ch-33's six-round table and the HTML figure both treat this as a ramp: early rounds near 50%, later rounds near 80%. The monotone ramp itself is inferred from the prose; the specific 35/50/62/70/75/80 numbers in the HTML figure are reconstruction, not published.

## What ch-33 does and does not claim

**Attested and used in §3:**
- The four-step round structure (RM → RS → SFT → DPO).
- K=10–30 rejection samples, T=0.6–1.0.
- DPO LR 1e-5, β=0.1, NLL coefficient 0.2, most-recent-batch-only.
- 50–80% synthetic per round.
- Fresh RM each round; stale preferences never reused.

**Inferred (labelled in §3.2 and the HTML figure):**
- Which specific eval regression each round targeted (Meta does not publish round-by-round eval deltas).
- The monotone synthetic ramp values.
