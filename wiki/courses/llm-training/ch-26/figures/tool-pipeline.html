APIGen 3-Layer Verifier — Interactive Walkthrough

APIGen (Salesforce, 2024) accepts a synthetic function-calling sample iff it clears three independent checks, in sequence. Each stage rejects a different failure mode; removing any one costs a measurable fraction of BFCL-V1 score.

Why each layer earns its keep — BFCL-V1 ablation

Full 3-layer (format + execution + semantic) : 88.24  ←  baseline
Remove semantic check                        : 82.24  (−6.0)
Remove execution check                       : 77.34  (−10.9)
Remove format check                          : 70.14  (−18.1)  ← Glaive-era ceiling

Format alone lands at the 2023 Glaive-style open-FC ceiling (~70%). Execution adds the biggest single-layer lift (+11). Semantic catches the residual 6% — calls that run without error but answer the wrong question (wrong unit, wrong target, right function with wrong arg semantics). Only an LLM judge or a human catches these.
