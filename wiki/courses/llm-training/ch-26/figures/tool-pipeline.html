B. pass^k and pass@k from repeated trials

For each task, run n trials and count c successes. τ-bench defines pass^k = mean over tasks of C(c,k)/C(n,k) (all k sampled trials succeed) and pass@k = 1 − mean of C(n−c,k)/C(n,k) (at least one succeeds).

Default input reproduces the chapter's worked example (n = 4; tasks with 3 and 4 successes). Source for the definitions: τ-bench, arXiv:2406.12045 v1, §3. Published reference point: gpt-4o function calling on τ-retail has pass^1 above 60% and pass^8 below 25% (Fig. 4).

C. ToolRL reward for one predicted call

One ground-truth call with K arguments; one predicted call with the same K argument keys proposed. Adjust what matches.


  
Formula: ToolRL, arXiv:2504.13958 v1, §3.3. r_param for one call is the Jaccard overlap of key sets; with K keys proposed and m matched it is m/(2K − m). If the name is wrong the call is not matched to the ground truth in this simplified panel, so r_param and r_value are set to 0 (the paper computes the best matching over all calls). Default input is the chapter's worked example.







  
D. Function masking as in Hammer
