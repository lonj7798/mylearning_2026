# Chapter 12a — 사전학습 중 암기, 지식 습득, 일반화

> **핵심 통찰.** 모델은 학습 문장을 한 단어도 틀리지 않고 재현할 수 있지만, 그 안의 사실에 관한 질문에는 답하지 못할 수 있다. 합성 전기를 사용한 통제 실험에서, 사람마다 하나의 고정 전기만으로 학습한 124M GPT2는 QA 미세 조정 후 홀드아웃 질문에 9.7% 정확도로 답했으며, 각 사람에게 서로 다르게 표현하고 순서를 섞은 전기를 다섯 개씩 주었을 때는 96.6%를 기록했다([[physics-of-lm-3-1-knowledge-storage]] 그림 3). 한 방향으로 학습한 사실은 반대 방향으로 검색되지 않으며([[reversal-curse]], [[physics-of-lm-3-2-knowledge-manipulation]]), BLOOM-176B는 관련 사전학습 문서가 약 10개인 TriviaQA 질문에는 25%, 10^4개일 때는 55% 이상을 답한다([[long-tail-knowledge]] §3.1). 데이터의 0.1%를 100번 반복하면 800M 모델의 성능이 400M 모델 수준으로 저하되었다([[repeated-data-scaling]] 초록).
>
> **지침.** 중요한 사실이 적은 형식으로만 나타난다면 같은 문자열을 반복하는 대신 다시 작성한 버전(다른 표현, 문장 순서, 방향)을 사전학습 데이터에 더하라. 다시 작성은 [[physics-of-lm-3-1-knowledge-storage]]에서 홀드아웃 추출을 9.7%에서 96.6%로 올렸고, OLMo-7B에서는 바꾸어 쓴 주입이 중복 주입보다 더 천천히 잊혔기 때문이다([[factual-knowledge-acquisition-pretraining]] 표 2). 고품질 부분집합의 가중치를 올릴 때는, 100B 학습 토큰에서 [[repeated-data-scaling]]이 적합한 저하 구간 E = k·N^α 밖으로 반복 횟수를 유지하고 복사 평가를 모니터링하라. 최악의 반복 횟수에서 3% 반복 데이터는 복사에서 유효 모델 크기를 3배 줄였고 시험 손실에서는 최대 1.15배만 줄였기 때문이다. 그렇지 않고 반복을 피할 수 없다면, 전체 데이터셋을 약 4 에포크까지 균등하게 반복하라([[data-constrained-scaling]]). 홀드아웃 엔터티, 바꾸어 표현한 질문과 반대 방향 질문, 그리고 코퍼스에서 사실이 나타나는 빈도로 층화한 정확도로 지식을 평가하라.

## 범용 모델에서 이 장이 중요한 이유

범용 모델은 학습 텍스트에 없었던 표현, 방향, 조합으로 사실에 관한 질문에 답해야 한다. 측정 가능한 문제는 두 양 사이의 간극이다. 모델이 학습 데이터를 얼마나 재현할 수 있는지, 그리고 그 데이터의 지식을 새 프롬프트 아래 얼마나 사용할 수 있는지이다. 이 간극은 사전학습에서 결정된다. [[physics-of-lm-3-1-knowledge-storage]]는 사전학습이 추출할 수 없는 형식으로 사실을 저장했을 때, 자신들이 시험한 어떤 QA 미세 조정 설정도 이를 회복하지 못했다고 보고한다(결과 2). 그러므로 이후 단계(SFT, 선호 최적화, RL)는 사전학습 데이터 설계가 만든 것을 물려받는다.

이 장은 중복 제거(ch-12)와 도메인 혼합(ch-13) 사이에 있다. 중복 제거는 문자열의 반복 횟수를 정하고, 혼합은 도메인의 등장 횟수를 정한다. 둘 다 노출 결정이며, 이 장은 노출 횟수와 노출 형식이 암기, 추출, 망각에 미치는 효과를 보여 주는 근거를 제시한다. 강의 목표를 위해 다음 세 질문에 답한다.

1. 범위: 어떤 데이터 형식이 저장한 사실을 보지 못한 질문에 사용할 수 있게 하는가(§5, §6, §9).
2. 좁아짐: 어떤 데이터 패턴이 모델을 복사와 인컨텍스트 학습 같은 일반 행동을 희생해 암기된 문자열 쪽으로 이동시키는가(§2, §9).
3. 측정: 암기와 일반화를 어떻게 구별하며, 어떤 측정이 각각을 과소·과대 계수하는가(§1, §2, §3, §8).

## §1 서로 다른 세 양: 축어 암기, 저장 정보, 추출 가능한 지식

**정의.** 이 장에는 네 가지 측정이 나온다. 서로 다른 것을 재므로 하나의 숫자인 것처럼 비교해서는 안 된다.

1. **추출 가능한 암기** ([[quantifying-memorization]] 정의 3.1). 학습 데이터에 [p || s]가 있는 길이 k 접두사 p 중 어떤 것이 탐욕 디코딩에서 모델이 s를 생성하게 하면, 문자열 s는 문맥 토큰 k개로 추출 가능하다. 예: 학습 텍스트에 “My phone number is 555-6789”가 있고, 4단어 접두사 “My phone number is”가 “555-6789”를 산출한다.
2. **정확 암기** ([[memorization-without-overfitting]] 정의 1). argmax f(s) = y이면 학습 문맥 (s, y)를 암기했다고 한다. 학습 문맥 전체에서의 비율은 M(f)이다.
3. **의도하지 않은 암기** ([[how-much-do-lms-memorize]] §2). 데이터 분포의 참조 모델이 이미 예측하는 양을 넘어, 모델이 특정 학습 샘플에 관해 보유한 정보이다.
4. **지식 추출** ([[physics-of-lm-3-1-knowledge-storage]] §1). 모델이 해당 엔터티에 대한 텍스트로 학습한 뒤, 질문은 한 번도 학습에 나타나지 않은 엔터티에 관한 질문에서의 정확도이다.

**문제.** (1)이나 (2)가 높다고 해서 (4)가 높다는 뜻은 아니다. 문자열이 저장되었기 때문이 아니라 예측 가능하기 때문에 모델이 학습 문자열을 낼 수도 있다. Pile로 학습하지 않은 GPT-2는 Pile 평가 집합의 약 6%를 올바르게 완성하고, Pile로 학습한 GPT-Neo 1.3B는 40%를 올바르게 완성한다([[quantifying-memorization]] §4.1).

**수식(정확 암기).**

M(f) = (1/|C|) · Σ_{(s,y)∈C} 1{argmax f(s) = y}

- C: 학습 문맥 집합; s: 입력 접두사; y: 정답 다음 토큰; f(s): 모델의 로짓; 1{·}: 조건이 성립하면 1, 아니면 0.

계산 예시: 학습 문맥 5개 중 argmax 토큰이 정답과 일치하는 것이 3개라면 M(f) = 3/5 = 0.6이다.

**수식(우도로 추정한 의도하지 않은 암기).** [[how-much-do-lms-memorize]]은 mem_U(x, θ, θ̂) = H^K(x | θ) − H^K(x | θ, θ̂)로 정의하고, 다음처럼 추정한다.

mem_U(x) ≈ −log2 p(x | θ) − ( −log2 max{ p(x | θ̂), p(x | θ) } )

- x: 하나의 학습 샘플; θ: 데이터 분포를 근사하는 참조 모델; θ̂: 학습한 모델; H^K: Kolmogorov 복잡도(가장 짧은 기술 길이). 산술 부호화 아래 코드 길이로 근사하며, 이는 음의 로그우도와 같다(§2.3).

계산 예시: 참조 모델이 p(x | θ) = 2^−40을 할당하면 x의 비용은 40비트이다. 학습한 모델이 2^−10을 할당하면 mem_U = 40 − 10 = 30비트로, 학습한 모델은 분포가 설명하지 못하는 x의 정보 30비트를 보유한다. 학습한 모델이 2^−50을 할당하면 max가 참조 모델을 선택하므로 mem_U = 40 − 40 = 0비트이다.

**함의.** 암기 감사, 용량 추정, 지식 평가는 서로 다른 질문에 답한다. 이 장의 나머지 부분은 각 결과가 어느 양을 측정하는지 밝힌다.

## §2 축어 암기가 모델 크기, 중복, 문맥 길이에 따라 확장되는 방식

**문제.** 중복 제거 결정(ch-12)에는 중복이 암기를 얼마나 높이는지, 더 큰 모델이 이를 더 악화하는지 알아야 한다.

**측정의 작동 방식** ([[quantifying-memorization]] §3.2):
1. 길이 ℓ ∈ {50, 100, ..., 500}인 학습 시퀀스를 표본으로 뽑고, 중복 분석을 위해 2^(n/4)와 2^((n+1)/4) 사이의 중복 횟수 버킷마다 시퀀스 1,000개를 뽑는다.
2. 모델에 처음 ℓ − 50개 토큰을 프롬프트로 준다.
3. 탐욕 디코딩하고, 다음 50개 토큰이 정확히 일치하면 시퀀스를 추출 가능으로 표시한다.
4. 길이 전반에서 추출 가능한 비율을 평균 내고, 각 모델 크기에 대해 반복한다.

**수식.** 논문은 로그 선형 적합을 보고한다. 중복 수를 정규화한 표본에서 모델 크기에 대해서는 다음과 같다.

frac(N) ≈ c + β · log10 N, with β = 0.19 (매개변수가 10배 늘 때마다 19퍼센트포인트, R² = 99.8%; §4.1)

- frac: 표본 시퀀스 중 추출 가능한 비율; N: 매개변수 수; c: 절편(본문에 보고되지 않음).

계산 예시(도출): GPT-Neo 125M에서 6B까지 log10(6×10^9 / 1.25×10^8) = log10(48) = 1.68이고, 1.68 × 19 ≈ 32퍼센트포인트만큼 이 표본에서 추출 가능한 시퀀스가 더 많다.

**증거.**
- 모델 크기: Pile에서 GPT-Neo 125M–6B의 로그 선형 증가를 보이며, T5와 OPT도 같은 방향을 보인다([[quantifying-memorization]] §4.1, §5.1, §5.3). 더 큰 모델은 더 적은 패스에서 암기 임계값에도 도달한다([[memorization-without-overfitting]] §4). **복제됨.**
- 중복: 2회에서 900회 중복까지 로그 선형 증가하며, 중복 횟수가 적은 시퀀스에서도 암기가 발생한다([[quantifying-memorization]] §4.2).
- 문맥: 6B 모델에서 표본 시퀀스의 33%는 문맥 50개 토큰으로 추출 가능하고, 문맥 450개 토큰에서는 65%이다(§4.3). 저자들은 이를 발견 가능성(discoverability)이라고 부른다.
- 균등 표본: GPT-J 6B는 GPT-2 XL에는 없는 Pile의 최소 1%를 추출할 수 있다(§4.4).
- 중복 제거 학습: C4로 학습한 1.5B 모델에서, 정확 부분문자열 중복 제거 뒤 원래 35회 미만 반복된 시퀀스는 1.2%가 암기되었고, 제거하지 않았을 때는 3.6%였다. 원래 C4에서 최소 408회 반복된 시퀀스에는 이점이 없었다(§5.2). [[deduplicating-training-data]]는 프롬프트를 주지 않은 측면을 보고한다. 원래 C4 모델은 생성 토큰의 1.926%가 복사한 50토큰 시퀀스에 속한 반면, 정확 부분문자열 중복 제거 뒤에는 0.138%였다(표 4).

**조건과 한계.** 탐욕 디코딩과 정확 일치는 하한을 준다. 빔 100개를 사용한 빔 검색은 평균적으로 2퍼센트포인트 미만(최대 5.6)을 더하고, 100회 반복에서 출력의 32.6%는 학습 집합 어딘가에 나타나는 반면 15.8%는 실제 연속과 일치한다([[quantifying-memorization]] §4.4). 마스크드 언어 모델은 약 한 자릿수만큼 더 적게 암기한다(T5-XL은 100회 반복에서 3.5%, GPT-Neo 2.7B는 53.6%, §5.1). OPT-66B는 GPT-Neo 125M보다 Pile의 더 작은 비율을 암기하며, 저자들은 원인으로 데이터 큐레이션과 분포 이동을 분리할 수 없다(§5.3).

**범용 모델에 대한 함의.** 저자들은 학습 데이터가 중복으로 치우칠 때 더 큰 모델이 “의도하지 않은 데이터셋 특이성”을 학습할 가능성이 높다고 결론 내린다(§6). 이 강의는 이를 모델 크기가 커질수록 중복 제거가 더 엄격해져야 하는 이유로 읽는다(**해석**). 추출은 접두사 길이에 좌우되므로, 저자들은 감사에 학습 데이터로 프롬프트를 주어야 한다고 말한다(§4.3).

## §3 용량: 매개변수당 비트와 데이터가 이를 초과할 때 일어나는 일

**정의.** 용량은 학습한 모델이 데이터셋 크기 전반에서 도달하는 최대 의도하지 않은 암기이다([[how-much-do-lms-memorize]] 정의 5).

**문제.** 모델이 암기하는지 일반화하는지는 데이터의 정보가 모델 매개변수에 들어맞는지에 달려 있다.

**작동 방식** ([[how-much-do-lms-memorize]] §3.2):
1. 일반화가 불가능하고 정보량을 정확히 아는 균등 무작위 토큰 시퀀스 데이터셋을 만든다.
2. 데이터셋 크기를 늘려 가며 GPT-2 구조 모델(매개변수 100K–20M, 10^6단계, 배치 2,048)을 포화할 때까지 학습한다.
3. 암기한 비트를 측정한다. 데이터셋 크기 전반의 평탄 구간이 용량이다.

**수식.** H(dataset) = N_seq · S · log2 V, 그리고 α = capacity / parameters이다.

- N_seq: 시퀀스 수; S: 시퀀스당 토큰 수(64); V: 어휘 크기(2,048); α: 매개변수당 비트.

계산 예시(표 1에서 도출): 각 시퀀스는 64 × log2 2048 = 64 × 11 = 704비트를 담는다. 8층, d_model 256 모델은 매개변수 6.86 × 10^6개이고 측정한 용량은 2.51 × 10^7비트(α = 3.65)이다. 이 모델은 약 2.51 × 10^7 / 704 ≈ 35,650개의 무작위 시퀀스를 저장할 수 있다.

**증거.**
- GPT 스타일 모델은 매개변수당 약 3.6비트를 저장한다(초록). 표 1의 평균은 bfloat16에서 3.51, float32에서 3.83이므로, 정밀도를 두 배로 하면 용량이 약 9% 더해진다([[how-much-do-lms-memorize]] §3.2).
- 중복을 제거한 FineWeb 텍스트에서, 이중 하강(데이터가 늘면서 시험 손실이 올랐다가 다시 내려감)은 데이터셋 정보가 용량을 초과할 때 시작한다. 충분한 데이터에서는 학습 시퀀스의 추출률이 시험 시퀀스의 추출률로 수렴한다. 즉 “성공한 모든 학습 데이터 추출은 일반화에 기인한다”(§4, 그림 3, 그림 8). **결과(단일 연구).**
- 사실에 대해서 [[physics-of-lm-3]]은 합성 전기에서 사실당 1,000회 노출 시 매개변수당 지식 2비트, 100회 노출 시 약 1비트라는 하한을 측정한다. 이는 최대 0.5B의 GPT2 모델에서 얻은 결과이다(결과 1, 4). 두 추정은 서로 다른 양(원시 무작위 비트 대 추출 가능한 지식 비트)을 재므로 서로 모순되지 않는다(**해석**).
- 멤버십 추론(샘플이 학습에 들어갔는지 판별)은 용량과 데이터셋 크기에 따라 시그모이드를 따른다. 적합한 법칙은 매개변수당 10^2개 이상의 토큰으로 학습한 모델에서 우연과 같은 F1 0.5를 암시한다([[how-much-do-lms-memorize]] §5.2.2, 표 2).

**조건과 한계.** 검증 실행의 모델은 최대 1.5B이며, 64-토큰 시퀀스와 완벽하게 중복 제거한 데이터를 사용한다. 중복이 있는 자연 코퍼스는 다루지 않는다.

**함의.** 중복을 제거한 코퍼스의 정보가 용량을 초과하면 모델은 대부분의 샘플을 개별적으로 저장할 수 없고, 저자들은 샘플 사이에서 정보를 공유하는 일이 일반화를 만든다고 제안한다(§4, **해석**). §2가 더 자주 추출된다고 보인 중복 시퀀스는 정보는 한 번만 계산되지만 여러 번 보이므로 이 체제 밖에 있다(**해석**, 이 강의).

## §4 학습 동역학: 과적합 전의 암기와 노출 뒤의 망각

**문제.** 사실은 학습 중 이산적인 지점에서 보인다. 남는 양은 각 노출이 얼마나 더하는지와 그 이득이 얼마나 빨리 감쇠하는지에 달려 있다.

**과적합 없는 암기.** [[memorization-without-overfitting]]은 N개 매개변수를 가진 모델이 M(f) ≥ τ에 필요한 패스 수 T(N, τ)를 정의한다.
- 더 큰 모델은 더 빨리 암기한다. WikiText-103의 인과 언어 모델에서 T(N, 0.9)는 N과 함께 단조롭게 감소하며, 고정 학습률에서도 이 효과는 유지된다(§4, §4.2, 그림 1, 그림 5).
- 더 큰 모델은 검증 퍼플렉서티가 오르기 시작하기 전에 더 큰 학습 데이터 비율을 암기한다(§4.2, 그림 4). 저자들은 과적합만으로는 이 암기 동역학을 설명하지 못한다고 결론 낸다.
- 한 번 본 홀드아웃 배치는 처음에는 빠르게 잊히고, 암기는 이어 망각 기준선이라는 바닥에 접근한다. 이 기준선은 모델 크기에 따라 높아진다(§5, 그림 8). 반복 주입은 기준선을 올리고(차이는 10^-2 차수), 간격 반복은 10^-3 차수만큼 바꾼다(그림 10, 125M).

**미시 습득과 망각.** [[factual-knowledge-acquisition-pretraining]]은 OLMo 사전학습을 재개하고 매 100단계마다 가공 사실을 주입한다.

1. 각 노출은 프로브 답의 로그확률을 올리고, 이득은 이어 감쇠한다(§4.1, 그림 2). AdamW 모멘텀이 한 배치의 업데이트를 여러 단계에 걸쳐 퍼뜨리므로(§3), 이득은 50단계 창 안의 최대값에서 읽는다.
2. 프로브는 암기(같은 문장), 의미 일반화(패러프레이즈), 구성적 일반화(문장을 결합한 사실)를 시험한다.
3. 노출당 즉시 이득인 효과성(effectivity)은 177B, 500B, 1.5T 토큰으로 학습한 체크포인트에서 개선되지 않았고, 1B에서 7B로 갈 때 개선되었다(§4.2, 그림 3).
4. 추가 t단계 뒤 남은 이득의 비율인 유지 가능성 R은 log t에 대해 선형으로 하락한다(§4.3).

**수식**(정의 3, 식 4):

R(q, t) = [ℓ(q; θ_{t_LAM+t}) − ℓ(q; θ_{t_pre})] / [ℓ(q; θ_{t_LAM}) − ℓ(q; θ_{t_pre})],  ΔR ≈ −a · log(t2 / t1)

- ℓ(q; θ): 매개변수 θ에서 프로브 q의 표적 구간에 대한 로그확률; t_pre: 첫 노출 전 마지막 단계; t_LAM: 마지막 노출 뒤 국소 최대값의 단계; a: 감쇠 상수(클수록 더 빠른 망각).

계산 예시. 토큰 단위의 적합선은 R(T) = a · (x0 − log10 T)이며, a는 표 2에서, x 절편 x0는 표 6에서 가져온다(log(tokens)로 보고됨. 밑이 10인 해석은 그림 5의 토큰 축과 맞으며, 도출함). 배치 2,048 시퀀스, 500B-토큰 체크포인트의 암기 프로브에서:
- 중복: a = 0.25, x0 = 11.02. 10^10 토큰 뒤 R = 0.25 × (11.02 − 10) = 0.255.
- 패러프레이즈: a = 0.21, x0 = 11.37. 10^10 토큰 뒤 R = 0.21 × (11.37 − 10) = 0.288.
- 배치 128 시퀀스, 중복: a = 0.31, x0 = 9.45(표 10–11). 10^10 토큰 뒤 0.31 × (9.45 − 10) < 0이므로 R = 0.

**증거.** 중복 주입은 더 큰 즉시 이득을 주지만 더 빨리 잊히며, 2,000단계 뒤에는 패러프레이즈 주입과 비슷한 수준으로 끝난다(§4.1). 표 2의 9개 단계·깊이 셀 중 7개에서 패러프레이즈의 감쇠 상수가 중복보다 낮다. 배치가 2,048이 아닌 128이면 x 절편은 “수십 배” 하락한다(표 6과 11: 500B에서 중복 암기의 11.02 대 9.45, 약 37배, 도출). **결과(단일 연구)**이며, 한 모델군과 가공 사실을 대상으로 했다.

**조건과 한계.** 프로브는 생성한 답이 아니라 로그확률로 채점한다(부록 A). 배치 크기와 학습률은 각각 두 값으로만 비교했다. 저자들은 학습 가능성 임계값이 x 절편과 다를 수 있다고 명시한다(각주 7).

[figures/knowledge-acquisition-explorer.html](figures/knowledge-acquisition-explorer.html) 그림(패널 B)은 모든 체크포인트, 프로브 유형, 배치 크기에 대해 이 적합선을 그리며, 독자가 마지막 노출 뒤 선택한 토큰 수에서 R을 읽을 수 있게 한다.

**함의.** 이 습득 모형에서 사실은 각 노출의 이득이 다음 노출 전 사라지지 않을 때만 학습된다(**해석**, [[factual-knowledge-acquisition-pretraining]] §4.4). 이 설정에서는 더 큰 배치와 패러프레이즈 노출이 보존 기간을 늘렸다.

## §5 저장 대 추출: 다시 표현이 중요한 이유

**정의.** 노출은 학습에서 사실이 한 번 등장하는 것이다. 지식 증강은 같은 사실을 여러 형식으로 다시 쓰는 일이다. multiM(사람당 서로 다르게 표현한 전기 M개), permute(섞은 문장 순서), fullname(대명사를 전체 이름으로 대체)이 있다([[physics-of-lm-3-1-knowledge-storage]] §4.2).

**문제.** 웹 텍스트는 대중적 사실을 많은 형식으로, 희귀 사실을 적은 형식으로 진술한다. 개수뿐 아니라 형식이 추출 가능성을 결정하는지가 질문이다.

**실험의 작동 방식** ([[physics-of-lm-3-1-knowledge-storage]] §2, 부록 C–D):
1. 여섯 속성(생년월일, 출생 도시, 대학교, 전공, 회사, 회사 도시)을 가진 합성 인물 N = 100,000명의 전기를 생성한다.
2. 전기로 GPT2(124M, rotary embedding)를 처음부터 사전학습한다. 80,000단계, 배치 96, 512-토큰 창을 사용한다.
3. 인물 절반(P_train)의 QA 쌍으로 미세 조정한다.
4. 질문을 한 번도 학습하지 않은 나머지 절반(P_test)에서 정확 일치 QA 정확도를 측정한다.
5. 선형 분류기로 은닉 상태를 프로브하여 각 속성이 어디에 저장되는지 찾는다.

**증거**(P_test에서 여섯 속성의 평균 정확도, bioS 데이터, 그림 3; 다수 추측 기준선은 2.7%). bioS는 템플릿으로 생성한 전기 집합이고, bioR은 Llama가 작성한 전기 집합이다(§2).

| 사전학습 데이터 | BIO 사전학습 후 QA 미세 조정 | 혼합 학습(BIO + QA) |
|---|---|---|
| single(전기 하나, 고정 순서) | 9.7 | 86.6 |
| single + fullname | 48.9 | 85.9 |
| single + permute1 | 4.4 | 82.5 |
| single + permute5 | 70.0 | 93.7 |
| multi5 | 41.0 | 91.8 |
| multi5 + permute | 96.6 | 95.5 |

[figures/knowledge-acquisition-explorer.html](figures/knowledge-acquisition-explorer.html) 그림(패널 A)은 두 학습 절차 모두에 대해 그림 3의 증강 17행 중 9행(위의 여섯 행과 multi2, multi5 + fullname, multi5 + permute + fullname)을 호버 값 및 표 보기와 함께 그린다.

계산 예시(도출): P_test에는 인물 50,000명 × 질문 6개 = 질문 300,000개가 있다. 9.7%에서는 약 29,100개를 답하고, 96.6%에서는 약 289,800개를 답한다.

- 결과 2: 사람당 전기 하나일 때, 속성 토큰의 다음 토큰 정확도는 99%를 넘지만, 시험한 모든 미세 조정 설정에서 홀드아웃 QA 정확도는 0에 가깝다. 여기에는 사람당 1,350회 노출인 682M 모델도 포함된다(§4.1, 그림 2). 그림 3의 9.7% 평균은 주로 첫 번째 속성인 생년월일의 33.5%에서 온다.
- 결과 4: bioS single에서 프로브는 회사명 바로 앞 토큰까지 약 2%로 회사명을 예측하며, 그 지점에서 정확도는 100%에 도달한다. multi5 + permute에서는 이름 바로 다음 위치에서 여섯 속성을 모두 거의 100%로 예측할 수 있다(§5.1, 그림 5). 저자들의 설명은 증강이 없으면 모델이 속성을 이름의 성질이 아니라 앞 문장의 연속으로 저장한다는 것이다(**해석**).
- 결과 6: “소수(minority)” 인물 데이터를 바꾸거나 소수 QA를 쓰지 않고, 증강한 “유명인(celebrity)” 인물 100,000명을 더하면 증강하지 않은 소수 인물의 정확도가 4.4%에서 86.8%(bioS)로, 10.0%에서 76.3%(Llama가 작성한 bioR)로 올랐다(§6, 그림 8). 유명인 데이터를 WikiBook 텍스트로 바꾸면 도움이 되지 않았다(비고 6.1).
- 결과 1: 혼합 학습(BIO 대 QA 토큰 비율 2:8로 사전학습 내부에 QA 데이터를 넣음)은 bioS single에서도 86.6%에 도달했다(§3).
- 보강 근거: [[physics-of-lm-3]]은 하나의 고정 전기를 1,000회 노출한 것이 서로 다른 템플릿 전기 1,000개보다 약간 적게 저장되며, 다양성이 낮은 데이터는 암기될 수 있지만 추출 가능성은 거의 0%라고 보고한다(부록 A.3). [[factual-knowledge-acquisition-pretraining]]은 패러프레이즈 노출에서 더 느린 망각을 발견한다(§4). 상태: 부분적 보강 근거가 있는 **결과(단일 연구, 통제된 합성 데이터)**.

**조건과 한계.** 여섯 속성을 가진 합성 전기이며, 이 논문의 모델은 최대 682M이다(1B 모델과 N = 20M의 후속 연구가 이를 확인했다고 각주에서 보고함). 영어-프랑스어 번역은 정확도를 약 40%로 올렸다(각주). 인코더 전용 마스크드-LM 모델은 한 단어 속성을 제외하면 추출을 위한 지식을 저장하지 못했다(결과 7).

**함의.** 범용 모델에서 사실이 사전학습 중 나타나는 형식의 다양성은 후속 단계가 이를 사용할 수 있는지를 결정한다. 같은 유형의 다른 엔터티가 다양한 형식으로 나타날 때 희귀 엔터티가 이득을 본다. 증강한 인물 100,000명은 증강하지 않은 인물 100,000명의 정확도를 4.4%에서 86.8%로 올렸다(결과 6).

## §6 조작과 방향: 분류, 역검색, reversal curse

**정의.** 지식 조작은 저장한 사실의 함수에 답하는 것이다(예: 출생 월이 짝수인지). 역검색은 속성에서 엔터티를 복원하는 것이다. reversal curse는 “A is B”로 학습한 모델이 B가 주어졌을 때 A에 무작위 이름보다 높은 우도를 할당하지 못하는 현상이다([[reversal-curse]] §1).

**문제.** 범용 모델은 학습 텍스트가 진술하지 않은 방향과 변환으로 사실을 질문받는다.

**조작에 관한 증거** ([[physics-of-lm-3-2-knowledge-manipulation]], 출생일을 거의 100%로 추출하는 bioS multi5 + permute로 사전학습한 모델):
- 사고의 연쇄 없이 출생 월의 홀짝을 판단하려면 홀드아웃 정확도 75%에 도달하는 데 학습 표본 10,000개가 필요하고, 월 순위 매기기는 85%에 학습 표본 50,000개가 필요하다(결과 3).
- 사고의 연쇄 힌트(답 전에 속성을 쓰는 것)는 시험 시점에 생성할 때만 도움이 된다. 학습 인물 10,000명의 “전공 mod 5”에서 힌트 없이는 23.6%(우연 20%), 모델이 힌트를 쓸 때는 86.4%, 힌트로 학습했지만 힌트 없이 답할 때는 24.1%였다(그림 4; 결과 4).

계산 예시(각주 14): 힌트 정확도 91.0%, 힌트가 틀릴 때 무작위 추측 50%라면 예측 정확도는 0.910 + (1 − 0.910) × 0.50 = 0.955이다. 측정 정확도는 94.2%이다. 힌트가 있을 때의 정확도는 힌트 생성 정확도가 예측하는 값에 가까우므로, 남은 오류는 주로 속성을 검색하는 데서 온다(**해석**).

**방향에 관한 증거.**
- QA 미세 조정과 혼합 학습 아래, 뒤집지 않은 16개 bioS 데이터셋 모두에서 역검색 정확도는 0에 가깝다. 뒤집지 않은 모든 미세 조정 행에서 전체 이름 정확도는 0.0이며, 사전학습 텍스트에서 이름이 속성 뒤에 나타날 때만 정확도가 오른다([[physics-of-lm-3-2-knowledge-manipulation]] 결과 7, 그림 6).
- 가공 사실로 미세 조정한 GPT-3-175B에서 DescriptionToName은 학습한 방향 96.7%, 반대 방향 0.1%였고, NameToDescription은 50.0%와 0.0%였다([[reversal-curse]] 표 1). 각 사실에는 학습한 순서로 패러프레이즈 30개가 있었다. GPT-3-350M의 학습률 및 배치 크기 설정 20개 전반에서 반대 방향 정확도는 0.0%에서 0.3% 사이에 머물렀다(부록 B.2, 그림 7). 350M–175B에서 올바른 이름의 로그확률은 무작위 이름과 다르지 않았다(그림 4).
- GPT-4는 유명인의 부모를 79%의 경우에, 부모로부터 유명인을 33%의 경우에 맞혔다(§2.2; 학습 데이터가 알려지지 않아 잠정적임).
- 810M–52B 사전학습 모델의 영향 함수는 프롬프트와 관련된 구절이 완성과 관련된 구절보다 앞에 나타날 때만 학습 시퀀스가 완성에 영향을 줌을 보인다. 순서를 뒤집으면 영향은 거의 0으로 감쇠한다([[influence-functions-generalization]] 초록, §5.3.4).
- 상태: 미세 조정, 처음부터 학습, 영향 분석을 사용한 세 그룹에서 **복제됨**.

**조건과 한계.** 문맥에 “A is B”가 주어지면 모델은 “B is A”를 추론한다([[reversal-curse]] 부록 B.6). 실패는 학습 텍스트에서 학습하는 과정에 있다. Allen-Zhu와 Li는 이를 왼쪽에서 오른쪽으로 진행하는 자기회귀 학습에 돌린다(**해석**, [[physics-of-lm-3-2-knowledge-manipulation]] §5).

**함의.** 지식에 대한 양방향 접근은 데이터에 있어야 한다. [[physics-of-lm-3-2-knowledge-manipulation]] 결과 9는 완화책으로 뒤집은 재진술(예: 다시쓰기 프롬프트를 통해), 검색, 줄 번호를 나열한다.

## §7 long-tail 지식: 사실을 포함하는 문서 수에 대한 의존성

**정의.** 질의응답 쌍의 관련 문서는 눈에 띄는 질문 엔터티와 답 엔터티를 모두 담은 사전학습 문서이며, 엔터티 연결로 찾는다([[long-tail-knowledge]] §2).

**문제.** 평균 QA 정확도는 모델이 희귀 사실을 아는지 숨긴다.

**작동 방식** ([[long-tail-knowledge]] §2–§3):
1. 사전학습 코퍼스(The Pile, ROOTS, C4, OpenWebText, Wikipedia)를 엔터티 연결한다.
2. TriviaQA와 Natural Questions를 엔터티 연결하고, 질문 및 답 엔터티가 함께 나타나는 문서를 센다.
3. 질문을 log10 횟수로 버킷화하고, 버킷별 4-shot 정확 일치 정확도를 측정한다.
4. 인과성을 시험하기 위해 표본 질문의 관련 문서를 제거한 C4로 4.8B 모델을 다시 학습한다.

**증거.**
- 관련 문서가 10^1에서 10^4로 증가할 때 BLOOM-176B의 TriviaQA 정확도는 25%에서 55% 이상으로 오른다(§3.1).
- 반사실 재학습(C4의 약 30% 제거)에서 정확도 손실은 질문의 원래 관련 문서 수와 함께 커진다(§3.2, 그림 5).
- 관련 문서가 100개 미만인 Natural Questions 항목에서 정확도는 매개변수에 대해 로그 선형(R² = 0.98)이며, 지도 기준선 또는 인간을 맞추려는 외삽에는 10^18개를 넘는 매개변수가 필요하다(§4.2, 그림 6).
- 관련 문서 수는 코퍼스 간 Spearman 0.87–0.97로 상관한다(표 1). 저자들은 이를 사용해 사전학습 출처를 다양화해도 희귀 사실에는 제한된 이득만 줄 것이라고 주장한다(§4.1).
- 검색 증강은 희귀 질문에서 정확도를 가장 많이 올린다(§4.3, 그림 9).

**동역학과의 연결(해석, 도출).** [[factual-knowledge-acquisition-pretraining]] §4.4는 학습 가능성 임계값을 가설로 제시한다. 만나는 간격이 그 임계값을 넘는 사실은 축적되기 전에 잊힌다. 두 가정 아래의 계산 예시(사실을 담은 문서가 균등하게 간격을 두고 있고, 임계값은 표 6의 x 절편 근처이며 각주 7은 그렇지 않을 수 있다고 말함)를 보자. 2T-토큰 실행에서 문서 100개에 있는 사실은 2×10^12 / 100 = 2×10^10 토큰(10^10.3)마다 한 번 보인다. 이 간격은 10^11.02(중복 암기, 배치 4M 토큰)보다 짧지만 10^9.45(배치 128 시퀀스)보다 길다. 문서 10개라면 간격은 2×10^11이고, 둘보다 길다.

**조건과 한계.** TriviaQA에서 엔터티 연결의 정밀도는 약 60%이다(§2.3). 배경 텍스트가 있는 인간 정확도는 희귀 질문에서 가장 높으며, 저자들은 이를 이용해 희귀 질문 자체가 더 어려운 것은 아니라고 주장한다(§3.1, 그림 7).

**함의.** 범용 모델의 사실 정확도는 코퍼스의 문서 빈도에 의존한다. 이는 125M–176B(GPT-Neo와 BLOOM)에서는 상관적으로, 4.8B에서는 인과적으로 나타난다(§3.1–§3.2). 평가는 빈도 버킷별 정확도를 보고해야 하며, 희귀 사실을 위한 데이터 설계는 다양한 형식의 노출을 더하거나(§5) 검색에 의존해야 한다.

## §8 행동을 학습 문서로 추적하기: 영향 함수

**정의.** 영향 함수는 학습 시퀀스 하나를 학습 집합에 추가했을 때 모델의 측정값이 어떻게 바뀔지를 추정한다([[influence-functions-generalization]] §2.1).

**문제.** 능력이 암기한 단락에서 왔는지 또는 많은 관련 문서에서 왔는지를 결정하려면 학습 데이터로의 귀인이 필요하다.

**수식**(식 25):

I_f(z_m) ≈ −∇_θ f(θ_s)ᵀ (G + λI)⁻¹ ∇_θ L(z_m, θ_s)

- z_m: 후보 학습 시퀀스; θ_s: 최종 사전학습 가중치; f(θ) = log p(z_c | z_p; θ): 프롬프트 z_p가 주어졌을 때 완성 z_c의 로그확률; L: 학습 손실; G: EK-FAC(고유값 보정 Kronecker-인수분해 곡률)로 근사한 Gauss-Newton 헤시안; λ: 감쇠. 양의 I_f는 z_m을 추가하면 완성의 로그확률이 오른다는 뜻이다.

**작동 방식.**
1. 모델마다 G의 EK-FAC 근사를 한 번 적합한다(MLP 매개변수만).
2. 각 질의에 대해 v = (G + λI)⁻¹ ∇_θ f를 한 번 계산한다.
3. 각 후보 시퀀스에 대해 그래디언트 ∇_θ L(z_m)과 점수 −vᵀ∇_θ L(z_m)을 계산한다.
4. 후보 순위를 매긴다. 비용을 줄이기 위해 TF-IDF 필터링(질의와 용어 중복이 높은 후보를 남김) 또는 질의 배칭을 사용한다(§3.2).

두 매개변수 계산 예시: ∇f = (1, 1), G + λI = diag(2, 0.5)라고 하자.
- ∇L = (−1, −0.5)인 시퀀스 1: (G + λI)⁻¹∇L = (−0.5, −1), ∇f와의 내적 = −1.5, I_f = +1.5이다. 이것으로 학습하면 완성의 로그확률이 오른다.
- ∇L = (−1, +0.5)인 시퀀스 2: (G + λI)⁻¹∇L = (−0.5, +1), 내적 = +0.5, I_f = −0.5이다. 이것으로 학습하면 완성의 로그확률이 낮아진다.
역곡률은 곡률이 낮은 두 번째 좌표에 2를, 첫 번째 좌표에 0.5를 곱하므로 두 번째 좌표가 부호를 결정한다.

**증거** ([[influence-functions-generalization]], 810M–52B 사전학습 모델):
- 영향은 멱법칙 꼬리를 이루며 많은 시퀀스에 퍼져 있다. 저자들은 전형적인 어시스턴트 출력에서 하나의 시퀀스가 지배하는 것을 찾지 못했지만, 유명 단락 질의는 정확한 단락을 반환했다(§5.2.1, §5.3.3).
- 810M 모델의 가장 영향력 큰 시퀀스는 질의와 토큰을 공유하며, 52B 모델에서는 토큰 중복은 적지만 주제를 공유한다(§5.3.1, 그림 1).
- 같은 질의의 한국어 및 터키어 번역에 대한 영어 시퀀스의 영향은 810M에서는 무시할 만하며 모델 크기와 함께 증가한다(§5.3.1, 그림 16).
- 상태: 비공개 모델에서의 **결과(단일 연구)**.

**조건과 한계.** 영향 함수는 전체 재학습이 아니라 국소 반응(근접 Bregman 반응 함수)을 근사한다. MLP 매개변수와 코퍼스 일부만 다뤘으며, 미세 조정은 연구하지 않았다(§1).

**함의.** 범용 모델이 의존하는 교차 언어 및 추상적 이전은 이 분석에서 더 큰 규모에 나타난다. 영향 스캔은 벤치마크 행동이 많은 관련 문서에 의해 지지되는지, 몇 개의 근접 복사본에 의해 지지되는지를 점검하는 도구이다.

## §9 사전학습 데이터 설계에 대한 결과

**비균등 반복.** [[repeated-data-scaling]]은 토큰의 고정 비율이 작은 부분집합을 반복하는 방식으로 모델을 100B 토큰 동안 학습한다.
- 데이터의 0.1%를 100회 반복한 토큰이 10%인 800M 모델은 400M 모델의 성능으로 저하되었다(초록; §2는 “거의” 340M이라고 말함).
- 최악의 반복 횟수에서 반복 데이터 3%를 쓰면, 복사(11회 반복한 단락의 손실)는 유효 모델이 3배 작아진 수준으로 저하됐고 시험 손실은 최대 1.15배 저하됐다(§2, 그림 5). 논문은 복사를 반복 패턴을 완성하는 어텐션 회로인 induction head(ch-08b)와 연결하며, 접두사 일치 점수도 낮은 반복 비율에서 우선적으로 저하됐다(그림 6).
- 최대 피해는 반복 부분집합의 학습 손실이 0에 접근하는 때와 일치하며(§2, 그림 2), 이는 진단 지표이다.

계산 예시(§5.1): 800M 모델의 손실은 약 2.0 nats/token, 400M 모델은 약 2.2라고 하자. 반복한 10%를 암기하여 그 손실이 0이 되고 나머지 90%가 2.2로 저하되면, 평균은 0.9 × 2.2 + 0.1 × 0 = 1.98로 2.0보다 낮다. 따라서 학습 목표는 암기를 선호한다.

**수식(저하 구간, §2).** E = k · N^α이며, 왼쪽 경계는 k = 4.2×10^6, α = −0.56이고 오른쪽 경계는 k = 5.1×10^7, α = −0.50이다.

- E: 부분집합에 대한 반복 에포크; N: 매개변수 수; 이 구간은 100B 학습 토큰에서 최대 저하의 최소 50%를 표시한다.

계산 예시(도출): N = 10^9에서 왼쪽 E = 4.2×10^6 × 10^(−5.04) ≈ 38이고, 오른쪽 E = 5.1×10^7 × 10^(−4.5) ≈ 1,613이다. 100B 토큰 중 10%를 반복한다면 이 구간은 10^10 / 1,613 ≈ 6.2M부터 10^10 / 38 ≈ 261M까지의 고유 토큰 반복 부분집합에 대응한다. [figures/knowledge-acquisition-explorer.html](figures/knowledge-acquisition-explorer.html) 그림(패널 C)은 어떤 모델 크기와 반복 비율에 대해서도 이 구간을 계산한다.

**균등 반복.** [[data-constrained-scaling]]은 전체 데이터셋을 반복한다. 최대 4 에포크는 손실을 무시할 만하게 바꿨다(8.7B 모델은 4 에포크에서 검증 손실이 1 에포크보다 0.5% 높게 끝남). 두 결과는 함께 성립한다. [[repeated-data-scaling]]의 해는 나머지가 고유한 가운데 부분집합(예: 데이터의 0.1%)을 100회 이상 반복하는 데서 오며, [[data-constrained-scaling]]은 모든 토큰을 같은 횟수만큼 반복한다(**해석**).

**음의 한계 가치.** 중복 문자열과 크게 반복한 부분집합은 음의 한계 가치를 가진 샘플이다(이 강의가 ch-43a에서 가르치는 “음성”의 네 의미 중 첫 번째). 이는 양성 표적으로 사용하면 성능을 낮춘다. 이 단계는 이를 제거하거나 다시 작성하며, 음의 그래디언트를 쓰지 않는다.

**결정 규칙.**
- 사실 또는 문서 유형이 희귀하고 중요할 때는 패러프레이즈, 순서를 바꾼 재진술, 뒤집은 재진술을 생성해 사전학습 데이터에 더한다. 증강은 홀드아웃 추출을 9.7%에서 96.6%로 올렸고([[physics-of-lm-3-1-knowledge-storage]]), 사전학습 텍스트에서 속성이 이름보다 앞에 올 때만 역검색이 거의 0에서 올라갔기 때문이다([[physics-of-lm-3-2-knowledge-manipulation]] 그림 6). 그렇지 않으면 long tail에는 추론 시 검색에 의존한다([[long-tail-knowledge]] §4.3).
- QA 형식 또는 명령어 데이터가 있을 때는 SFT에만 넣지 말고 일부를 사전학습에 포함한다. 같은 데이터에서 사전학습 후 미세 조정은 9.7%였지만 혼합 학습은 86.6%에 도달했기 때문이다([[physics-of-lm-3-1-knowledge-storage]] 결과 1).
- 부분집합 가중치를 높일 때는 반복 횟수를 계산해 E = k·N^α 구간과 비교하고, 부분집합의 학습 손실 및 복사 평가를 모니터링한다. 부분집합 손실이 0에 가까울 때 피해가 최대였기 때문이다([[repeated-data-scaling]]).
- 지식이 많은 연속 사전학습에서 배치 크기를 고를 때, 같은 토큰 수라면 큰 배치를 선호한다. OLMo-7B의 500B-토큰 체크포인트에서 배치 128은 2,048에 비해 유지 가능성의 x 절편을 약 37배 줄였기 때문이다. 다만 두 배치 크기만 시험했고, 작은 배치 실행에서는 옵티마이저 상태를 다시 초기화했다([[factual-knowledge-acquisition-pretraining]] §4.3, 표 6, 11). 그렇지 않고 메모리 때문에 작은 배치를 써야 한다면 표적 사실 노출 간격을 줄인다. 이는 시험한 개입이 아니라 학습 가능성 임계값 가설에서 따른다(**해석**, [[factual-knowledge-acquisition-pretraining]] §4.4).

## 일반화 렌즈

**(a) 무엇이 범위를 넓히는가.** 같은 사실의 다양한 재진술: multi5 + permute는 하나의 고정 전기의 9.7%에 비해 홀드아웃 추출 96.6%를 보였다([[physics-of-lm-3-1-knowledge-storage]] 그림 3). 같은 유형의 다른 엔터티에 관한 증강 데이터: 소수 정확도 4.4% → 86.8%([[physics-of-lm-3-1-knowledge-storage]] 결과 6). 사전학습 내부의 QA 형식 데이터(결과 1). 역방향 질의를 위한 뒤집은 재진술([[physics-of-lm-3-2-knowledge-manipulation]] 그림 6). 모델 규모: 810M보다 52B에서 더 추상적이고 교차 언어적인 영향 패턴([[influence-functions-generalization]] §5.3.1), 560M보다 BLOOM-176B에서 더 높은 long-tail 정확도([[long-tail-knowledge]] §3.1), 1B보다 7B에서 더 큰 효과성([[factual-knowledge-acquisition-pretraining]] 그림 3). 중복 대신 패러프레이즈한 노출, 그리고 망각을 늦춘 더 큰 배치([[factual-knowledge-acquisition-pretraining]] 표 2, 6, 11).

**(b) 무엇이 좁아짐이나 망각을 일으키는가.** 저하 구간 안에서 반복한 작은 부분집합: 시험 손실의 1.15배에 비해 복사에서 3배 유효 크기 손실([[repeated-data-scaling]] 그림 5). 중복 텍스트: 9개 셀 중 7개에서 패러프레이즈 텍스트보다 더 빠른 망각([[factual-knowledge-acquisition-pretraining]] 표 2), 더 높은 추출 가능한 암기([[quantifying-memorization]] §4.2). 하나의 형식, 하나의 방향으로만 주어진 사실: 추출은 거의 0이고 역방향 검색도 거의 0([[physics-of-lm-3-1-knowledge-storage]] 결과 2; [[reversal-curse]] 표 1). 시험 때 CoT를 생성하지 않고 CoT로 학습: 86.4%에 비해 24.1%([[physics-of-lm-3-2-knowledge-manipulation]] 그림 4). 보존을 줄이는 긴 만남 간격과 작은 배치([[factual-knowledge-acquisition-pretraining]] 표 6, 11). 크게 반복한 데이터로 사전학습한 뒤 미세 조정: 처음부터 학습하는 것에 비해 1.6배 유효 크기 감소([[repeated-data-scaling]] §5.4는 반복 토큰 90%에서 이를 보고하며, §2는 50%에서 같은 비교를 설명함).

**(c) 이 단계에서 이를 어떻게 측정하는가.** 시험 엔터티에 관한 질문을 하나도 학습하지 않는 홀드아웃 엔터티 QA 분할([[physics-of-lm-3-1-knowledge-storage]] §2.1). 패러프레이즈 및 뒤집은 프로브([[factual-knowledge-acquisition-pretraining]] 표 1; [[reversal-curse]] §2.1). 관련 문서 수로 버킷화한 정확도([[long-tail-knowledge]] §3.1). 학습하지 않은 모델 또는 시험 집합 추출과 비교한 학습 데이터의 추출률([[quantifying-memorization]] §4.1; [[how-much-do-lms-memorize]] §4). 반복 부분집합의 복사 평가 및 학습 손실([[repeated-data-scaling]] 그림 2, 5). 하나의 평균이 아닌 도메인별 홀드아웃 퍼플렉서티([[paloma]]). 행동을 문서에 귀인하기 위한 영향 스캔([[influence-functions-generalization]]). 알려진 측정 오류: 추출은 접두사 길이(33% 대 65%), 디코딩, 일치 정의에 좌우된다([[quantifying-memorization]] §4.3–§4.4). 엔터티 연결 횟수의 정밀도는 약 60%이다([[long-tail-knowledge]] §2.3). 실제 모델의 reversal 및 조작 시험은 학습 데이터 범위를 배제하지 못한다([[reversal-curse]] §2.2; [[physics-of-lm-3-2-knowledge-manipulation]] §4). 매개변수당 10^2 토큰 이상에서는 멤버십 추론이 우연일 것으로 예측되므로 샘플이 없다는 것을 확인할 수 없다([[how-much-do-lms-memorize]] §5.2.2). 유지 가능성은 생성이 아니라 로그확률로 측정한다([[factual-knowledge-acquisition-pretraining]] 부록 A).

| 지식 주입 연속 사전학습에 작은 배치 사용 | 프로브 로그확률 이득이 약 10^9.5 토큰 안에 사라짐 | 두 배치 크기에서 유지 가능성을 비교한다([[factual-knowledge-acquisition-pretraining]] 표 6, 11) |

## 이해 점검

1. 모델은 전기 안의 속성 토큰에서 99%를 넘는 다음 토큰 정확도에 도달했지만, 홀드아웃 엔터티 질문에는 9.7%로 답한다. 프로빙 결과를 사용하여 이 모델에서 속성이 어디에 저장되는지, QA 미세 조정이 왜 이를 이름 위로 옮기지 못하는지 설명하라.
2. 다른 사람의 증강 전기를 더하자 증강하지 않은 사람의 정확도가 4.4%에서 86.8%로 올랐다. 서로 다른 엔터티의 데이터가 어떻게 모델이 희귀 엔터티의 사실을 저장하는 방식을 바꾸는지에 대한 작동 방식을 설명하고, WikiBook 텍스트가 왜 이 효과를 내지 못했는지 설명하라.
3. 중복 주입은 패러프레이즈 주입보다 더 큰 즉시 로그확률 이득을 내지만, 이 장은 패러프레이즈를 권한다. 감쇠 상수와 x 절편을 사용하여 절충을 설명하고, 생성한 답에서 이 권고를 확인하려면 어떤 측정이 필요한지 말하라.
4. 반복 데이터 실험에서 피해는 왜 가장 높은 반복 횟수가 아니라 중간 반복 횟수에서 최대가 되는가? 0.9 × 2.2 + 0.1 × 0 계산과 용량 논증을 사용하라.
5. 반복 부분집합은 왜 시험 손실보다 복사를 더 해치며, 이것이 범용 모델의 인컨텍스트 학습에 대해 무엇을 뜻하는가?
6. 실습이 속성 비교를 위한 사고의 연쇄 예시를 사전학습 데이터에 더했지만, 직접 답 벤치마크에서는 변화가 없다. 결과 4와 힌트 정확도 계산으로 이 결과를 설명하고, 데이터가 실제로 만든 변화를 측정할 평가를 제안하라.
7. 매개변수당 200토큰으로 학습한 모델에서 멤버십 추론이 우연 수준으로 실패한다. 이것이 특정 벤치마크 항목이 학습에 없었다는 것을 왜 보이지 않는지, 이 장의 어느 방법이 어느 쪽이든 근거를 줄 수 있는지 설명하라.
