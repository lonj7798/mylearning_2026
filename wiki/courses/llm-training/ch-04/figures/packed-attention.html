Per-document loss share and NEFTune scale

Target tokens Ni count positions whose label is not −100. Following TRL's padding-free collator, the label is −100 wherever position_ids is 0, so Ni = Li − 1 when position ids reset, and only the first token of the row loses its label when they are continuous. Token mean weights documents by Ni; sequence mean (LongAlign scaling) gives each document 1/M. The last column is the NEFTune noise scale of the Transformers hook (row length) divided by the per-sequence scale of Algorithm 1, √(Li / row length).

How to read the result

  • With the document mask on, switching position ids between reset and continuous leaves every attended pair's RoPE offset unchanged, because RoPE attention depends only on the difference of positions. The true boundaries are unchanged too.
  • With continuous position ids, a framework that infers boundaries from position_ids finds one segment for the whole row. In that path the reset is what carries the document mask.
  • With the document mask off, orange cells show attention to other documents. If position ids also reset, those cross-document pairs receive offsets that do not equal their distance in the row, including negative offsets.
  • Turning the mask on removes long distances from f(i) unless a single document is long.
