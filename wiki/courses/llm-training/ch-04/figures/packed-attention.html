What you're seeing. Each green square at (i, j) means query token i is allowed to read key token j. The rule: same sub-sequence AND j ≤ i. Flip one sub-sequence into another by editing lengths — notice the green block splits cleanly, never touching off-diagonal cells.

Why it matters. Drop the block-diagonal mask and the softmax in sub-seq 2 includes keys from sub-seq 1 in its partition function Z = Σj exp(qi·kj). Loss stays plausible; gradients silently leak between unrelated documents. A max_seq_len = 4096 dense mask is 16M entries — instead flash_attn_varlen_func(..., cu_seqlens_q, cu_seqlens_k, causal=True) consumes only the cumulative offsets shown above and computes the diagonal blocks in-kernel. Memory is O(Σ Li), not O(N²).

position_ids reset at every boundary. RoPE uses the position for its rotation angle, and learned embeddings index into a table. Forgetting the reset means sub-sequence 2's first token looks like it sits at position L1, not 0 — the model effectively sees one very long conversation instead of many short ones.
