Group-Baseline Advantages: RLOO vs GRPO vs Dr.GRPO

Two interactive panels for ch-40. Panel 1: pick a group size K and a reward distribution; compare the per-sample advantages each variant assigns. Panel 2: set rollout lengths and correctness; see per-token gradient magnitude under GRPO (1/|o_i|) vs Dr.GRPO (1/L_max) to visualize the length bias.

Panel 1 — Advantage distribution under RLOO, GRPO, Dr.GRPO

RLOO: A_i = r_i − (1/(K−1)) Σ_{j≠i} r_j    GRPO: A_i = (r_i − mean) / std    Dr.GRPO: A_i = r_i − mean

Watch the "easy" and "hard" distributions: std → 0, so GRPO's advantage blows up (clipped here by ε=1e-6 in the denominator). Dr.GRPO stays well-scaled. Watch K small (K=2): RLOO pairs equal ±(r_1 − r_2), so the two bars are mirror images. Large K: RLOO → Dr.GRPO exactly.

Panel 2 — Length bias: per-token gradient magnitude vs response length

stats render on load
GRPO aggregates each response with (1/|o_i|). A 500-token wrong response gets a per-token loss magnitude of |A|/500; a 50-token correct response gets |A|/50 — 10× larger. The optimizer therefore moves each token in the long wrong response 10× less than each token in the short correct one. Adding padding/repetition to a wrong rollout dilutes the penalty instead of amplifying it. Dr.GRPO uses a fixed 1/L_max, so per-token penalty magnitude is equal regardless of realized length.
