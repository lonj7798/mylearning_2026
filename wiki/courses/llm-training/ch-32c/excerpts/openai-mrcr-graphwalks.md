## OpenAI MRCR (multi-round co-reference resolution)
- "Inspired by the MRCR eval first introduced by Gemini (arXiv:2409.12640v2)"; OpenAI's version "expands the tasks's difficulty and provides opensource data".
- Task: a long, multi-turn synthetic conversation in which the user asks for writing about topics; "Hidden in this conversation are 2, 4, or 8 identical asks, and the model is ultimately prompted to return the i-th instance of one of those asks."
- Difficulty sources listed by the card: needles come from the same distribution as distractors (all assistant responses generated by gpt4o); the model must distinguish order among needles; more needles and longer context increase difficulty.
- Metric: `SequenceMatcher` ratio from Python `difflib`. The answer must start with a given alphanumeric hash; "If this hash is not included, the match ratio is set to 0."
- 438 distinct entities, 10 writing formats, 100 samples per bin. Bins by tokens of prompt + answer: [4096, 8192], (8192, 16384], (16384, 32768], (32768, 65536], (65536, 131072], (131072, 262144], (262144, 524288], (524288, 1048576]. Token counts in the reference script use tiktoken `o200k_base`.
- Changelog 12/5/2025: "A bug during generation caused ~10% of datapoints to contain too many target needles, and ~5% of datapoints to contain incorrect ground truth"; corrected rows carry a `date_added` field.

Grading code (README):
```python
def grade(response, answer, random_string_to_prepend) -> float:
    if not response.startswith(random_string_to_prepend):
        return 0
    response = response.removeprefix(random_string_to_prepend)
    answer = answer.removeprefix(random_string_to_prepend)
    return float(SequenceMatcher(None, response, answer).ratio())
```

## Graphwalks
- "The model is given a graph represented by its edge list and asked to perform an operation"; `problem_type` is `bfs` or `parents`; the prompt contains a 3-shot example, the graph, and the operation.
- Extraction: the last line of the response must contain "Final Answer:" followed by a bracketed list; otherwise the parse fails and recall, precision, and F1 are 0.
- Grading: set overlap between sampled and gold node lists; recall = overlap / gold size; precision = overlap / sampled size; F1 = 2 · recall · precision / (recall + precision); both empty gives 1.0.
- Changelog 2/27/26: 24 of 400 `parents` samples in `graphwalks_128k_and_shorter.parquet` had an incorrect ground truth (root node included); the BFS prompt was reworded to return only nodes at exactly the requested depth.
