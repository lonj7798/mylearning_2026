# 10a장 — 모델 기반 품질 필터와 벤치마크 데이터 선택

모델 기반 선택은 (1) 긍정·부정 예시를 정하고 (2) 분류기나 LLM으로 점수를 매기고 (3) 임계값 또는 순위로 문서를 고르고 (4) 남은 토큰의 영역 분포를 검증하는 절차다. FineWeb-Edu는 LLM 교육성 점수와 임계값을 사용했고, DCLM은 instruction 형태의 긍정 예시로 학습한 fastText 분류기를 CORE·EXTENDED 설정으로 비교했다. Nemotron-CC는 긴 학습 기간에서 품질 점수와 고유 토큰 수를 함께 최적화했다.

QuRating은 쌍별 LLM 판단과 temperature sampling을 사용한다. WebOrganizer처럼 품질 필터는 특정 도메인을 암묵적으로 더 많이 남길 수 있다. 도메인 손실과 목표 벤치마크의 상관으로 고르면 테스트 과제에 맞춘 학습이 되어 오염과 과적합 위험이 생긴다. 필터별 제거율, 언어·도메인·길이 변화, 고유 토큰 수, 미공개 평가를 기록한다.

## Recipe

분류기 학습 자료를 별도 보관하고 임계값을 ablation으로 정한다. 선택 전후 동일한 연산량으로 학습해 손실과 능력 축을 비교하며, 테스트 문항을 선택 기준에 넣지 않는다.
