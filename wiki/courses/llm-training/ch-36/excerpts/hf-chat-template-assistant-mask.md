# Excerpt: How `apply_chat_template` builds an assistant-token mask

**Source type:** released config/code. Read on 2026-09-15 at tag v4.46.0. Line numbers refer to that file. Later versions were not checked.

## Docstring (L1779-1782)

```python
return_assistant_tokens_mask (`bool`, defaults to `False`):
    Whether to return a mask of the assistant generated tokens. For tokens generated by the assistant,
    the mask will contain 1. For user and system tokens, the mask will contain 0.
    This functionality is only available for chat templates that support it via the `{% generation %}` keyword.
```

## How the mask is filled (L1895-1910)

```python
if return_assistant_tokens_mask:
    assistant_masks = []
    ...
    for i in range(len(input_ids)):
        current_mask = [0] * len(input_ids[i])
        for assistant_start_char, assistant_end_char in all_generation_indices[i]:
            start_token = out.char_to_token(i, assistant_start_char)
            end_token = out.char_to_token(i, assistant_end_char - 1)
            if start_token is None:
                # start_token is out of bounds maybe due to truncation.
                break
            for token_id in range(start_token, end_token + 1 if end_token else len(input_ids)):
                current_mask[token_id] = 1
        assistant_masks.append(current_mask)
```

The mask starts as all zeros and is set to 1 only inside character spans recorded from `{% generation %}` blocks. With no such block, `all_generation_indices` is empty for every conversation and the returned mask is all zeros (reading of L1895-1910).
