# Tülu 3 §3.2 — Prompt Decontamination

- **Artifact:** "Tülu 3: Pushing Frontiers in Open Language Model Post-Training", Allen AI
- **URL:** https://arxiv.org/abs/2411.15124 ; tooling: github.com/allenai/open-instruct/tree/main/decontamination
- **Source type:** official technical report

## Matching method (§3.2)

The authors tried full-string, n-gram and embedding matching and kept n-gram matching. Quoted from §3.2:

> "while embedding-based methods can in principle identify non-trivial contamination like that due to
> paraphrasing (Yang et al., 2023), we found it difficult to distinguish mere distributional similarity from
> actual paraphrasing. Moreover, partial surface-level overlap using n-gram matching successfully identified
> cases of contamination where the instances were trivially different, e.g., a math problem where only the
> numbers differ."

Operating point, stated in §3.2 and attributed there to Dubey et al. (2024) and Singh et al. (2024a):
- Overlap is computed on **prompts only** (user turns), because completions in open datasets are usually
  regenerated by a model and so carry no evidence about the original test item.
- n = 8. A token of a test instance counts as matched if the test and train instances share an 8-gram
  containing that token.
- A test instance has **significant overlap** with a training instance when more than **50%** of the test
  instance's tokens are matched against that same training instance.
- A **training set** counts as contaminated when its instances overlap with more than **2%** of the
  instances of any evaluation in the development or unseen suite.
- Action: training sets contaminated against the *unseen* suite are removed entirely. Sets contaminated
  against the *development* suite are removed entirely if removal does not significantly change model
  performance, and otherwise only the matching instances are removed.

## Public datasets found contaminated (App. B.2, Table 37; >5% eval overlap)

Percent of the *evaluation set's* instances that overlap with the training set:
Evol CodeAlpaca / HumanEval 70.7; LMSys-Chat-1M / Do-Anything-Now 90.3, JailbreakTrigger 75.0,
AlpacaEval 46.5, AGIEval English 18.7, HumanEval 17.7, BBH 10.6, MMLU 10.3, TruthfulQA 9.2, GSM8K 8.9;
ShareGPT / AlpacaEval 19.2, TruthfulQA 19.1; DaringAnteater / MATH 30.7; NuminaMath-TIR / MATH 18.2;
WildGuardmix / Do-Anything-Now 39.7, JailbreakTrigger 19.0; WildChat GPT-4 / Do-Anything-Now 54.0,
JailbreakTrigger 9.0; OpenAssistant 2 / AlpacaEval 18.3. The first five were used in decontaminated form;
the last four were not used at all.

Stated takeaway (App. B.2): datasets built from real traffic to API models, such as ShareGPT, WildChat and
LMSys-Chat, are likely to overlap with existing benchmark test sets, and should be decontaminated before use.
