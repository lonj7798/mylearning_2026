Policy-gradient variance — baseline comparison

Simulated RLHF-style estimator. Each iteration draws k rollouts per prompt with per-sequence score gradient g_i and scalar reward R_i ~ N(μ_R, σ_R²). The estimator is ĝ = (1/k) Σ_i (R_i − b_i) · g_i. The chart plots the sample variance of ĝ over N independent iterations for each baseline choice. Re-sample to see a different realisation. No model is trained; this is a variance demonstration, not a training curve.

Controls

None = b=0. Constant = exponential-moving-average of R with coef 0.1 (Williams 1992 original REINFORCE baseline). Value = Vφ(s) = μR + noise(ε) with ε = 0.3·σR (imperfect critic). Leave-one-out = bi = (1/(k−1))Σj≠i Rj per [[rloo]]. For k=1 LOO is undefined and is hidden.
