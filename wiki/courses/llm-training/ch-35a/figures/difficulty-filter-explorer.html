Difficulty filters as sampling experiments

A difficulty filter samples a reference model n times on a prompt and keeps the prompt when the number of correct samples k falls in a set S. If the reference model solves the prompt with probability p per sample, k follows a binomial distribution, so the filter keeps the prompt with a probability that depends on p. This page draws that probability for the published rules in read.md §2 and lets the reader test a custom rule. The second panel shows the published selection stages on a log scale.
