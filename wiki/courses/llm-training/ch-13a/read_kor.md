# 13a장 — 다국어 커버리지와 어휘

고정된 파라미터와 토큰 예산에서 언어 수를 늘리면 언어 간 간섭이 생기지만, 가까운 언어 사이의 전이도 생긴다. ATLAS는 전이와 반복을 반영한 유효 데이터량으로 다국어 스케일링을 분석한다. 언어쌍별 전이는 한 언어 학습 전후 다른 언어의 손실 변화로 측정하고, 처음부터 학습한 모델과 다국어 체크포인트를 계속 학습한 모델을 구분한다.

FineWeb2는 언어별 통계에서 임계값을 정해 필터링하며, ÜberWeb은 품질 차이가 측정된 간섭의 원인이 될 수 있음을 보인다. 언어별 토큰 비율, 문서 수, 중복률, 손실과 벤치마크 점수를 기록한다. 문자와 숫자가 비효율적으로 토큰화되면 해당 언어의 유효 학습량이 줄어드므로 vocabulary도 능력 축으로 평가한다.
