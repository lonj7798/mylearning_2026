Failed rollout signal: mask versus penalize

Companion to ch-29d §5-§6. Set the outcome of each rollout in one group and the handling rule for rollouts without a verified outcome. The page recomputes which rollouts receive gradient and the advantage each receives.

Panel A. Group advantage for one prompt (group size 8)

Default counts reproduce the ch-29d §6 example: penalize gives +1.732 / −0.577, mask gives +1.414 / −0.707; the leave-one-out form gives +0.857 / −0.286 and +0.800 / −0.400. Mask and crash-removal rules follow DeepSWE compact filtering (blog §2.3) and GLM-5 §4.1.2. GLM-5 does not state which valid samples are repeated when padding; this page repeats valid samples in list order, which is an assumption of the figure and changes the group mean.

Panel B. pass^k and pass@k for one task

Estimators from τ-bench §3: pass^k = C(c,k)/C(n,k) (all k trials succeed), pass@k = 1 − C(n−c,k)/C(n,k) (at least one succeeds). Default n = 8, c = 6, k = 2 gives 0.536 and 0.964, as in ch-29d §4.
