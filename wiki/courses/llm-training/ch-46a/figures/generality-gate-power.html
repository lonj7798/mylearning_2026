Sizing the generality gate

Companion to ch-46a §7.4. Set the suite size, the trials per task, and the two variance terms, and read the minimum detectable effect and the task count a target effect would require.

ω² = Var(xA) + Var(xB) − 2 Cov(xA, xB) = 2 Var(x) (1 − ρ)
δ = (zα/2 + zβ) · √( (ω² + σ²A/KA + σ²B/KB) / n )   (Eq. 10)
n = (zα/2 + zβ)² (ω² + σ²A/KA + σ²B/KB) / δ²   (Eq. 9)

α = 0.05, power 1 − β = 0.80, so z0.025 + z0.20 = 1.960 + 0.8416 = 2.8016.

Formulas and the constants are from adding-error-bars-evals §5, Eqs. 9 and 10. The default values reproduce worked example 2 of ch-46a §7.4: with the paper's illustrative binary-score values Var(x) = 1/12 and σ² = 1/6, a correlation of 0.70 chosen for that example rather than taken from the paper, and n = 114 tasks, δ is 16.2 points at K = 1 and 9.6 points at K = 4, and reaching 5 points at K = 4 requires 419 tasks. Raising K shrinks only the σ²/K term, so δ approaches a floor set by ω²; raising n shrinks the whole expression. The same source advises against lowering the sampling temperature to reduce variance (§3.3).
