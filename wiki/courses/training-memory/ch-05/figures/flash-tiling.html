FlashAttention Tiling — Online Softmax & the O(N) Memory Win

Naive attention writes the full N×N score matrix to HBM and reads it back three times (Q·Kᵀ → softmax → ·V). FlashAttention tiles Q into rows and K/V into columns, streams each K/V tile into SRAM, and keeps a numerically-exact online-softmax running state (max m, sum l, output O) entirely on-chip — so the N×N matrix is never materialized in HBM. Only the O(N) row statistics are kept. Step through the loop below.

Memory Hierarchy — where the bytes live

The core point: the full N×N score matrix is never written to HBM. As you raise N, the red "naive" cost grows as N² (quadratic) while the green "flash" cost — the O(N) m and l row-stats plus the O(N·d) output — stays essentially flat. That is why FlashAttention turns a terabyte-scale attention activation footprint into gigabytes, making long-context training possible at all (read.md §5).
