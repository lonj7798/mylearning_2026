Transformer Block Dataflow — shape과 byte를 동시에 보기

ch-extra bridge figure · pre-LN block 하나를 tensor 단위로 통과시킨다. 한 줄 요약: block 안의 tensor는 [B,s,h] / [B,a,s,s] / [B,s,4h] 세 shape의 변주뿐이고, training은 그 16개를 전부 붙들고 inference는 K·V 두 개만 남긴다. (단위 규약: 1 MB = 10⁶ B, ch-03 figure와 동일)

0 · config — 모든 숫자는 여기서 나온다

1 · mode — 같은 tensor를 만들고, 남기는 것만 다르다

2 · 한 step씩 — tensor가 생길 때마다 shape과 byte를 같이 본다

residual stream
backward용으로 보존 KV cache로 상주 즉시 해제 (transient) [B,a,s,s] — s에 제곱 [B,s,4h] — 4배 폭
training — 누적 보존량 inference — 상주량 (K·V만) 그 step에서 새로 만들어진 tensor 크기

3 · 같은 step을 진짜 숫자로 — s=3, h=4, a=2, d_head=2

위 패널은 s=4096이라 숫자를 볼 수 없다. 그래서 완전히 같은 연산을 손으로 검산 가능한 크기로 줄여서 나란히 돌린다 — token 3개, hidden 4차원, head 2개(각 2차원), MLP 폭 8. weight는 0 / ±1 / ±0.5만 써서 곱셈이 전부 암산 가능하다. (W_V = I로 잡아 V가 곧 LN1 출력이 되게 했다 — 그래야 context가 LN1 행들의 가중평균이라는 게 눈으로 보인다. causal mask 적용, ε=1e-5.)

4 · 위 16개의 합 = ch-03의 s·b·h·(34 + 5as/h) 인가?

backward가 뭘 요구하는지는 연산마다 정해져 있다. 취향이 아니다 — 각 연산의 VJP(vector-Jacobian product) 식에 뭐가 등장하는지가 전부다.
연산저장하는 것이유
matmul Y = XW입력 XdW = Xᵀ·dY
GELU입력미분이 입력의 함수
softmax출력 PdS = P ⊙ (dP − rowsum(dP⊙P))
dropoutmask (1 B)같은 mask 재사용
LayerNorm입력 + (mean, rstd)정규화 Jacobian 재구성
residual add x + f(x)아무것도 안 함∂(x+f)/∂x = I

여기서 바로 따라오는 결론 하나: Q·K·V 세 projection은 입력을 공유한다(LN1 출력 하나). 그래서 Korthikanti가 6·sbh가 아니라 2·sbh만 세는 것이다.

5 · 왜 pre-LN은 고속도로가 아니라 가지로 들어가는 복사본을 normalize하나

Post-LN — 2017 Transformer, GPT-1

x
x + Attn(x)
LayerNorm ← 고속도로 위에 있다
h′ = LayerNorm(x + Attn(x))
LayerNorm
h″ = LayerNorm(h′ + FFN(h′))
backward가 입력까지 가려면 L개의 LayerNorm Jacobian을 직렬로 통과한다. Xiong et al. 2020: gradient norm이 O(1/√ℓ)로 줄어들고, 초기화 시점의 first-vs-last layer 불균형이 O(L)까지 벌어진다. 원 논문이 warmup 4,000 step을 쓴 이유다.

Pre-LN — GPT-2 이후 전부

x ← 고속도로는 손대지 않는다
┗ 복사본에만 LayerNorm → Attn
h′ = x + Attn(LayerNorm(x))
┗ 복사본에만 LayerNorm → FFN
h″ = h′ + FFN(LayerNorm(h′))
고속도로에 남는 것은 순수한 identity다: ∂xℓ+1/∂xℓ = I + ∂Sub(LN(xℓ))/∂xℓ. I가 항상 붙어 있으므로 gradient는 O(1)로 유지되고 warmup이 선택사항이 된다. 곱셈이 아니라 덧셈이 backward의 기본 경로라는 게 핵심.
