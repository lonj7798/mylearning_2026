QKV Computation Animation

Step through the scaled dot-product attention computation from input to output

n = 4 (tokens)
d_model = 8 (embedding dim)
d_k = d_v = 4 (head dim)
h = 1 (single head for clarity)
Dimensions at each step: X (4x8) -- W_Q (8x4) --> Q (4x4) | X (4x8) -- W_K (8x4) --> K (4x4) | X (4x8) -- W_V (8x4) --> V (4x4) | QK^T (4x4) / sqrt(4) --> S (4x4) | softmax(S) --> A (4x4) | A * V --> Output (4x4)
Total compute: 3 projections (4x8x4 = 96 each) + score matrix (4x4x4 = 64) + output (4x4x4 = 64) = ~420 FLOPs for this tiny example.
