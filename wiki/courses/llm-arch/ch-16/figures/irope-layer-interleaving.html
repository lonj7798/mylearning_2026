NoPE layers handle the 8M-position gap via pure content matching (no positional encoding to extrapolate). RoPE layers add positional structure with inference-time temperature scaling. The residual stream carries information between both layer types.

Key Design Principles

RoPE Layers (Position-Aware)

Handle tasks requiring positional knowledge: syntactic parsing, local coherence, counting, ordering. These layers know WHERE tokens are. In iRoPE, they use inference-time temperature scaling for extension. In Gemma 3, global layers use base=1M for long-range, local layers use base=10K.

NoPE Layers (Position-Free)

Handle tasks requiring semantic matching: fact retrieval, reasoning, entity linking. These layers know WHAT tokens say but not where they are. They are inherently length-invariant — no positional encoding means no out-of-distribution positions at any length.

Local SWA Layers

Attend only within a fixed window (e.g., W=1024). KV cache is bounded regardless of sequence length. These handle the majority of processing — most language understanding is local. Use a different RoPE base optimized for the window size.

Global Attention Layers

Attend to the full context. These are expensive (full KV cache) but essential for cross-document reasoning and long-range retrieval. Used sparingly — 1 in 6 layers in Gemma 3. Use a high RoPE base (1M) to encode long-range relative positions.
