Sinusoidal Positional Encoding

Each dimension oscillates at a different frequency. High-frequency dimensions distinguish nearby positions; low-frequency dimensions encode global position. Together they create a unique fingerprint for every position.

1. Sinusoidal Waves Across Dimensions
PE(pos, 2i) = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

Each curve shows the encoding value for one dimension pair (sin component) across sequence positions 0-127. Dimension 0 has period 2pi ~ 6.3 positions. Dimension 510 has period 2pi x 10000 ~ 62,832 positions. The multi-scale structure lets the model distinguish both nearby and distant positions.

The diagonal is always 1.0 (a position's encoding is most similar to itself). Similarity decays with distance, but does not decay monotonically — the multi-frequency structure creates a complex pattern.

Key property: For any fixed offset k, PE(pos+k) is a linear transformation of PE(pos). This lets the model learn relative-position attention through linear projections.
