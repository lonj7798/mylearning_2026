The Original Transformer Architecture

Click any layer to expand details. Vaswani et al. (2017) encoder-decoder design.

ENCODER
Encoder Output ▶
The final encoder output is a sequence of contextualized vectors, one per source token. Shape: (T_src, 512). This tensor is computed once and reused by every decoder layer's cross-attention, at every decoding step. This "compute once, attend many" property is a key efficiency advantage of the encoder-decoder design.

x 6 layers
Add & Norm ▶
output = LayerNorm(x + FFN(x))
Residual connection adds the FFN output back to the stream, then layer normalization rescales. This is the Post-LN placement from the original paper. Each sub-layer's output is added (not concatenated) to the residual stream — information accumulates additively.
↑
Feed-Forward Network d_ff=2048 ▶
FFN(x) = ReLU(xW1 + b1)W2 + b2
  • W1: 512 x 2048 (expand)
  • W2: 2048 x 512 (project back)
  • Applied identically to each position (position-wise)
  • Contains 2/3 of layer parameters (~2.1M vs ~1.05M for attention)
  • Acts as a key-value memory: rows of W1 are pattern detectors, columns of W2 are value writers
↑
Add & Norm ▶
output = LayerNorm(x + MultiHeadAttn(x))
The residual connection ensures gradient flow directly from output to input (the "gradient superhighway"). LayerNorm normalizes across the d_model=512 feature dimension per position, keeping activations well-scaled.
↑
Multi-Head Self-Attention h=8, d_k=64 ▶
Attention(Q,K,V) = softmax(QK^T / sqrt(d_k)) V
Bidirectional — no mask. Every source position attends to every other.
  • 8 heads, each with d_k = d_v = 64
  • Total: 8 x 64 = 512 = d_model (same cost as single-head)
  • Q, K, V projections: 3 x (512 x 512) = 786K params
  • Output projection W_O: 512 x 512 = 262K params
  • Scaling by 1/sqrt(64) = 1/8 prevents softmax saturation
Each head learns a different "view": syntactic dependencies, coreference, positional patterns, etc.
↑
Input Embedding + Positional Encoding ▶
Token embeddings are looked up from a (|V| x 512) matrix and scaled by sqrt(d_model) = sqrt(512). Sinusoidal positional encodings are then added (not concatenated) to inject position information.
PE(pos,2i) = sin(pos / 10000^(2i/512)) PE(pos,2i+1) = cos(pos / 10000^(2i/512))
The addition means position and content share the same 512 dimensions — downstream layers must learn to disentangle them. This is a known limitation that RoPE later addressed.

DECODER
Linear + Softmax ▶
P(next token) = softmax(h_T * W_vocab + bias)
Projects the decoder's final hidden state to vocabulary size (512 -> |V|), then softmax produces a probability distribution over all tokens. The weight matrix is often tied with the embedding matrix (weight tying), halving vocabulary-related parameters.

Add & Norm ▶
output = LayerNorm(x + FFN(x))
Same structure as encoder. Residual + layer norm after the FFN sub-layer.
↑
Feed-Forward Network d_ff=2048 ▶
FFN(x) = ReLU(xW1 + b1)W2 + b2
Identical structure to encoder FFN. Position-wise: each token position processed independently. The expand-then-compress pattern (512 -> 2048 -> 512) lets the network compute in a higher-dimensional space before projecting back.
↑
Add & Norm ▶
output = LayerNorm(x + CrossAttn(x, enc_output))
Residual connection preserves decoder state; cross-attention output is added on top.
↑
Multi-Head Cross-Attention Q: decoder, K/V: encoder ▶
CrossAttn = softmax(Q_dec * K_enc^T / sqrt(d_k)) * V_enc
This is how the decoder "reads" the source sequence:
  • Queries come from the decoder's previous sub-layer
  • Keys and Values come from the encoder's final output
  • No masking — decoder can attend to all source positions
  • Encoder output is computed once and reused at every decoder layer and every decoding step
  • Same h=8 heads, d_k=64 structure as self-attention
This is the mechanism that was entirely eliminated in decoder-only models (GPT), where the "source" is simply prepended to the same sequence.
↑
Add & Norm ▶
output = LayerNorm(x + MaskedSelfAttn(x))
Residual + layer norm after masked self-attention.
↑
Masked Multi-Head Self-Attention causal mask ▶
Mask[i,j] = 0 if j <= i, else -inf Attn = softmax((QK^T + Mask) / sqrt(d_k)) V
Causal (autoregressive) — each position can only attend to itself and earlier positions. The mask sets future positions to -inf before softmax, zeroing their attention weights.
  • Prevents information leakage from future tokens during training
  • At inference time, decoding is sequential: generate one token at a time
  • This is the same mechanism used in decoder-only LLMs (GPT, LLaMA, Claude)
↑
Output Embedding + Positional Encoding ▶
Target tokens (shifted right by one position) are embedded and summed with sinusoidal positional encodings, identical to the encoder. During training, the full target sequence is processed in parallel with the causal mask enforcing autoregression. During inference, tokens are generated one at a time.

Base model parameters: d_model=512, h=8 heads, d_k=d_v=64, d_ff=2048, 6 encoder + 6 decoder layers = ~65M params total.
The encoder computes a bidirectional representation of the source; the decoder autoregressively generates the target, attending to both its own past tokens (masked self-attention) and the full source (cross-attention).
