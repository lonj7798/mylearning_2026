DeepSeek V3 → V4: Architectural Evolution

Five architectural axes evolved between V3 (671B, 2024) and V4-Pro (1.6T, 2026). Each change targets a specific bottleneck that scaling V3 alone could not solve.

Component DeepSeek-V3 DeepSeek-V4
Attention
MLA (uniform)
576-dim latent per token per layer. All heads share same resolution. O(L²) attention.
→
Hybrid CSA + HCA
Per-head pathway: CSA (sparse top-k, O(Lk)) for lookup heads, HCA (extreme compression) for summary heads. 10% KV cache of V3.2.
Residual
Connections
Standard residual
xl+1 = xl + f(xl). Simple addition. Risk of explosion / collapse at depth.
→
mHC (Birkhoff)
Doubly stochastic mixing matrix via Sinkhorn-Knopp. L1-norm preserved. 4x wider stream, +6.7% overhead.
Memory
Module
None
All knowledge retrieval via attention + MoE computation.
→
Engram
O(1) hashed N-gram lookup. Context-aware gating. Layers 2 & 15. 20-25% of sparse budget.
MoE
Experts
256 experts, top-8
FP8 precision. 5.5% activation ratio. 37B active / 671B total.
→
384 experts, top-6
FP4 precision. 3% activation ratio. 49B active / 1.6T total. Halved expert memory vs V3.
Optimizer
AdamW
β1=0.9, β2=0.95, wd=0.1. 14.8T tokens. Zero loss spikes.
→
Muon
Faster convergence, greater stability. >32T tokens (>2x V3).
Context
Length
128K tokens
Trained at 4K, extended post-training to 32K then 128K.
→
1M tokens
Pre-trained at 32K, extended to 1M. 8x context increase enabled by hybrid sparse attention.
Post-
Training
SFT + RL (GRPO)
Single-pass pipeline. R1 distillation. ~5K GPU-hours.
→
Two-stage pipeline
Stage 1: domain-specific expert SFT/RL. Stage 2: on-policy distillation into unified model.

Key theme: V3 proved that integrating five innovations (MLA, MoE, aux-loss-free, MTP, FP8) produces compound savings. V4 extends this philosophy: hybrid attention + Engram + mHC + FP4 experts + Muon each enable the others. Engram frees attention from factual recall, letting CSA operate with smaller k budgets. FP4 makes 384 experts affordable. mHC enables the wider residual stream that carries 1.6T parameters. The compound effect — not any single innovation — is the story.
