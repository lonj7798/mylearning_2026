Collective Communication Primitives

The building blocks of distributed training. Each parallelism strategy uses a specific combination of these primitives.

All-Reduce

Sum (or average) tensors across all GPUs. Every GPU ends with the same result.

All-Reduce in Distributed Training

All-Reduce is the workhorse of Data Parallelism. After each GPU computes gradients on its micro-batch, all-reduce sums them so every replica has identical averaged gradients for the optimizer step.

Communication volume: 2N per GPU (N for reduce-scatter phase + N for all-gather phase in ring implementation).

Also used by Tensor Parallelism to combine partial results from column/row-parallel operations — but here it sits on the critical path and cannot be overlapped.
