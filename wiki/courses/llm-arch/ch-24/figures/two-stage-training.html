Stage 1: OLMo-Mix-1124

  • Filtered Common Crawl web data
  • Deduplicated, quality-classified
  • Standard web-scale distribution
  • Builds broad language competence
  • ~1 epoch (7B), ~1.5 epochs (32B)
Goal: general knowledge, language modeling foundations

Stage 2: Dolmino-Mix-1124

  • 50% high-quality filtered web
  • ~12% academic papers
  • ~10% math content
  • ~10% educational material
  • ~10% Q&A / instruction data
  • ~8% synthetic data
Goal: refine reasoning, academic knowledge, instruction following

Model Souping

  • Train multiple Stage 2 variants
  • 50B and 300B token mixes
  • Evaluate each on benchmark suite
  • Weight-average the best performers
  • Zero inference cost overhead
Goal: exploit linear mode connectivity for free quality gains
