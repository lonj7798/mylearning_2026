Reading the Visualization

Each card shows one MoE architecture. The grid represents all experts in a single layer, and each row shows one token's routing pattern (which experts are activated for that token). Yellow cells are shared experts that process every token regardless of routing.

The combination bar chart below shows C(N, k) for each architecture -- the number of distinct expert teams the router can assemble. Notice the exponential jump from Mixtral (28 combinations) to DBRX (1,820) to DeepSeek-V3 (trillions). More combinations means finer-grained specialization.
