GPT-1: Pre-Train + Fine-Tune (2018)

Pre-train on BooksCorpus with language modeling, then fine-tune on each downstream task with labeled data and a task-specific linear head. Every task requires gradient updates, task-specific data collection, and hyperparameter tuning.
[START] premise [DELIM] hypothesis [EXTRACT] --> Linear head --> {entailment, contradiction, neutral} --> Fine-tune entire model on NLI data

GPT-2: Zero-Shot Transfer (2019)

The model performs tasks described in natural language without any gradient updates. Task format is specified through text prompts: "TL;DR:" for summarization, "Q: ... A:" for QA. Performance is inconsistent but proves the concept.
Input: "The dog chased the cat. TL;DR:" Output: "A dog chased a cat." --> No fine-tuning, no gradient updates

GPT-3: In-Context Learning (2020)

Provide a few examples of the desired input-output mapping directly in the prompt. The model infers the pattern and generalizes. No gradient updates, no task-specific architecture. The few-shot advantage widens with model scale -- an emergent property.
Input: "Translate English to French: sea otter => loutre de mer peppermint => menthe poivree cheese =>" Output: "fromage" --> Pattern learned from examples in the prompt
