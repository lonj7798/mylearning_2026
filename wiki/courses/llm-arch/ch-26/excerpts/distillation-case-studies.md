# Excerpt: Knowledge Distillation Case Studies — Phi-4 and DeepSeek-R1

<!-- sources: phi-4 technical report, deepseek-r1 technical report -->

## Two Paradigms of LLM Distillation

Classical distillation (Hinton et al., 2015) trains a student to match the teacher's soft logit distribution. Modern LLM distillation has evolved two distinct approaches, illustrated by Phi-4 and DeepSeek-R1:

1. **Data-mediated distillation** (Phi-4): The teacher generates high-quality synthetic training data. The student trains on this data using standard cross-entropy loss — no direct logit matching.
2. **Behavior-mediated distillation** (DeepSeek-R1): The teacher generates reasoning traces (chain-of-thought). The student trains via SFT on these traces, learning not just the answer but the reasoning process.

Both approaches are "distillation" in the broad sense — transferring knowledge from a stronger model to a weaker one — but they distill different things.

## Case Study 1: Phi-4 (14B) — Data-Mediated Distillation

### Setup

| Component | Detail |
|-----------|--------|
| Teacher | GPT-4o |
| Student | Phi-4 (14B dense Transformer) |
| Distillation method | 40% synthetic training data generated by GPT-4o |
| Training data volume | ~10T tokens total (40% synthetic = ~4T synthetic tokens, from ~290B unique tokens) |
| Replay | Synthetic data replayed 13.8 epochs |

### Architecture Choices for the Student

Phi-4 uses a standard decoder-only Transformer:
- 40 layers, 5120 hidden dim, 40 attention heads, 10 KV heads (GQA)
- RoPE, SwiGLU, RMSNorm
- tiktoken tokenizer (GPT-4's tokenizer, for better token efficiency)

No architectural novelty — the innovation is entirely in data.

### The Synthetic Data Pipeline

50 distinct generation approaches, including:
- **Multi-agent prompting:** Multiple LLM personas discuss a problem, generating diverse solution paths
- **Self-revision:** The teacher generates a solution, critiques it, and generates an improved version
- **Instruction reversal:** Given a solution, generate the question — teaching the student to recognize problem structure
- **Seed curation:** Web/code sources are filtered, cleaned, and used as seeds for synthetic elaboration

### Results — Student Surpasses Teacher

| Benchmark | Phi-4 (14B) | GPT-4o (teacher) | Gap |
|-----------|-------------|------------------|-----|
| GPQA (grad STEM) | 56.1% | 50.6% | +5.5 |
| MATH | 80.4% | 74.6% | +5.8 |
| HumanEval | 82.6% | — | — |
| MMLU | 84.8% | — | — |

### Why the Student Surpasses the Teacher

Three factors converge:

1. **Domain concentration:** GPT-4o is a generalist; Phi-4 focuses its 14B parameters on STEM reasoning. More knowledge per parameter in the target domain.

2. **Data curation:** The synthetic data pipeline selects only the highest-quality teacher outputs. The student never sees GPT-4o's failures, inconsistencies, or weak areas — only its best reasoning.

3. **Epoch replay:** 13.8 epochs over synthetic data. Standard wisdom says "see each token once" — but with synthetic data of sufficiently high information density, replay is beneficial because the model gradually extracts deeper patterns from the same examples. This is analogous to a human studying a textbook multiple times versus reading many low-quality blog posts once each.

### Implications for Quantization

Phi-4 at INT4 (~7 GB) achieves STEM performance that a 70B model at FP16 (140 GB) cannot match. This represents a 20x memory reduction with *improved* quality on the target domain — the most extreme point on the Pareto frontier achieved through distillation + quantization.

## Case Study 2: DeepSeek-R1 — Behavior-Mediated Distillation

### Setup

| Component | Detail |
|-----------|--------|
| Teacher | DeepSeek-R1 (671B MoE, 37B active) |
| Students | Qwen2.5-{1.5B, 7B, 14B, 32B}, Llama-3.1-8B, Llama-3.3-70B |
| Distillation method | SFT on 800K curated reasoning traces from R1 |
| Training | Direct SFT only — no RL applied to distilled models |

### What Gets Distilled

Unlike Phi-4 (which distills knowledge via data), R1 distillation explicitly transfers **reasoning behavior**:
- The training data consists of R1's chain-of-thought traces
- Each example includes the full reasoning process, not just the final answer
- The student learns to replicate R1's step-by-step reasoning patterns

### Results — Scaling the Distillation

| Student Model | AIME 2024 (pass@1) | MATH-500 |
|---------------|-------------------|----------|
| R1-Distill-Qwen-1.5B | 28.9% | 83.9% |
| R1-Distill-Qwen-7B | 55.5% | 92.8% |
| R1-Distill-Qwen-14B | 69.7% | 93.9% |
| R1-Distill-Qwen-32B | 72.6% | 94.3% |
| R1-Distill-Llama-70B | 70.0% | 94.5% |
| GPT-4o (for reference) | 9.3% | 74.6% |

The 1.5B distilled model (28.9% on AIME) outperforms GPT-4o (9.3%) — a model roughly 1000x larger. This is the most extreme example of distillation efficiency in the literature.

### Distillation vs RL: The Key Finding

On the same base model (Qwen-32B):

| Method | AIME 2024 |
|--------|-----------|
| RL only (no distillation) | 47.0% |
| Distillation only (no RL) | 72.6% |

Distillation from R1 outperforms direct RL by 25.6 percentage points on AIME. The paper notes that applying RL *after* distillation would yield further gains, but the distillation alone captures most of the benefit. This suggests that for smaller models, learning from a teacher's demonstrations is more sample-efficient than discovering reasoning strategies through RL.

## Distillation + Quantization: The Combined Strategy

The two case studies suggest a deployment pipeline:

1. Train a large frontier model (R1: 671B, GPT-4o: unknown)
2. Distill into a smaller model targeting your domain (Phi-4: 14B for STEM, R1-Distill: 7-32B for reasoning)
3. Quantize the distilled model to INT4 for deployment

This pipeline compounds the compression:
- Distillation: 671B → 14B = ~48x parameter reduction
- Quantization: FP16 → INT4 = 4x memory reduction
- Combined: ~192x memory reduction from the original model

The resulting model fits on consumer hardware while retaining the majority of the frontier model's capability in its target domain.
