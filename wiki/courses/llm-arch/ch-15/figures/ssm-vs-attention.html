SSM vs Attention: Two Paths Through the Same Matrix

The Structured State Space Duality (SSD) shows SSMs and linear attention compute the same semiseparable matrix via different algorithms

Dual Computation Paths

SSM Path (Recurrence)

  • For each t: compute h_t = A_t h_{t-1} + B_t x_t O(N) per step
  • Output: y_t = C_t h_t O(N) per step
  • Total: O(L*N)
  • Best when L >> N (long sequences). Inference: constant memory, O(1) per step.
↔ DUAL ↔

Attention Path (Quadratic)

  • Compute full matrix M where M[t,s] = C_t (prod A_r) B_s O(L^2)
  • Output: y = M * x (matrix-vector multiply) O(L^2)
  • Total: O(L^2)
  • Best when L is small. Leverages tensor core matmul hardware for maximum throughput.

Mamba-2's chunk-wise hybrid: quadratic within chunks (tensor cores), recurrence across chunks (linear). Best of both worlds.

The Semiseparable Matrix M

Both paths compute y = Mx where M is lower-triangular and semiseparable (every lower-triangular submatrix has rank at most N, the state dimension).
