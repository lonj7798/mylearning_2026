Key Differences

Separate vs Unified

R1 is a dedicated reasoning model. Qwen 3 unifies thinking and non-thinking modes in a single model, controlled at inference time.

Data Scale for RL

R1 uses large-scale RL training data. Qwen 3 achieves strong results with only 3,995 query-verifier pairs -- orders of magnitude less.

Compute Allocation

R1 always reasons (varying length). Qwen 3 lets users set a thinking budget, gracefully truncating reasoning if the budget is exceeded.
