NVFP4 Blackwell production default

16-element block. Element: E2M1 (4 bit).
Block scale: E4M3 (8 bit, fractional) + per-tensor FP32.
E2M1 (4 bit) E4M3 scale (8 bit) FP32 tensor (32 bit)
Caption. Two-level scaling (NVFP4) buys ~½ bit MSE over MXFP4's power-of-two scale. DSV3 FP8 is the conservative baseline; NVFP4 is the 2026 production default on Blackwell. Drag the sliders to see how the per-block scale amortizes differently as block size changes: larger blocks reduce overhead but spread the dynamic range over more elements (higher quantization noise). A 1×128 tile in DSV3 keeps the scale "close" to outliers in activations; the small 16-element NVFP4 block does the same for FP4 weights.
