Bit Layouts for Modern Numeric Formats

How every bit is spent across the formats LLM training and inference actually use. Hover over a row to see what each format is used for.

Format Bits Layout (S | E | M) S / E / M Dynamic range Smallest pos. (subnormal)
How to read the rows. Sign bits flip polarity. Exponent bits buy dynamic range — each extra bit roughly doubles the addressable orders of magnitude. Mantissa bits buy precision within a range. Block formats (MXFP4, NVFP4) move the exponent budget out of the per-element word and into a shared scale, so each value carries only sign + mantissa and the per-block scale absorbs dynamic range. BitNet 1.58 takes this to the extreme: no exponent, no mantissa, only a ternary code per weight.
