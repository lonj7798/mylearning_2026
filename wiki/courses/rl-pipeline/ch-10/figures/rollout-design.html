Companion to ch-10. Formulas and parameter defaults come from the cited sources; the curves are computed in your browser. Where a value is an approximation made for this figure (for example, a pass-rate distribution built from bin midpoints), it is labeled.

1. Group size n and zero-variance groups

With a binary reward and pass rate p, all n rollouts of a group get the same reward with probability pn + (1 − p)n. Such a group has zero advantage and no gradient ([[dapo]] §3.2; llm-training ch-40 §5). The curves show the probability that a group is informative, 1 − pn − (1 − p)n.

Big-Math reports Llama-3.1-8B success-rate quintiles (64 rollouts) of 28.64%, 12.16%, 10.26%, 12.44%, 36.50% from easiest to hardest, the hardest bin being success below 20% [[big-math]] §3.1. This figure places each bin's mass at its midpoint (0.9, 0.7, 0.5, 0.3, 0.1); the real distribution inside the hardest bin includes prompts at p = 0, which are never informative, so the computed fraction is an upper bound. For comparison, BroRL measured a dynamic-sampling pass rate of 41% at N = 16 and 62% at N = 512 on its own prompt set [[brorl]] Table 2; that is data, not this formula.

2. Length shaping near the limit

DAPO soft overlong punishment [[dapo]] Eq. 13: 0 up to Lmax − Lcache, then linear to −1 at Lmax, −1 beyond. Defaults: 16,384 expected + 4,096 buffer = 20,480 (§4.1). MAI-Thinking-1 length penalty [[mai-thinking-1]] Eq. 12: −wlen·ρq·|y|/ℓmax, with ρq the problem's pass rate; wlen = 0.25 up to 64k and 0 at 128k (Sec. 3.1.5).

DAPO length term at |y|
MAI length term at |y|
MAI term for the same |y| on a hard problem (ρ = 0.1)

MAI's penalty is applied at every length and scales with pass rate, so an easy problem pays more for the same length than a hard one; DAPO's term is zero until the buffer and does not depend on difficulty. MAI's ℓmax grows with its 8k → 128k doubling schedule (Sec. 3.1.3); wlen is 0 at 128k, so the 128k option shows 0. Whether truncated responses should also be masked is contested: DAPO measured +6 AIME24 from overlong filtering (Table 1); Skywork-OR1 and Olmo 3 RL-Zero found masking hurt [[skywork-or1]] Exp. 3, [[olmo-3-rl-pipeline]] §6.
