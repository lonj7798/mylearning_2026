Sampler weight memory relative to BF16

Ratio = f · (8.25 / 16) + (1 − f). MXFP8 costs 8 bits per element plus one 8-bit scale per 32 elements = 8.25 bits. The post states the experts are "over 95%" of parameters and that MXFP8 storage "nearly halves" weight memory. Padding and metadata are ignored.

Global-context token capacity relative to all-BF16 KV

Ratio = 16·n_g / (16·3 + 8.25·(n_g − 3)), assuming equal per-token KV size in every global layer, 8.25 bits per MXFP8 KV element, the final three global layers in BF16, and a fixed global-KV memory budget. The post reports "approximately 67% more global-context tokens" (ratio ≈ 1.67) but gives neither n_g nor the KV scale layout, so this calculator cannot confirm the figure.
