prefill vs decode
Prefill processes T tokens in parallel — compute-bound. Decode emits one token per step, re-reads full KV cache — bandwidth-bound.
Caption. KV cache scales linearly with batch × seq_len. Long-context serving is fundamentally a KV-cache memory problem before it's anything else. A Llama-3-70B serving 16 concurrent 8k-token requests in BF16 burns ~10 GB just on KV cache; push T to 128k and the same batch overflows an H100.
