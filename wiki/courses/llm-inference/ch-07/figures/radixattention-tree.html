What you should notice. The root system-prompt node (You are a helpful assistant...) is reused by every chat session — three children share it from the start. When you insert a new prompt that begins with the same system message, the matching prefix is recognized greedily (green flash) and only the unmatched suffix becomes a new branch (yellow). The hit-rate counter aggregates matched_tokens / total_tokens across all inserts: chat workloads routinely sit at 50–90% because the system prompt + few-shot examples dwarf the per-turn user text. LRU eviction removes the leaf with the oldest access time so popular subtrees stay resident.
