Logical sequences and block tables

What you should notice. Naive contiguous KV (the pre-vLLM way) reserves max_seq_len per request and burns 60%+ of memory on slack. PagedAttention splits the cache into fixed-size blocks (here 16 tokens each) and gives each sequence a block table — exactly like an OS page table over physical frames. Beam-fork uses copy-on-write: the first divergent block is duplicated, but every earlier block is shared, so beam search and chat-session prefix sharing cost almost nothing. The reported fragmentation is internal — wasted tokens inside partially filled blocks. PagedAttention pushes KV utilization to ~96% in practice vs ~60% for contiguous.
