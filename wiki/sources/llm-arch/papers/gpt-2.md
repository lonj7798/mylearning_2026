# Language Models are Unsupervised Multitask Learners
- **Core Insight:** Language models are unsupervised multitask learners; sufficient scale enables zero-shot task transfer without fine-tuning.
- **Guideline:** When scaling up, invest equally in data quality and model size; curate the training set as carefully as you design the architecture.
- **Authors:** Alec Radford, Jeffrey Wu, Rewon Child, David Luan, Dario Amodei, Ilya Sutskever
- **Year:** 2019
- **URL:** https://cdn.openai.com/better-language-models/language_models_are_unsupervised_multitask_learners.pdf
- **Relevant chapters:** Zero-shot transfer, scaling language models, dataset curation, emergent capabilities

## Abstract
Natural language processing tasks, such as question answering, machine translation, reading comprehension, and summarization, are typically approached with supervised learning on task-specific datasets. We demonstrate that language models begin to learn these tasks without any explicit supervision when trained on a new dataset of millions of webpages called WebText. When conditioned on a document plus questions, the answers generated by the language model reach 55 F1 on the CoQA dataset -- matching or exceeding the performance of 3 out of 4 baseline systems without using the 127,000+ training examples. The capacity of the language model is essential to the success of zero-shot task transfer and increasing it improves performance in a log-linear fashion across tasks. Our largest model, GPT-2, is a 1.5B parameter Transformer that achieves state of the art results on 7 out of 8 tested language modeling datasets in a zero-shot setting but still underfits WebText. Samples from the model reflect these improvements and contain coherent paragraphs of text. These findings suggest a promising path towards building language processing systems which learn to perform tasks from their naturally occurring demonstrations.

## Key Contributions
- Demonstrated that sufficiently large language models can perform downstream tasks in a zero-shot setting (no fine-tuning, no gradient updates), a major departure from GPT-1's fine-tuning paradigm
- Created WebText, a curated 40GB dataset of web pages filtered by Reddit outbound links with 3+ karma, establishing that data quality and diversity matter as much as scale
- Showed that language model capacity is critical for zero-shot transfer, with performance improving log-linearly with model size across tasks
- Achieved state-of-the-art on 7 of 8 language modeling benchmarks in zero-shot, demonstrating that a single model can generalize across domains without task-specific training
- Raised awareness of the potential for language model misuse, leading to a staged release strategy that influenced responsible AI discourse

## Architecture Details
- **Architecture:** Decoder-only Transformer (same family as GPT-1, scaled up)
- **Model sizes:** 117M (Small), 345M (Medium), 762M (Large), 1.5B (XL)
- **GPT-2 XL layers:** 48
- **GPT-2 XL model dimension:** 1600
- **GPT-2 XL attention heads:** 25
- **Context window:** 1024 tokens (doubled from GPT-1's 512)
- **Vocabulary size:** 50,257 (byte-level BPE)
- **Training dataset:** WebText -- ~40GB of text from 8 million web pages (Reddit outbound links with 3+ karma)
- **Tokenization:** Byte-level BPE (not character-level or word-level), enabling open-vocabulary handling
- **Layer normalization:** Moved to input of each sub-block (pre-norm), with additional layer norm after final self-attention block
- **Weight initialization:** Modified -- residual layer weights scaled by 1/sqrt(N) where N is the number of residual layers
- **Activation function:** GELU
- **Positional embeddings:** Learned
- **Batch size:** 512 sequences of 1024 tokens
- **No fine-tuning:** All evaluations performed zero-shot
