# Diversity Axes of the RL Task Distribution

Evidence labels: **causal** = a training ablation changes only this axis; **observational** = models compared or evaluated, no training on the axis; **practice** = a recipe does it, no ablation. Every number is quoted from the cited card.

| Axis | How it's measured | What goes wrong without it (evidence) | How labs control it | Cards |
|---|---|---|---|---|
| Domain | Share of prompts per domain tag (math, code, science, IF, agentic, chat) | **Causal.** Math-only vs mixed-domain zero-RL: SuperGPQA 29.8 vs 34.2 (7B), 35.6 vs 39.5 (14B) ([[general-reasoner-verifier]] Table 4). Single-environment agent policies fail on other environments (DB policy 0.2 on ALFWorld) while a 5-task policy averages 67.7 vs 67.8 best single ([[agentrl]] Table 4). Cross-domain transfer is uneven: RG-Algebra lowered ARC 6.49 → 4.18 ([[reasoning-gym]] Table 2) | Domain tagging and balanced coverage ([[kimi-k1-5]] §2.1); per-task advantage normalization (removing it: 65.0 → 59.4, [[agentrl]] Table 6); stage order or joint mixture (ch-17) | [[general-reasoner-verifier]], [[agentrl]], [[reasoning-gym]] |
| Difficulty / pass rate | Per-prompt pass rate from N rollouts of the current or reference policy | **Causal.** Keeping only pass ≤ 4/8 or not filtering both hurt vs removing 8/8 only ([[polaris]]); zero-variance groups add no gradient, and filtering them raised the asymptote ([[scalerl]] Fig. 6a); dynamic sampling +8 AIME24 ([[dapo]] Table 1). Curriculum beat fixed difficulty at every level ([[reasoning-gym]] Table 5) | Offline + online pass-rate filters ([[skywork-or1]]); drop pass ≥ 0.9 ([[scalerl]]) or > 0.9 ([[polaris]]); generator difficulty parameters ([[reasoning-gym]]); 64-rollout difficulty bins ([[big-math]]) | [[polaris]], [[scalerl]], [[dapo]], [[skywork-or1]], [[reasoning-gym]] |
| Tool calls per turn (single / parallel / dependent) | Call-count category per sample: single, parallel (several calls one turn), dependent/sequential, none | **Causal (SFT).** At 25K samples, removing parallel-call data: BFCL overall 50.60 vs 58.19 for full ToolACE data at the same size; removing non-tool ("multi-type") data: 42.71 and irrelevance 6.99; removing dependent or nested data: under 1.3 points ([[toolace]] Tables 6–7). **Observational:** real user queries contain more multiple-function and fewer parallel cases than curated sets ([[bfcl]] §5.2) | Generate the four dialog types explicitly ([[toolace]] §2.2.1); evaluate Simple / Multiple / Parallel / Parallel-Multiple / Irrelevance separately ([[bfcl]]) | [[toolace]], [[bfcl]] |
| Tool calls / turns per episode (horizon) | Number of tool calls or interaction turns per trajectory; required actions per task | **Causal.** Fixed 10-turn cap gave higher early reward then collapsed, fixed 5 plateaued, staged cap reached highest reward ([[agentgym-rl]] Fig. 7, one environment). **Observational:** τ²-bench pass^1 near zero above 7 required actions ([[tau2-bench]] Fig. 5); accuracy falls with tool-call count ([[agentscaler]] Fig. 5); sharded multi-turn instructions average 39% below single-turn ([[lost-in-multi-turn]]; course excerpt in llm-training ch-25, no library card) | Staged turn caps ([[agentgym-rl]]); tasks composed from atomic subtasks so action count is set ([[tau2-bench]] §3.2); tool-graph walks with max step count ([[agentscaler]] §2.2) | [[agentgym-rl]], [[tau2-bench]], [[agentscaler]], [[lost-in-multi-turn]] |
| Tasks / questions per episode (multi-intent, multi-question) | Number of independent requests in one prompt or one episode | **Observational only.** Learner hypothesis: "RL almost only on single-question prompts → the model loses the ability to answer two or more questions in one prompt." Evidence: DeepSeek-R1 AIME24 81.66 → 52.49 with several problems per prompt; equal single-question MATH500 scores split under stress (R1-7B 66.75 vs R1-32B 88.97); AReaL-boba-RL-7B (RL on R1-7B) 38.07 vs its base 49.42 at stress 9 ([[rest-multi-problem-stress]] Table 1, §4). τ-bench: 19% of gpt-4o failures are partial resolution of compound requests ([[tau2-bench]] §5.2). **Causality not established:** no study found trains with vs without multi-question prompts. REST trains no model; the RL-vs-base pair is one lineage with unknown data. Closest causal analogue is a different axis: GRPO lowered constraint compliance in 15 of 16 trained variants ([[scaling-reasoning-losing-control-mathif]] Table 4) | **Practice:** reverse task recombination concatenates same-persona tasks into one compound task ([[apigen-mt]] §4.1.3); composite tasks with up to one subtask per group ([[tau2-bench]]). Evaluate with REST-style stress levels | [[rest-multi-problem-stress]], [[tau2-bench]], [[apigen-mt]], [[scaling-reasoning-losing-control-mathif]] |
| Toolset size / unseen tools | Distinct tools or APIs and domains in training; held-out tool ecosystems at test | **Causal (SFT).** API-cluster diversity 6 → 14 → 30 clusters at ~30K instances raised overall accuracy, largest gain in relevance detection ([[toolace]] Fig. 5; values figure-only) | 26,507 APIs / 390 domains ([[toolace]]); 3,000+ real MCP + 20,000+ synthetic tools ([[kimi-k2-agentic-data]]); 30,000+ APIs in 1,000+ domains ([[agentscaler]]) | [[toolace]], [[kimi-k2-agentic-data]], [[agentscaler]] |
| Environment count | Distinct executable environments (database + tools) in RL | **Causal.** Four-subdomain average 18.4% with 0 environments → 38.5% with 1,978, larger jumps at 10 → 100 and 100 → 500 ([[agent-world]] §4.3.3, Fig. 8) | Web-mined or generated environments with unit-tested tools ([[agent-world]]); database-as-environment ([[agentscaler]]) | [[agent-world]], [[agentscaler]] |
| User behavior (simulator diversity) | Simulator families / personas / sampling methods used for the user role; held-out simulators | **Causal.** One frozen GPT-5-mini user: held-out τ²-Retail peaks at 46.1% then returns toward 40.4% baseline; persona-guided 49.2%, ensemble of 3 57.1%, population co-training 62.2% ([[simulator-collapse]] Table 1). Simulator error rates 16–47% of conversations ([[tau2-bench]] Table 2) | Persona-guided user LM ([[apigen-mt]] §4.2); co-trained simulators rewarded for within-batch reward variance ([[simulator-collapse]]); dual-control users with tools ([[tau2-bench]]) | [[simulator-collapse]], [[tau2-bench]], [[apigen-mt]] |
| System prompt / persona | Distinct system prompts or personas conditioning prompts | **Partly measured.** Removing the domain policy system prompt: τ-airline 33.2 → 10.8 (evaluation, [[tau2-bench]] Table 3). Persona-conditioned synthesis yields less similar outputs ([[persona-hub]] Fig. 10). No RL ablation of system-prompt diversity found | Persona pools ([[persona-hub]]); synthesized system prompts per agent ([[kimi-k2-agentic-data]]); see [[system-prompt-diversity]] (practice, SFT) | [[persona-hub]], [[system-prompt-diversity]], [[kimi-k2-agentic-data]] |
| Constraint count (IF) | Constraints per prompt; constraint types seen vs unseen | **Causal.** Constraints per instance n = 1…6: IFEval 71.2 → 85.8 at n = 6; training on up to 5–6 generalized better than up to 3 although tests have ≤ 3 ([[ifbench]] Table 1, Fig. 2); **Observational:** on 58 unseen constraints (vs IFEval's 25 templates) GPT-4.1 and Claude 3.7 Sonnet score below 50% | Many constraint types, several per prompt, ranges beyond test ([[ifbench]]); per-instruction checklists ([[rlcf-checklists]]) | [[ifbench]], [[rlcf-checklists]] |
| Answer format | Share of items by answer type (integer, expression, interval, matrix, MC, free text) | **Measured on graders, not policies.** Rule recall 0.78–0.95 on math, 47% on general science ([[verifier-pitfalls]]); rule vs model verifier agreement with Gemini 22.2% vs 78.7% ([[general-reasoner-verifier]]); 117,018 MC items in a 643K pool are guessable ([[big-math]] Table 2) | Remove or reformulate MC / yes-no / proofs ([[big-math]]); convert to integers ([[dapo]] §3.5); model verifier for non-canonical formats ([[general-reasoner-verifier]]) | [[big-math]], [[dapo]], [[verifier-pitfalls]], [[general-reasoner-verifier]] |
| Output / trajectory length range | Max response length; distribution of lengths across tasks | **Causal.** RL max length 1k → 8k: math 28.73 → 39.82, IF hard accuracy 19.05 → 14.29 ([[scaling-reasoning-losing-control-mathif]] Table 5); 14K → 32K raised asymptote, lowered efficiency ([[scalerl]] Fig. 9); Qwen3-4B trained at 24K dropped irreversibly vs 40K ([[polaris]]) | Staged context 8K → 16K ([[skywork-or1]]); soft overlong punishment ([[dapo]]); per-task advantage normalization for mixed lengths ([[agentrl]]) | [[scaling-reasoning-losing-control-mathif]], [[scalerl]], [[polaris]], [[dapo]] |
| Language | Prompt language and CoT language share | **Partly measured.** R1 without a language-consistency reward mixes languages; with it, consistency stays stable, math comparable, coding slightly lower ([[deepseek-r1-recipe]], B.6 Fig. 7, on R1-Distill-Qwen-7B). ACEBench-zh (treated as OOD by the authors) rose 43.9 → 65.6 at 4B after agent SFT ([[agentscaler]] Table 2) | Language-consistency reward = target-language word share in CoT ([[deepseek-r1]] Eq. 7) | [[deepseek-r1-recipe]], [[agentscaler]] |

## Axes dropped for lack of evidence
- Multilingual prompt mixture in RL as a diversity lever: no source read gives an RL ablation over prompt languages.

## Reading the table
- Rows marked causal still come from single studies, mostly one model family; treat effect sizes as specific to that setup.
- For the tasks-per-episode row, the evidence shows that current reasoning models perform worse on multi-question prompts and that one RL-trained model did worse than its base. It does not show that single-question RL training causes the drop; a controlled run (same base, with vs without multi-question prompts in RL) has not been found.
