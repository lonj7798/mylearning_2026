# Enhancing Human-Like Responses in Large Language Models
- **Core Insight:** A contrastive DPO dataset built by prompting one model twice, once for a casual human-like answer (chosen) and once for a formal impersonal answer (rejected), made fine-tuned models win 89.6% (Llama-3-8B), 89.5% (Qwen-2.5-7B), and 79.6% (Mistral-Nemo) of 2,000 pairwise "which is more human-like" votes against their official instruct models (§5.1, Table 5), at a cost mainly on IFEval (−9.11, −3.01, −9.29; Table 6).
- **Guideline:** Use style-contrast DPO pairs (same question, two system prompts) only for the style axis, and audit the chosen side for fabricated personal experience before training, because the dataset's sample chosen answer claims advice "from my grandma" while the rejected answer states it is an AI (Table 1), and the reported win is largely from removing self-referential AI disclaimers (§5.1); for an agent that must disclose it is an AI, that chosen distribution teaches the wrong behaviour.

## Summary
Questions were generated by Llama 3 405B in two types (conversational; general knowledge), and Llama 3 70B answered each twice with different system prompts: a human-like, conversational, engaging answer (chosen) and a formal, structured, impersonal answer (rejected) (§3, §3.1). Sampling used temperature 1 and top-p 1 (§3.2). The dataset has 10,884 samples covering 256 topics (§3.3). Llama3-8B-Instruct, Qwen-2.5-7B-Instruct, and Mistral-Nemo-Instruct-2407 were fine-tuned with LoRA + DPO in Axolotl on 2×A100 80GB (§4).

## Key Contributions
- Released human-like DPO dataset and three fine-tuned models (Fig. 1, §4.3).
- Pairwise human-likeness voting app (Gradio on Hugging Face Spaces) with emojis removed from both sides to reduce identifiable patterns (§5.1).
- Capability check on the Open LLM Leaderboard suite (§5.2).

## Technical Details
**Human-likeness evaluation (§5.1, Table 5).** 500 questions generated with the §3 method; 2,000 votes across three model pairs; annotators were mostly high-school students, generally non-native English speakers, plus adults. Selection rates (fine-tuned vs official): Llama 89.6% vs 10.4%; Qwen 89.5% vs 10.5%; Mistral-Nemo 79.6% vs 20.4%. The authors name the main failure of the official models as self-referential disclaimers such as "I am just a language model...".

**Capability retention (Table 6; Average / IFEval change).** Llama −1.20 / −9.11; Qwen −0.20 / −3.01; Mistral-Nemo −0.65 / −9.29. Average change without IFEval (Table 7): Llama −0.02, Qwen +0.36, Mistral-Nemo +1.07.

**Training dynamics (Fig. 3).** DPO reward margins are plotted against training steps (x-axis to 350) for all three models; no numeric values are given in the text, and the margin values were not extracted.

## Findings relevant to generality and negative feedback
- **Negative signal design.** The rejected side is a deliberately formal answer from the same model, so DPO learns "less formal, fewer disclaimers" rather than a calibrated naturalness scale.
- **Generality.** IFEval drops 3–9 points (Table 6); other Leaderboard tasks change by ≤3.02.
- **Limits stated by the authors (§6.1).** Synthetic data lacks the variability of real user interactions; annotator pool and language proficiency limit the evaluation.
- **Evaluation weakness (card note).** Questions for the human evaluation were produced by the same method as the training questions (§5.1), so the test is in-distribution; no comparison against a real human-written reference was run.
