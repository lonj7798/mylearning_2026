# The Residual Stream Is the Block's Backbone — and the Unit of Memory

<!-- slug: residual-stream-memory-backbone · type: doc · source: wiki:llm-arch:wiki/courses/llm-arch/ch-03/excerpts/residual-stream-deep-dive.md -->

**Core Insight.** A decoder-only transformer is one `[B, T, h]` tensor — the residual stream — flowing from embedding to unembedding, with `2L` sub-layers that *read* it, compute, and *add* back. Attention and the MLP never replace the stream; they only write increments: `x_L = x_0 + Σ_ℓ Δ_attn^(ℓ) + Σ_ℓ Δ_ffn^(ℓ)`. This additive backbone is simultaneously the reason 100-layer models train (an identity gradient path), the reason features compose across layers (early writes are never overwritten), and the reason gradient checkpointing is *cheap*: the checkpoint you store is exactly one snapshot of the stream, `[B, T, h]` = **33.55 MB**, versus the **1.64 GB** of interior tensors it lets you discard — a 49× ratio.

**Guideline.** Think of `h` (`d_model`) as the stream's *bandwidth* and of `s·b·h` as the course's atomic memory unit — every coefficient in the activation formula (`34`, `10`, `24/t`, `2` for full recompute) is counted in multiples of it. When you place a checkpoint, place it on the stream (a block boundary), never inside a sub-layer: the stream is the narrowest point in the block's dataflow, so it is the cheapest possible cut.

## Technical Details

- **The stream formula.** For Pre-LN, `L` layers unroll to
  `x_L = x_0 + Σ_{ℓ=1..L} [ Attn_ℓ(LN(x_{ℓ-1})) + FFN_ℓ(LN(x_{ℓ-1} + Attn_ℓ(LN(x_{ℓ-1})))) ]`.
  The output is the input embedding **plus** the sum of all `2L` sub-layer contributions. Nothing is overwritten; every write persists to the unembedding.
- **Why residual connections exist at all (He et al. 2015).** Deeper plain networks were *worse on the training set* — an optimization failure, not overfitting: SGD struggles to learn the identity through a stack of nonlinearities. Learning the residual `F(x) = H(x) − x` instead makes "do nothing" the easy solution (`F ≈ 0`). Gradient consequence: `∂L/∂x_ℓ = ∂L/∂x_{ℓ+1} · (I + ∂F_{ℓ+1}/∂x_ℓ)` — the `I` is a gradient superhighway. A 96-layer transformer without skips would push gradients through 96 matmuls in series; with skips, layer 1 has a direct additive path from layer 96.
- **Composition depends on persistence: induction heads (Elhage et al. 2021).** Layer `ℓ` runs a "previous-token" head writing "what preceded me" into position `t`'s stream; layer `ℓ+k` runs a pattern-matching head that reads that write to find an earlier position with the same predecessor and copies its successor. This works *only* because the layer-`ℓ` write is still legible `k` layers later. In a pipeline architecture without a shared stream, layers `ℓ+1 … ℓ+k−1` would have destroyed it.
- **The functional bus decomposition:**

| Component | Role | Analogy |
|---|---|---|
| Residual stream | Communication bus | shared memory / data bus |
| Attention heads | Inter-**position** communication | message passing between processors |
| MLP layers | Per-**position** computation | local compute on each processor |
| LayerNorm | Signal conditioning | voltage regulation |
| Unembedding | Final readout | output port |

  Geva et al. (2021): the MLP is a key-value memory — each row of `W_up` is a pattern detector ("key"), the matching column of `W_down` is what gets written to the stream ("value"), and GELU/SiLU sparsifies which patterns fire.
- **The MLP's 4h expansion, in bytes.** `d_ff = 4h` held exactly across the GPT line: GPT-1 `768→3072`, GPT-2 `1600→6400`, GPT-3 `12288→49152`. At the reference config (`B=1, T=4096, h=4096`, bf16), `4h = 16384` and each `[B,T,4h]` tensor is **134.22 MB** — 4× the stream snapshot. The block saves two of them (up-projection output and GELU output) = **268.44 MB**, i.e. **8× the 33.55 MB checkpoint**. The stream is narrow; the MLP briefly widens it 4× and that width is what you pay for.
- **`d_model` = stream bandwidth.** The llm-arch source's framing: a wider stream carries more simultaneous signals without interference, which is why `d_model` grew 512 (2017) → 8192 (Llama-2-70B). Memory-wise this is also why every activation term is linear in `h` while the attention term is *not*: `5as²b` has no `h` in it at all (the `5as/h` form only looks like it does because it is normalized by `sbh`). Widening the stream grows the linear term and leaves the quadratic term untouched.
- **Verified checkpoint arithmetic (reference config, `L=80`):** one stream snapshot `[B,T,h]` = **33,554,432 B = 33.55 MB**; interior tensors discarded per block = **1,644,232,704 B = 1.64 GB**; ratio **49.0×**. Block total = **1.68 GB**, ×80 = **134.22 GB** with no checkpointing → `2·s·b·h·L` = **2,684,354,560 B = 2.68 GB** with per-block checkpointing (**50×**). That `2·s·b·h·L` formula from [[ch-03]] L110 is not an abstraction — it is literally "80 snapshots of the residual stream, 2 bytes an element."
- **Decoder-only means one stream, not two.** Encoder-decoder models have a bidirectional encoder stack, a causal decoder stack, and cross-attention between them — three attention patterns, two activation ledgers, and a cross-attention cache. Decoder-only concatenates prompt and completion into a single causal sequence: one stack, one stream, one attention pattern, one KV cache. The unification argument is that any encoder-decoder task can be rewritten as decoder-only but not the reverse; the *memory* argument is that a single stream makes the activation formula a single `L × (per-layer)` product, which is exactly why `sbh(34 + 5as/h) × L` is a one-line formula at all.
- **The GPT-lineage lesson:** every architecture change from GPT-1 to GPT-3 that mattered was a **stability** fix to the stream, not a capacity fix — pre-norm placement, `1/√N` residual-branch init, batch-size ramp. Capacity came from raw scaling (117M → 175B, 12 → 96 layers, `d_model` 768 → 12288). The 2017 block needed only stability patches to scale 1,500×.
- **Training-memory angle:** The residual stream is why activation memory is `L × per-layer` and not something worse — the stream is a *fixed-width* `[B,T,h]` interface between blocks, so per-block cost never compounds and a checkpoint on the boundary is always exactly `2sbh` bytes. Three practical consequences: (1) gradient checkpointing's whole leverage is the 49:1 ratio between interior tensors and the stream snapshot, which exists only because the block re-narrows to `h` at both ends; (2) the residual `add` itself stores nothing for backward (`∂(x+f)/∂x = I`), so the backbone is byte-free as an *operation* — you pay only for its snapshots; (3) sequence parallelism ([[megatron-tp-sp]]) is possible precisely because the stream is independent across the `T` axis, letting you shard the same `[B,T,h]` tensor by sequence position across a TP group and divide the whole `34 sbh` term by `t`.
