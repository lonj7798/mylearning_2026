# Allen AI Tülu 3: The Next Era in Open Post-Training
- **Core Insight:** Open-source post-training can match or exceed frontier closed models when you (a) build a **persona-driven synthetic prompt factory** for skill-targeted prompts, (b) mix 57% public + 43% in-house synthetic, (c) layer SFT → DPO → RLVR (verifiable rewards).
- **Guideline:** For a modern open post-training recipe, curate ~900K prompts (mix of public sources + persona-driven in-house synthesis), generate responses with GPT-4o / Claude-3.5-Sonnet, apply DPO with both off-policy and on-policy prefs, and finish with RLVR on skills with verifiable correctness (math, precise instruction following, code).
- **Author(s):** Nathan Lambert, Hamish Ivison, Jacob Morrison, Noah A. Smith, Yizhong Wang, Luca Soldaini, et al. (Allen AI)
- **Year:** 2024–2025 (v3 Nov 2024, v3.1 and 405B scaling 2025)
- **URL:** https://allenai.org/blog/tulu-3-technical ; https://allenai.org/blog/tulu-3 ; https://allenai.org/blog/tulu-3-405B
- **Relevant topics:** open post-training, persona-driven synthesis, RLVR, Tülu 3

## Core claim / thesis
Tülu 3 is a fully-open post-training stack: every prompt, response, preference, reward model, and evaluation is disclosed and reproducible. It demonstrates that open recipes can approach (and with 405B scaling, surpass) DeepSeek V3 on instruction-following benchmarks. The central data-engineering move is a **persona-driven synthetic prompt factory**.

## Key moves
- **Persona-driven prompt synthesis:**
  - Sample a persona (e.g., "a machine learning researcher focused on neural networks").
  - Combine with a skill template (e.g., "create a coding problem", "write a math word problem", "write a precise-instruction-following task").
  - Feed to GPT-4o / Claude-3.5 as prompt generator.
  - Targeted skills: precise instruction following, math, coding.
- **Prompt corpus:**
  - 939,344 prompts total.
  - 57% from public sources (WildChat, OpenMathInstruct, NoRobots, etc.).
  - 43% in-house synthetic.
- **Response generation:** GPT-4o for general; Claude-3.5-Sonnet for coding (best-in-class code response quality).
- **SFT mix:** curated from the prompt pool + responses (see [[tulu-3-sft-mix]]).
- **Preference (DPO):** both off-policy and on-policy preference pairs; on-policy pairs generated by sampling from the SFT-trained Tülu itself and labeling with a preference model.
- **RLVR (Reinforcement Learning with Verifiable Rewards):** for math, precise instruction following, and other skills with objective checkers — the reward is exact-match / format-compliance / test-case pass, not a learned RM. See [[rlvr-tulu3]].

## Training results
- Tülu-3-70B matches Llama-3.1-70B-Instruct and exceeds it on several instruction benchmarks.
- Tülu-3-405B (2025 blog) surpasses DeepSeek-V3 on several instruction-following measures — first open recipe to do so at scale.
- Every dataset, reward model, and checkpoint is open.

## Practitioner takeaways
- Persona-conditioning is used *inside* the prompt-generation pipeline, not just the response side — diversifies *what* gets asked.
- Public + synthetic mix is explicitly split 57/43; that ratio is treated as a tunable knob.
- RLVR-only-on-verifiable-skills is deliberate; "helpfulness" / "writing" still trained with DPO against learned RM.
- The SFT + DPO + RLVR ordering is the current 2025 open-post-training template.

## Risks + gotchas
- **GPT-4o / Claude-3.5 license contamination** for derivative models — Tülu data is released but downstream commercial use should verify.
- **RM-collapse risk in on-policy DPO** — mitigated by periodic mix with off-policy pairs.
- **Benchmark overfitting** in RLVR — explicit care taken to hold out IFEval / GSM8K / MATH evaluations from training prompts.
