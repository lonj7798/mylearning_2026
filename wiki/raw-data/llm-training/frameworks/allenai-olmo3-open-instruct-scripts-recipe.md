## Starting point for a small general-purpose run
Every number below is a verified row above. For 7B-scale DPO on an SFT checkpoint, the Olmo 3 scripts use `dpo_norm` with β = 5, one epoch, warmup ratio 0.1, linear decay, batch 128 pairs and LR 1e-6 (Instruct, 260,000 pairs, 16,384 tokens) or 8e-8 (Think, 150,000 pairs); the paper reports sweeping LR and dataset size for each model. For 7B-scale RLVR, the scripts use β = 0.0, 64 prompts × 8 samples, LR 1e-6 constant, temperature 1.0, clip range 0.2 / 0.272, and a response length matched to the model type (8,192 Instruct, 32,768 Think, 16,384 RL-Zero), on 8–16 learner GPUs with 32–56 vLLM engines.

## Verification
- Created on 2026-09-14 from the scripts at open-instruct d8a7f1c, 00d42c4 and commit 7917d41, and arXiv:2512.13961v2 App. A.6 Tables 47–49.
- CHANGELOG entry of 7917d41 lists `clip_higher=0.28`, `truncated_importance_sampling_ratio_cap=10.0` and `advantage_normalization_type=mean_std`; the code diff in the same commit sets 0.272, 2.0 and "centered". The rows use the code values.
- Not reported in the scripts: DPO optimizer betas and gradient clipping, RL training step counts (Table 49 prints 1,400 / 750 / 450 / 2,000), and the rejected-response generation method for the delta-learning DPO mixes.
