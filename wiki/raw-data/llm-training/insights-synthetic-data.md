# Insights — Synthetic data

- The library separates three regimes that share a name but not a method: synthetic pretraining corpora ([[phi-textbooks]], [[phi-1-5]], [[rephrasing-the-web]], [[hf-cosmopedia]]), synthetic post-training prompts and responses ([[magpie]], [[persona-hub]], [[tulu-3-sft-mix]], [[nemotron-4-synthetic]]), and synthetic reasoning traces ([[openmathinstruct]], [[open-thoughts]], [[s1]], [[limo]], [[sky-t1]]). Numbers do not transfer between them.
- Rewriting existing text raises measured pretraining efficiency. Pre-training a 1.3B model on C4 plus Mistral-7B-Instruct rephrases sampled 1:1 speeds up pre-training by about 3x and improves the average of 13 zero-shot tasks ([[rephrasing-the-web]]); a 1.3B model trained on under 7B tokens of filtered code plus generated textbooks reaches competitive HumanEval scores ([[phi-textbooks]], [[phi-1-5]]); Cosmopedia generates over 30M files and 25B tokens with under 1% duplicate content, and its authors state most project time went to prompt design ([[hf-cosmopedia]]).
- Prompt-side conditioning is the measured source of diversity. Adding a persona to the synthesis prompt changes what is produced, and 1.07M persona-conditioned math problems with no MATH instances used give a fine-tuned Qwen2-7B a large MATH gain ([[persona-hub]]); giving an aligned model only the pre-query part of its chat template makes it emit user instructions, and SFT of Llama-3-8B-Base on 300K filtered Magpie-Pro conversations is competitive with the official instruct model ([[magpie]]); a 126-discipline taxonomy generates 10M pairs without benchmark training sets ([[glan]]); 28 per-task instructor modules with random topics and near-duplicate rejection is the same idea in an open pipeline ([[airoboros]]).
- Selection pressure on synthetic data changes results more than sample count. 6K DEITA-selected samples score 7.22 on MT-Bench against 5.89 for 10K random samples ([[deita]]); the 9,229 Alpaca examples rated ≥ 4.5 by ChatGPT beat the full 52,002 ([[alpagasus]]); IFD computed by a 124M GPT-2 ranks samples consistently with LLaMA2-7B (Spearman ρ 0.679-0.802) ([[superfiltering]], [[ifd]], [[cherry-llm]]); gradient-entropy diversity reaches Spearman ρ ≈ 0.90 with post-training accuracy over 300+ controlled runs ([[prismatic-synthesis]], [[less]], [[instag]]). **Replicated** across six independent selection methods.
- Synthetic data gains value when an external correctness signal exists. Toolformer keeps only API calls whose result lowers cross-entropy on following tokens by at least τ_f ([[toolformer]]); APIGen passes each sample through format, execution, and semantic checks and a 7B model trained on the result ranked 6th on BFCL at 85.65 ([[apigen]], [[apigen-mt]], [[toolace]]); rejection-sampling fine-tuning keeps only paths with correct answers and correct intermediate calculations ([[rejection-sampling-finetuning]]).
- Recursive training on self-generated data has a measured failure mode and a measured counterweight. Low-probability events disappear first and fitted variance shrinks when each generation trains on the previous generation's samples ([[model-collapse]], [[strong-model-collapse]]); rephrased synthetic data scales without collapse signals in the runs of [[synthetic-data-scaling-laws]]. The practice visible in [[tulu-3-sft-mix]], [[nemotron-4-synthetic]], and [[deepseek-r1-distill-synth]] is to anchor synthetic data with a stronger teacher, public corpora, or executable verifiers rather than train on unfiltered self-output.
