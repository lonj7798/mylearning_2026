# Qwen Long-Context Data Pipeline (Qwen 2.5-1M and Qwen 3)
- **Core Insight:** Qwen 2.5-1M and Qwen 3 push effective context to 1M tokens via (a) **dual-chunk attention (DCA)** at inference for training-free length extrapolation, (b) **length-upsampled continued pretraining** on 256K-token contexts with code + book + synthetic long tasks, and (c) a **synthetic long-task SFT mix** heavy on multi-needle retrieval, long-doc summarization, and RAG-style multi-passage QA — with the training context capped at 256K while inference supports 1M through DCA.
- **Guideline:** For ultra-long (1M+) context, train at a reasonable cap (256K) and use inference-time attention modifications (dual-chunk or YaRN-like) for extrapolation; synthesize multi-needle retrieval at training context length to explicitly teach retrieval skill.
- **Authors:** Qwen Team (Alibaba DAMO)
- **Year:** 2025
- **URL:** https://arxiv.org/abs/2501.15383 (Qwen2.5-1M) ; https://qwenlm.github.io/blog/qwen2.5-1m/ ; Qwen 3 technical report
- **Relevant topics:** Qwen 2.5-1M, Qwen 3 long-context, dual-chunk attention, synthetic long tasks

## Abstract
The Qwen 2.5-1M report (Jan 2025) documents how Qwen's team trained Qwen-2.5-7B/14B-1M to support 1M-token inference context despite training context capped at 256K. The pipeline has three legs: (1) gradual long-context continued pretraining 32K → 128K → 256K with length-upsampled real long documents; (2) long-context SFT with synthetic multi-needle, summarization, RAG-QA, and code-repo tasks generated by Qwen-Max; (3) Dual-Chunk Attention at inference for length extrapolation from 256K training to 1M inference. Qwen 3 (2025) reuses and refines this recipe within its hybrid-thinking training.

## Key Contributions
- **Dual-Chunk Attention (DCA)** — inference-time attention trick splitting long queries into chunks with intra- and inter-chunk attention, enabling 4× extrapolation from training context.
- **Synthetic long-task SFT mix** — multi-needle, summarization, RAG, and FILL-IN tasks generated by Qwen-Max.
- Open Qwen-2.5-7B-1M, Qwen-2.5-14B-1M weights.
- First open model family supporting 1M context with real retrieval quality.

## Synthesis pipeline (REQUIRED — concrete, modality-specific)

### Continued pretraining (three gradual-extension stages)
- **Stage 1 — 32K:** continued pretraining on general long docs, ~50B tokens.
- **Stage 2 — 128K:** code-repo heavy mix, ~50B tokens.
- **Stage 3 — 256K:** document concatenation across topics, synthetic multi-topic mixed-context, ~100B tokens.
- **Per-stage document mix:**
  - Code repositories concatenated in dependency order.
  - Books concatenated chapter-wise.
  - Academic papers + citation-linked follow-ups.
  - Synthetic multi-document cluster: related web docs bundled.

### Long-context SFT
- **Synthetic task mix:**
  - **Multi-needle retrieval:** 1–8 needles injected at varied positions, retrieved on demand.
  - **Long-doc summarization:** 50K–200K doc → summary.
  - **RAG-QA:** 5–20 candidate passages, answer requires cross-passage fusion.
  - **Long-code understanding:** code-repo + question about cross-file dependencies.
  - **FILL-IN:** document with masked segment to reconstruct.
- **SFT data generation:** Qwen-Max (2.5) or Qwen-3-Max serves as teacher, generating gold answers with full document in context.
- **Filter:** answer must reference multiple positions of the source document (to avoid shortcut learning).
- **Output shape:** hundreds of thousands of long-context SFT pairs; training length capped at 256K.

### Dual-Chunk Attention at inference
- Split long queries into chunks of training-size (256K); within-chunk attention is standard; between-chunk uses a special low-rank formulation that extrapolates RoPE smoothly.
- Enables 1M-token context serving without retraining.
- **Teacher model(s):** Qwen-Max (internal).
- **Cost:** not disclosed.

## Modality-specific technical details (REQUIRED — long-context)
- **Token-range:** 32K → 256K (training), 1M (inference via DCA).
- **Needle-retrieval difficulty:** explicitly trained via multi-needle; Qwen-2.5-14B-1M achieves ~100% on NIAH 1M, ~85% on RULER 1M.
- **Document-type mix:** code ~35%, books ~25%, academic ~15%, multi-doc bundles ~15%, synthetic ~10%.
- **Packing strategy:** cross-document attention mask + multi-topic document bundles to create realistic long-context "conversations".
- **Position-encoding adaptation:** Qwen uses YaRN for base extension during training; DCA at inference.
- **Per-stage data mix:** as above; synthetic synthetic long-task fraction grows stage by stage.

## Quality / diversity evaluation
- Qwen-2.5-14B-1M: NIAH 1M ~100%, RULER 1M ~85%, InfiniteBench strong.
- Qwen 3 family inherits recipe with further improvements via hybrid-thinking pipeline.
- Short-context quality preserved — MMLU / GSM8K within 1 point of base Qwen-2.5.
- Outperforms Llama-3.1-70B-128K at equivalent eval length.

## Risks + gotchas
- **DCA is inference-only:** generalization from 256K training to 1M inference works for retrieval-style tasks but degrades on true long-range reasoning.
- **Synthetic-needle dominance:** risk of training overly retrieval-oriented — Qwen team balances with summarization/RAG tasks.
- **Closed training data:** specific synthetic-task distribution not released.
- **Alibaba-internal tooling:** Qwen-Max teacher and DCA implementation not fully open.
