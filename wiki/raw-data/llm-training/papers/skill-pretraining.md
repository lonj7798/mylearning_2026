# SPT: Skills as Pre-Training Data for Agentic Language Models
- **Core Insight:** Across 1.6B, 3B, and 7B backbones and two SFT recipes, mid-training on 347,770,880 tokens of public skill packages raised the four-benchmark agentic average by 9.11–24.96 points over direct SFT, while the six-benchmark general average changed by −0.85 to +0.51 (Main Results, Table 1).
- **Guideline:** When adding tool-use documents to a mid-training mix for a small model, combine them with general annealing data at 20–50% skill share instead of training on skill data alone, because at 1.6B with Tulu 3 SFT a 30% share gave agentic 38.60 (with Dolmino) and 37.58 (with SmolLM) versus 22.06 for pure skill data and 15.56 / 9.07 for general-only data (Mixing Skill and General Data; Table 12). This sweep used one backbone, one SFT recipe, and 5 seeds.
- **Authors:** Yufei Sun, Yudong Li, Yiming Cheng (Beijing University of Posts and Telecommunications; Tsinghua University)
- **Year:** 2026 (arXiv v1 2026-08-27)
- **URL:** https://arxiv.org/abs/2608.26563
- **Source type:** paper
- **Relevant topics:** mid-training, agentic and tool-use data, data mixture, multi-file document serialization, decontamination, general-capability retention, SFT-then-RL robustness

## Abstract
Tool-using models are mainly trained on tool-call traces and agent trajectories during post-training; these need task environments, execution, and verification, so coverage is expensive. Public skills (reusable, human-written instructions for AI agents) encode tool semantics and workflows but are normally used only as inference-time context. The authors introduce Skill Pre-Training (SPT), a mid-training method that applies causal language modeling to SkillCorpus, a collection of public multi-file skill packages, optionally mixed with general data. Reference Insert places supporting files near their mentions in the primary instruction file. Across model scales and post-training recipes, SPT improves agentic performance over mid-training on general or trajectory data while largely preserving general performance, and mixtures with general annealing corpora add further gains.

## Key Contributions
- SkillCorpus: 38,040 cleaned and decontaminated ClawHub packages, 218,277 files (SkillCorpus Construction).
- SPT: unchanged causal-LM objective on skill data before post-training; no environments, tool execution, or synthetic trajectories (Skill Pre-Training).
- Reference Insert, a reference-aware package serialization, with an ablation against four alternatives (Multi-File Skill Assembly; Table 2).
- Equal-token corpus comparisons (general, trajectory, skill) on three backbones × two SFT recipes, a mixture-ratio sweep, and an SFT→GRPO test (Tables 1, 3; Fig. 4).

## Technical Details
**Terms.** Mid-training is continued training of a pre-trained checkpoint on curated or domain-weighted data before post-training (Related Work). A skill package pairs a primary instruction file, typically SKILL.md, with optional references, scripts, templates, and configuration files (SkillCorpus Construction).

**SkillCorpus**
- Skills on npm grew from 170,226 (February 2026) to 1,640,440 (June 2026), 9.6× (Introduction; Fig. 1a). This npm count is motivation only; SkillCorpus comes from a May 1, 2026 ClawHub snapshot of trusted, identity-verified, independently audited publishers (SkillCorpus Construction; Table 4).
- An iterative, manual-audit-derived heuristic screen (semantic dedup, near-duplicate and autogenerated detection, erroneous workflows, quality tiers) removes about 2% of packages (App. Filtering and cleaning).
- File-level cleaning removes 818 lock files, 170 encoded blobs, and 256 data URIs and applies 23,973 secret redactions; a 100k-character package budget keeps sections by priority (SKILL.md, README, other text, configs, scripts) and removes 25,632 sections from 1,893 packages; packages under 40 characters are dropped (App.).
- Decontamination: manual audit plus DeepSeek-V4-Flash judgments against API-Bank, MetaTool, APTBench, ToolEyes, and six OLMES tasks; a whole package is removed if any file contains benchmark schemas, templates, or rewritten variants, about 0.3% of candidates (App. Training-corpus benchmark decontamination).
- Exact 13-gram diagnostic before removal: 1.24B-character pool; 163 unique benchmark 13-grams matched; instances with a match: MetaTool 13 of 6,214, APTBench 66 of 3,561, ToolEyes 40 of 1,121, MMLU 8 of 28,084, all other tasks 0 (Table 8).
- Composition by package share: code/software 35.96%, other 29.26%, web/search/browser 9.39%, automation/workflow 7.34% (Table 6). Script share: Latin 93.75%, CJK 6.25% (Table 7).

**Reference Insert (Multi-File Skill Assembly; App. Reference resolution rule)**
1. Write a package header with name and description.
2. Scan SKILL.md line by line; after a line with an unambiguous reference to a supporting file, insert `<referenced_file_sep>` and that file. Each file is inserted once, at its first mention.
3. Append remaining files with `<unreferenced_file_sep>`; end the package with a separator; pack the stream into 4,096-token blocks.
- Output: 84,905 blocks, about 347.8M tokens. 70,655 referenced files are resolved across 17,957 packages; the mean distance from the referring line to the file content falls from 14,518.996 to 737.189 MeCo tokens (94.92%) (App.).

**Mixture (Eq. 1).** p_α(x) = α·p_skill(x) + (1 − α)·p_gen(x), with |D_α|_tok = B and 0 ≤ α ≤ 1. p_skill and p_gen are the empirical distributions over skill and general blocks, B is the fixed mid-training token budget, and α is the skill fraction; α = 1 is pure-skill SPT, α = 0 is the general-data control (Skill and General Data Mixture).

**Setup (Experimental Setup; App. Evaluation Protocols)**
- Backbones: MeCo-1.6B-DCLM-160B, Instella-3B-Stage1, OLMo-3-1025-7B (stage1-step999000), all after one general pre-training stage with no annealing or post-training. Mid-training conditions at equal tokens: Dolmino (general), AgentBank (trajectories), SkillCorpus; plus direct SFT. SFT: Tulu 3 or xLAM-FC. Results are means over 5 seeds. Hyperparameters: see Recipe ledger.
- Agentic: API-Bank (3 levels, execution-based), MetaTool (4 tool-selection subtasks), APTBench (SWE and deep-research tasks, 3-shot), ToolEyes (5-shot ReAct, ≤ 9 turns, T = 0.3, top-p 0.5; GPT-4 judge replaced by DeepSeek-V4-Flash, 97.2% agreement with humans on 300 samples). General: ARC-C, BoolQ, HellaSwag, PIQA, WinoGrande, MMLU under OLMES 5-shot.

**Results**
- SkillCorpus has the best agentic average in all 6 backbone × SFT blocks and ranks first in 23 of 24 per-benchmark comparisons; the exception is 1.6B + Tulu 3 ToolEyes (AgentBank 26.96 vs 26.39) (Main Results; Table 1).
- Ordering Dolmino < AgentBank < SkillCorpus holds in all six blocks. Dolmino adds 2.62–4.83 over direct SFT; SkillCorpus adds 6.49–20.13 over Dolmino and 4.07–9.91 over AgentBank (Main Results).
- 7B + xLAM-FC agentic average: none 28.50, Dolmino 33.33, AgentBank 44.05, SkillCorpus 53.46; general 75.31 / 75.16 / 74.38 / 75.07 (Table 1).
- Gain over direct SFT, xLAM-FC vs Tulu 3: 11.55 vs 9.11 (1.6B), 16.99 vs 13.28 (3B), 24.96 vs 19.33 (7B) (Main Results).
- Mixture sweep (1.6B, Tulu 3; ratios 0, 1, 5, 10, 20, 30, 50, 70, 90, 100% skill): 30% is best with both general sources; general score at 30% is 58.64 (Dolmino) and 58.83 (SmolLM) vs 59.29 / 59.26 general-only; 20–50% beats both endpoints; above 50% the agentic score falls (Mixing Skill and General Data; Tables 12–13).
- Serialization (1.6B, Tulu 3): Reference Insert 22.06, DeepSeek-Coder packing 20.19, Skill-FIM 17.98, Metadata 16.50, Random File 16.09; general 58.20 vs 57.30–57.35. Reference Insert and Random File contain the same tokens, so the 5.96 gap comes from file order (Table 2).
- SFT→GRPO (SmolLM2-360M; math and instruction-following RLVR data, no tool-use supervision): agentic 11.94 (SkillCorpus), 7.25 (Dolmino), 4.95 (none); general 41.49 / 40.96 / 40.10 (Table 3).

## Findings relevant to generality and agentic training
- General retention (Result, single study): the largest general-average drop is Instella-3B + xLAM-FC, SkillCorpus 71.43 vs 72.28 without mid-training (MMLU 51.62 vs 54.06). In the same block, trajectory mid-training (AgentBank) gives MMLU 50.10 and general 70.34, versus 54.22 and 72.05 for Dolmino (Table 1). At 1.6B + Tulu 3, pure SkillCorpus gives general 58.20 vs 59.29 for Dolmino (Table 1).
- Interpretation (authors): general data "contributes more than retention"; its coverage helps skill workflows transfer to varied agentic tasks, since pure skill data scores below all 20–50% mixtures (Mixing Skill and General Data).
- Interpretation (authors): skills state tool applicability, constraints, and procedures explicitly, while trajectories record one execution, which may explain better transfer than AgentBank (Main Results).
- Limits stated by the authors: one source repository (ClawHub); English and Chinese only; 1.6B–7B backbones plus a 360M RL study; larger models and other compute regimes untested; no separate measurement of tool-selection, argument, error-recovery, or unsafe-action failures; no interactive long-horizon evaluation (Limitations).
- Artifacts: code, configs, and checkpoints are announced for future release (Artifact Availability).
