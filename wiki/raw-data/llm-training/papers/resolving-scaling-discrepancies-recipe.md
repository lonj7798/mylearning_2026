## Starting point for a small general-purpose run
For decoder-only models between 5M and 901M parameters trained near 20 tokens per parameter on RefinedWeb, the verified rows give: warmup tokens equal to N; AdamW with β1 = 0.9, independent weight decay 1e−4 and z-loss 1e−4; learning rate and batch size from Table 4 for the nearest size; β2 = 0.99 for Table 4 batch sizes of 192 or less and 0.95 for larger ones (Table 4); sequence length 2048. Table 4 does not state the batch unit; with Table 3 batch 256 equal to 2^19 tokens (§3.1) and sequence length 2048, the unit is sequences (derived: 256 × 2048 = 2^19). The source validated the LR and batch prescription only up to 901M parameters and about 14B tokens (App. G.5). The source does not test these values for longer training, other data mixtures, or post-training.
