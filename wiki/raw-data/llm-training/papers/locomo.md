# Evaluating Very Long-Term Conversational Memory of LLM Agents
- **Core Insight:** On LoCoMo QA, humans score 87.9 F1 while the best RAG setting (gpt-3.5-turbo-16k reading the top-5 retrieved observations) scores 41.4 and the 16K long-context model scores 37.8 overall but only 2.1 F1 on adversarial (unanswerable) questions (Table 2; Table 3).
- **Guideline:** When evaluating memory over long conversations, report adversarial or unanswerable questions separately from answerable ones, because the 16K-context model gains overall F1 over the 4K model (37.8 vs 22.4) while its adversarial F1 falls from 12.8 to 2.1 (Table 2).

- **Year:** 2024 (arXiv v1 2024-02; ACL 2024 per the GitHub README)
- **URL:** https://arxiv.org/abs/2402.17753
- **Source type:** paper
- **Relevant topics:** long-term conversational memory, synthetic multi-session dialogue, long-context evaluation, retrieval-augmented generation, temporal reasoning, abstention, human-edited synthetic data

## Abstract
Earlier long-term open-domain dialogue work evaluates responses over at most five chat sessions. The authors build a machine-human pipeline: two LLM agents with personas and temporal event graphs converse over many sessions, can share and react to images, and human annotators then edit the output for long-range consistency and grounding to the event graphs. The resulting LoCoMo dataset has conversations of 300 turns and 9K tokens on average, over up to 35 sessions. The benchmark has three tasks: question answering, event summarization, and multimodal dialogue generation. Experiments show that LLMs have difficulty with long conversations and with long-range temporal and causal dynamics; long-context LLMs and RAG improve results but stay below human performance.

## Key Contributions
- A generation pipeline combining MSC personas, per-speaker temporal event graphs, and a reflect-and-respond agent with short- and long-term memory (§3.1-3.3).
- A human verification step that edits long-range inconsistencies and image mismatches (§3.4; App. A.3).
- A 50-conversation dataset with 7,512 QA items in five reasoning categories, event-summary ground truth, and images (Table 5).
- A comparison of truncated-context base LLMs, a long-context LLM, and RAG over three retrieval databases (dialogs, observations, session summaries) (§5; Tables 2-4).
- The GitHub release keeps 10 of the 50 conversations as `data/locomo10.json`, with QA evidence dialog ids, observations and summaries, and scripts to generate new conversations (GitHub README).

## Technical Details
### Generation pipeline
- Two agents built on gpt-3.5-turbo (§3). Personas: a 4-5 sentence MSC persona is expanded by gpt-3.5-turbo into a full persona statement with one in-context example (§3.1; App. A.1).
- Temporal event graph per agent: generated by text-davinci-003, up to 25 events over 6 to 12 months, with causal `caused_by` links whose causes must have earlier dates. Events are generated iteratively in batches of k = 3, each batch conditioned on earlier events (§3.2; App. A.2, Fig. 6).
- Short-term memory: after session k, a summary w_k conditioned on the session history and the previous summary. Long-term memory: each turn is converted to an observation (an assertion about a speaker) tagged with the turn ids that support it (§3.3; App. A.2.1, Figs. 8-9).
- A response in session k+1 is conditioned on the latest summary, retrieved observations, the current session, the persona, and the graph events dated between the two sessions (§3.3).
- Image sharing: caption → keywords → web image search (icrawler). Image reaction: the received image is captioned with BLIP-2 and the agent responds (§3.3; fns. 3-4).
- Human editing: annotators edited nearly 15% of dialog turns and removed or substituted about 19% of images; they also removed graph events that do not appear in the conversation (§3.4; App. A.3).

### Dataset statistics (Table 5; Table 1)
- 50 conversations; 19.3 sessions, 15.8 turns per session, 304.9 turns and 9,209.2 tokens per conversation on average; 32.3 images per conversation.
- QA: 7,512 questions — single-hop 2,705 (36%), multi-hop 1,104 (14.6%), temporal 1,547 (20.6%), open-domain knowledge 285 (3.9%), adversarial 1,871 (24.9%).
- Event summarization: 24.2 ground-truth events and 896.5 tokens per event summary on average.
- License: CC BY-NC 4.0 (App. B.2). Annotators were in-house (App. B.3).

### Evaluation setup
- QA metric: partial-match F1 after normalization; answers are taken from conversation wording where possible; each QA item lists evidence turn ids, used to report retrieval recall@k (§4.1).
- Event summarization: FactScore precision, recall and F1 of atomic facts against the event graph, plus ROUGE (§4.2). Models summarize incrementally, session by session; RAG is not used (§5).
- Images are replaced by BLIP-2 captions for QA and summarization (§5). Retriever DRAGON, reader gpt-3.5-turbo-16k (§5). Temperature 0, top-p 1, single inference run, OpenAI API and Hugging Face as of January 2024 (App. C.2).

### Results
- QA overall F1: Mistral-Instruct-7B 13.9; Llama-2-Chat-70B 17.9; gpt-3.5-turbo 22.4; gpt-4-turbo 32.1; gpt-3.5-turbo-16k at 4K / 8K / 12K / 16K: 24.1 / 25.2 / 33.5 / 37.8; human 87.9 (Table 2). The §6.1 prose gives 32.4 for gpt-4-turbo.
- Adversarial F1: gpt-4-turbo (4K) 70.2; Llama-2-Chat-70B 22.1; gpt-3.5-turbo-16k falls from 13.1 at 4K to 2.1 at 16K (Table 2).
- RAG, observations top-5: overall 41.4, temporal 41.9, adversarial 44.7; dialog top-25: overall 35.8 with recall@25 of 79.9; summaries top-10: overall 31.5 despite recall 90.7 (Table 3). The authors attribute the summary result to information loss in summarization (§6.1).
- Event summarization FactScore F1: gpt-3.5-turbo 45.9, gpt-4-turbo 45.1, gpt-3.5-turbo-16k 39.9; the 16K model loses 3.0 precision and 8.7 recall versus the 4K model (Table 4; §6.2).
- Multimodal generation (MiniGPT-5): MM-Relevance 56.1 for Base and 57.8 with top-5 retrieved observations; MM-Relevance drops as dialog history length grows (App. Table 6; Fig. 4B).

## Findings relevant to generality, negative feedback, long context, and synthetic data
- **Longer input raises hallucination on unanswerable questions.** Increasing gpt-3.5-turbo-16k context from 4K to 16K raises overall QA F1 (24.1 → 37.8) and lowers adversarial F1 (13.1 → 2.1); the authors report long-context models misassign dialogs or events to the wrong speaker (§1; Table 2). Result (single study).
- **Long context does not improve event summarization.** The 16K model is below the 4K model on FactScore F1 (39.9 vs 45.9) (Table 4). Result (single study).
- **Retrieval unit matters.** Observations (short speaker assertions) outperform raw dialog turns at top-5 (41.4 vs 31.7 F1), and F1 declines as more observations are retrieved (38.8 at top-10, 37.8 at top-50) (Table 3). The authors interpret this as a signal-to-noise effect (§6.1). Interpretation.
- **Negatives in the benchmark.** Adversarial questions (24.9% of QA) are designed to be unanswerable; the expected output is to identify them as unanswerable (§4.1; Table 5). These are evaluation items; the paper does not train on them.
- **Synthetic-data construction and quality control.** Generator: gpt-3.5-turbo agents with text-davinci-003 event graphs; quality control: human edits to about 15% of turns and 19% of images (§3; §3.4). The authors state the data may not reflect real-world online conversations, images lack personal-photo visual consistency, and the pipeline is English only (§8).
- **Measurement error.** The authors note LLMs produce verbose or paraphrased answers, which complicates F1-based scoring (§4.1; §8).
