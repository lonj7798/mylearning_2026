# MAmmoTH: Building Math Generalist Models through Hybrid Instruction Tuning
- **Core Insight:** Fine-tuning on a deliberately mixed corpus of Chain-of-Thought (text reasoning) and Program-of-Thought (Python code reasoning) outperforms either alone; the two trace styles cover complementary error modes — CoT for conceptual steps, PoT for arithmetic/symbolic precision.
- **Guideline:** For math SFT, construct roughly 70/30 or 60/40 mix of PoT/CoT samples, generated by a strong teacher (GPT-4), with source problems drawn from 14+ datasets for diversity; use Python-execution filtering on the PoT subset.
- **Authors:** Xiang Yue, Xingwei Qu, Ge Zhang, Yao Fu, Wenhao Huang, Huan Sun, Yu Su, Wenhu Chen
- **Year:** 2023
- **URL:** https://arxiv.org/abs/2309.05653
- **Relevant topics:** math reasoning, hybrid CoT/PoT, instruction tuning, tool-augmented reasoning

## Abstract
MAmmoTH introduces **MathInstruct**, a 260K-sample math instruction dataset covering grade school to competition level, deliberately mixing CoT and PoT rationales. Models trained on MathInstruct (MAmmoTH-7B/13B/70B, Mistral, Llama-2 variants) establish new open-source SOTA on 9 math benchmarks at release (2023), with particularly strong gains on tasks requiring exact arithmetic (PoT helps) and conceptual reasoning (CoT helps).

## Key Contributions
- **MathInstruct 260K** dataset — first large-scale hybrid CoT+PoT math SFT set.
- Systematic ablation of CoT-only vs PoT-only vs hybrid → hybrid wins across difficulty levels.
- Model family MAmmoTH-7B/13B/70B with consistent gains.
- 14-source problem pool covering GSM8K, MATH, AQuA, Numerical, TheoremQA, etc.

## Synthesis pipeline (REQUIRED — concrete, modality-specific)
- **Seed input:** problems from 14 datasets: GSM8K, GSM8K-RFT, AQuA-RAT, MATH, TheoremQA, MathQA, NumGLUE, simuleq, asdiv, mawps, scienceQA, ApEdi (arith), camel-math, college-math — ~260K problems total.
- **CoT generation:** for problems lacking quality CoT, prompt GPT-4 with the problem and 2-shot CoT examples; accept solutions that match gold answer.
- **PoT generation:** prompt GPT-4 with the problem asking for a Python program that prints the answer; execute the program in a sandbox; accept if stdout matches gold.
- **Filtering:**
  - CoT: final-answer exact-match (numeric) or symbolic equivalence (MATH).
  - PoT: program must execute without error AND produce the correct printed answer.
- **Mixing strategy:** per-problem type — numerical / arithmetic-heavy get more PoT, conceptual / proof-like get more CoT. Overall ratio PoT:CoT ≈ 57:43.
- **Output shape:** 260K samples. CoT traces ~200–600 tokens; PoT traces ~100–400 tokens including code.
- **Teacher model:** GPT-4 (original 2023 model).
- **Cost / compute:** not disclosed; estimated ~$30–50K in GPT-4 API.

## Modality-specific technical details (REQUIRED — reasoning-trace)
- **Reasoning length distribution:** CoT 200–600 tokens, PoT 100–400 tokens. Short CoT style (not long-CoT).
- **Trace style:** dual — CoT uses natural-language reasoning; PoT uses `def solution():` Python template executed to produce the answer.
- **Correctness verifier:** final-answer match (CoT) OR program-output match (PoT).
- **Hybrid rationale:** CoT helps on questions where the reasoning is the hard part (conceptual, proof-like); PoT helps on questions where the arithmetic/symbolic manipulation is the hard part (long calculations).
- **PoT template example:**
  ```
  def solution():
      # Mary has 3 apples and buys 5 more.
      total = 3 + 5
      return total
  print(solution())
  ```

## Quality / diversity evaluation
- MAmmoTH-7B: GSM8K 53.6, MATH 31.5 — vs baseline LLaMA2-7B 14.6 / 2.5.
- MAmmoTH-70B: GSM8K 76.9, MATH 41.8 — SOTA open 2023.
- Ablation: CoT-only drops MATH by 8 points; PoT-only drops MATH by 4 but drops AQuA (logic) by 15.
- Generalization: trained model achieves non-trivial transfer to TheoremQA (theorem-level QA not seen in training).

## Risks + gotchas
- **GPT-4 teacher ceiling + licensing:** data inherits GPT-4 biases and OpenAI's ToS constraints on using outputs for competing models.
- **PoT exploits for wrong reasons:** programs that coincidentally print the right answer via shortcuts (e.g., `return 42`) are accepted by the filter.
- **Short-CoT limitation:** MathInstruct CoTs are ~300 tokens — insufficient for long-CoT distillation to teach reflection/backtracking.
