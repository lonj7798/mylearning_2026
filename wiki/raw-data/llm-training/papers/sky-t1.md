# Sky-T1: Train your own O1 preview model within $450
- **Core Insight:** Supervised fine-tuning of Qwen2.5-32B-Instruct on 17K reasoning traces distilled from QwQ-32B-Preview produced a model scoring 82.4 on Math500 and 43.3 on AIME2024, above the o1-preview scores of 81.4 and 40.0 reported in the same table, for 19 hours on 8 H100 GPUs, about $450 at Lambda Cloud pricing (Training; Evaluation and Results).
- **Guideline:** When distilling long chain-of-thought from an open-weights teacher, reformat the teacher's raw traces before training and mix math with code rather than training on one domain, because unformatted APPs responses parsed at about 25% accuracy versus above 90% after reformatting (Data Curation Process), and because adding APPs code data to a math-only mixture dropped AIME2024 from 43.3 to 36.7 until harder NuminaMath and TACO data were added back (Other findings).

## Summary
The post introduces Sky-T1-32B-Preview, a 32B reasoning model fine-tuned from Qwen2.5-32B-Instruct on 17K reasoning traces generated by QwQ-32B-Preview. The stated motivation is that o1-class models publish neither technical details nor weights (Overview). The team released the data, the training and evaluation code, a technical report with a wandb log, and the model weights (Fully Open-source). The reported training cost is under $450 (introduction). The post reports results on Math500, AIME2024, three LiveCodeBench splits, and GPQA-Diamond, and two negative-to-positive findings about model size and data mixture (Other findings).

## Technical Details
- Teacher: QwQ-32B-Preview, described as having reasoning capability comparable to o1-preview (Data Curation Process). Sampling parameters for trace generation are not reported.
- Rejection sampling: math traces are checked by exact match against the dataset's ground-truth solutions; code traces are checked by executing the unit tests shipped with the dataset; incorrect samples are discarded (Rejection Sampling).
- Final mixture: 5K coding from APPs and TACO, 10K math from the AIME, MATH, and Olympiads subsets of NuminaMath, and 1K science and puzzle data from STILL-2 (Rejection Sampling). The post's title figure and dataset name call the total 17K.
- Reformatting: QwQ traces are rewritten by GPT-4o-mini into a well-formatted version, an approach the post attributes to STILL-2. On APPs, assuming the code is in the last block gives QwQ about 25% accuracy; after reformatting, accuracy is above 90% (Data Curation Process). This is a parsing measurement, not a trained-model score.
- Student: Qwen2.5-32B-Instruct, described as an open-source model without reasoning capabilities (Training).
- Results, Sky-T1-32B-Preview versus Qwen2.5-32B-Instruct / QwQ / o1-preview (Evaluation and Results): Math500 82.4 / 76.2 / 85.4 / 81.4; AIME2024 43.3 / 16.7 / 50.0 / 40.0; LiveCodeBench-Easy 86.3 / 84.6 / 90.7 / 92.9; LiveCodeBench-Medium 56.8 / 40.8 / 56.3 / 54.9; LiveCodeBench-Hard 17.9 / 9.8 / 17.1 / 16.3; GPQA-Diamond 56.8 / 45.5 / 52.5 / 75.2.
- Model size: training 7B and 14B models gave only modest improvements; Qwen2.5-14B-Coder-Instruct trained on APPs moved LiveCodeBench from 42.6% to 46.3%, and models below 32B frequently generated repetitive content (Other findings).
- Data mixture: a 32B model trained on 3–4K Numina math problems from STILL-2 raised AIME2024 from 16.7% to 43.3%; adding APPs code data dropped AIME2024 to 36.7%; adding harder NuminaMath problems and TACO coding tasks restored 43.3% while improving coding (Other findings). The post's stated hypothesis for the drop is that math and coding require distinct reasoning approaches.
- Compute support acknowledged from Lambda and Anyscale (Acknowledgement).

## Findings relevant to generality and distillation
- Distillation: an open-weights teacher (QwQ-32B-Preview) is sufficient to transfer long chain-of-thought to a non-reasoning instruct model of the same size, measured on the six benchmarks above (Evaluation and Results).
- Distillation scale limit: the same recipe at 7B and 14B gave only modest improvements, with repetitive generations below 32B (Other findings). The post reports no controlled comparison across sizes with a fixed dataset.
- Generality across domains: mixing math and code caused interference until harder examples were added to both domains; the post measures this only on AIME2024 and LiveCodeBench (Other findings). No safety, instruction-following, or multilingual evaluation is reported.
- Trace correctness is enforced only where a verifier exists (ground-truth match for math, unit tests for code). The 1K STILL-2 science and puzzle subset is described without a verification procedure (Rejection Sampling).
