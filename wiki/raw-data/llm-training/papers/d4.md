# D4 / SemDeDup: Data-Efficient Learning Through Semantic Deduplication
- **Core Insight:** Exact dedup misses semantically redundant examples; embedding-based semantic dedup can remove large fractions of data with little or no loss and sometimes better OOD generalization.
- **Guideline:** After exact or MinHash dedup, run embedding-space clustering or nearest-neighbor filtering to prune semantic near-copies from web corpora.
- **Authors:** Amro Abbas, Kushal Tirumala, Daniel Simig, Surya Ganguli, Ari Morcos
- **Year:** 2023
- **URL:** https://arxiv.org/abs/2303.09540
- **Relevant topics:** semantic deduplication, diversity-aware filtering, embedding filtering

## Abstract
SemDeDup studies semantic redundancy in web-scale datasets and shows that removing semantically duplicate examples can improve data efficiency. Although introduced on vision-heavy web data, its core lesson carries directly into LLM data curation: exact dedup is necessary but not sufficient.

## Key Contributions
- Formalized semantic duplicate removal beyond exact text matching.
- Showed that large fractions of redundant data can be removed with minimal loss.
- Strengthened the case for diversity-aware data filtering in large-scale training.

## Technical Details
- Compute embeddings for examples.
- Cluster or compare neighbors in embedding space.
- Remove highly similar semantic near-copies rather than only exact duplicates.
- Practical value: lowers repeated gradient signal and improves effective data diversity.
