# LongWriter: Unleashing 10,000+ Word Generation from Long Context LLMs
- **Core Insight:** In a controlled SFT experiment on GLM-4-9B, capping SFT output length at 500, 1,000 and 2,000 words produced models whose maximum output length was about 600, 900 and 1,800 words, so the output-length ceiling tracks the longest outputs in SFT data rather than the context window (§2, Fig. 2).
- **Guideline:** To raise a model's output length, add a few thousand SFT examples with long outputs generated by decomposing each task into a paragraph plan and writing paragraphs sequentially with the previous text in context, mix them with general SFT data, and average the loss per token rather than per sequence (§3–§4.2; Table 2; Table 4).
- **Authors:** Yushi Bai, Jiajie Zhang, Xin Lv, Linzhi Zheng, Siqi Zhu, Lei Hou, Yuxiao Dong, Jie Tang, Juanzi Li (Tsinghua University, Zhipu AI)
- **Year:** 2024 (arXiv v1 2024-08-13; only version)
- **URL:** https://arxiv.org/abs/2408.07055 (code, data, models: https://github.com/THUDM/LongWriter)
- **Source type:** paper
- **Relevant topics:** long-output SFT data, agent-based data synthesis, plan-then-write, output length control, loss averaging, length-aware DPO, long-form writing evaluation

## Abstract
Long-context LLMs accept inputs of 100,000 tokens but rarely produce outputs over 2,000 words. Controlled experiments show the effective generation length is bounded by the longest outputs seen during SFT. The paper introduces AgentWrite, an agent pipeline that splits an ultra-long writing task into subtasks so that off-the-shelf LLMs can produce coherent outputs over 20,000 words. AgentWrite with GPT-4o builds LongWriter-6k, 6,000 SFT examples with outputs of 2k–32k words. Training on it extends existing models' output length to over 10,000 words without lowering quality. The paper also builds LongBench-Write, and a 9B model further trained with DPO reaches the top score on it.

## Key Contributions
- Probe (LongWrite-Ruler) showing all eight tested models top out near 2k words (§2, Fig. 1).
- Controlled SFT-length experiment linking output ceiling to SFT output length (§2, Fig. 2).
- AgentWrite: Step I plan (paragraph main points + word counts), Step II sequential writing (§3.1–3.2).

- LongBench-Write: 120 prompts with explicit length requirements, length score S_l and judge quality score S_q (§3.3, Table 1, Eq. 1).

## Technical Details
**LongWrite-Ruler (§2, App. B).** 8 seed instructions (4 Chinese, 4 English) × L ∈ {1000, 2000, 5000, 10000, 20000, 30000} = 48 prompts; temperature 0.5; max tokens set to each API maximum, 32k for open models. Length is measured in words (characters for Chinese).

**Controlled experiment (§2).** Base GLM-4-9B; 180k GLM-4 chat SFT examples. Removing outputs longer than 500 / 1,000 / 2,000 words keeps 72% / 98% / 99.9% of the data. The paper states that LLM-synthesized data and iterative SFT cannot break this ceiling because the generating models share it.

**AgentWrite (§3).**
1. Plan: prompt the LLM to split the instruction into paragraph subtasks, one line each, with "Main Point" and "Word Count"; each paragraph 200–1000 words (§3.1 prompt).
2. Write: call the LLM serially; for paragraph n, input the instruction, the full plan and the n−1 paragraphs already written (§3.2 prompt).
3. Validation (Table 2, GPT-4o, instructions ≥ 2,000 words only): S̄ 78.6 → 89.1 (+AgentWrite) vs 88.5 (+Parallel); [4k, 20k) S_l 5.6 → 86.8 vs 87.3; overall S_q 91.8 → 91.6 vs 88.9. Parallel writing lowers Coherence by 6% (§3.3).

**LongBench-Write metrics (§3.3, Eq. 1).** S_l = 100·max(0, 1 − (l′/l − 1)/3) if l′ > l, else 100·max(0, 1 − (l/l′ − 1)/2), where l is required and l′ actual length; S_l reaches 0 above 4× or below 1/3 of the target. S_q = mean of six GPT-4o judge dimensions (Relevance, Accuracy, Coherence, Clarity, Breadth and Depth, Reading Experience), judged "without considering length". Final S̄ = mean(S_l, S_q).

**LongWriter-6k construction (§4.1).** 3,000 instructions from GLM-4 SFT data (mostly Chinese) + 3,000 from WildChat-1M (mostly English), selected by a GPT-4o yes/no prompt for > 2,000-word requests (App. C); rule-based removal of toxic and scraping requests; manual check finds > 95% truly need several thousand words. Responses by AgentWrite with GPT-4o; about 0.2% removed (too short, or crashes from too many plan steps); "paragraph 1"-style markers stripped. Fewer than 100 examples have ≥ 20k-word outputs (§4.3.1, Fig. 5).

**Training (§4.2).** Base models GLM-4-9B and Llama-3.1-8B (128k context). LongWriter-6k + 180k GLM-4 chat SFT. Packing with loss weighting; loss is averaged over all target tokens in the batch, because per-sequence averaging "significantly" reduces the weight of tokens in long outputs and gave worse long-output results. DPO: about 50k GLM-4 chat DPO pairs + 4k long-writing pairs; for each instruction sample 4 outputs from LongWriter-9B, score with the ChatGLM-RLHF method plus S_l, take the top as chosen and a random other as rejected; 250 steps.

**Main results (Table 3; S̄ / S_l / S_q; [4k, 20k) S_l).** Claude 3.5 Sonnet 80.7 / 73.7 / 87.7; 26.0. GPT-4o 78.6 / 65.3 / 91.8; 5.6. GLM-4-9B-chat 68.3 / 51.0 / 85.5; 0.2. LongWriter-8B 79.8 / 77.4 / 82.2; 77.9. LongWriter-9B 80.5 / 78.6 / 82.3; 80.3. LongWriter-9B-DPO 84.0 / 82.6 / 85.4; 90.3. Human pairwise: DPO preferred over LongWriter-9B in 58% of cases (Fig. 9).

**Ablations (Table 4, GLM-4-9B; S̄ / S_l / S_q; [4k, 20k) S_l).** LongWriter-9B 80.5 / 78.6 / 82.3; 80.3. Without LongWriter-6k 62.6 / 48.1 / 77.1; 0. Plan-augmented outputs (plan prepended to response) 81.4 / 80.9 / 81.8; 81.4. 6k instruction-backtranslation examples from 2k–32k-word pretraining texts 60.4 / 44.8 / 70.0; 0.

## Findings relevant to generality and negative feedback
- **Generality.** Adding LongWriter-6k raised S_q from 77.1 to 82.3 (reported as +5%) and "Breadth and Depth" by 18% absolute versus the ablated model, and did not bias outputs toward longer responses on short prompts (§4.3.2, Table 4 and inline figure). Evaluation is limited to LongBench-Write and LongWrite-Ruler; general benchmarks are not reported.
- **Negative feedback.** DPO rejected samples are random non-top outputs among 4 samples, scored by quality plus length-following (§4.2). AgentWrite outputs contain occasional repetition and frequent summaries (§3.3).
- **Synthetic-data failure mode.** Instruction backtranslation on web long texts lowered both S_l and S_q; the authors attribute this to noisy formatting of web text and a mismatch between backtranslated and real user instructions (§4.3.2).
