# Alpaca: A Strong, Replicable Instruction-Following Model
- **Core Insight:** LLaMA 7B fine-tuned on 52K instruction-following demonstrations generated by text-davinci-003 won 90 versus 89 blind pairwise comparisons against text-davinci-003 in an evaluation by the 5 student authors, at a reported cost of less than $500 for data generation and less than $100 for fine-tuning (blog, "Training recipe" and "Preliminary evaluation").
- **Guideline:** When a strong instruction-following teacher and an open base model are available, a Self-Instruct-style generation pipeline can produce a single-turn instruction model at low cost; evaluate it beyond one teacher-style evaluation set, because the authors describe their evaluation as "limited in scale and diversity" and report hallucination as a common failure mode, "even compared to text-davinci-003" (blog, "Preliminary evaluation", "Known limitations").
- **Authors:** Rohan Taori, Ishaan Gulrajani, Tianyi Zhang, Yann Dubois, Xuechen Li, Carlos Guestrin, et al. (Stanford CRFM)
- **Year:** 2023 (blog post 2023-03-13; repository README at commit 761dc5b, 2023-05-30)
- **URL:** https://crfm.stanford.edu/2023/03/13/alpaca.html ; https://github.com/tatsu-lab/stanford_alpaca/tree/761dc5bfbdeeffa89b8bff5d038781a4055f796a

## Summary
The blog introduces Alpaca 7B, a LLaMA 7B model fine-tuned on 52K instruction-following demonstrations. The demonstrations were generated with text-davinci-003 by a modified Self-Instruct pipeline that starts from the 175 human-written seed pairs of Self-Instruct. The authors evaluate single-turn instruction following on the Self-Instruct evaluation set and find Alpaca similar to text-davinci-003. They release the data, the generation code, and the training code; the README later adds a weight diff. Use is restricted to research because of the LLaMA license, the OpenAI terms of use, and the absence of safety measures.

## Key Contributions
- A modified Self-Instruct pipeline: text-davinci-003 as generator, a new generation prompt, 20 instructions per request, one instance per instruction, no classification/non-classification split (README, "Data Generation Process").
- A released 52K dataset (`alpaca_data.json`) with instruction, optional input, and output fields (README, "Data Release").
- A released full fine-tuning script and hyperparameter table for LLaMA-7B and LLaMA-13B (README, "Fine-tuning").
- A public statement of cost, evaluation method, and known failure modes (blog).

## Technical Details
- **Seed and teacher.** Generation starts from the 175 human-written instruction-output pairs of the Self-Instruct seed set and prompts text-davinci-003 with seed examples in context (blog, "Training recipe"; README).
- **Generation prompt.** `prompt.txt` asks for 20 diverse task instructions in English, 1–2 sentences each, with an input that "should ideally not exceed 100 words" or `<noinput>`, and an output of "less than 100 words" (prompt.txt L1, L8–12). The README notes "a slight error in the prompt" and points to PR #24.
- **Released generation code defaults** (`generate_instruction.py` @761dc5b L110–120, L162): 3 seed examples per prompt, 5 prompts per request batch, temperature 1.0, top_p 1.0, max_tokens 3072. The README does not state the arguments used for the released 52K run.
- **Filters in the released code** (`generate_instruction.py` @761dc5b): drop the last example if generation stopped on length (L52); drop instructions with ≤ 3 or > 150 words (L64); drop instructions containing blacklisted words such as image, graph, file, map, draw, plot, video, audio, music, flowchart, diagram (L67–89); drop instructions starting with "Write a program", with punctuation, or with a non-ASCII character (L94–101); drop instructions whose ROUGE-L F-measure against any existing instruction exceeds 0.7 (L196). Outputs are not checked.
- **Dataset.** 52K examples; "Each of the 52K instructions is unique"; "Around 40% of the examples have an input" (README, "Data Release"). Data cost less than $500 through the OpenAI API (blog).
- **Diversity.** The README states the 52K data is "much more diverse" than the Self-Instruct release and shows a verb–object parse plot; no numeric measure is given (README, "Data Generation Process").
- **Prompt templates.** Two templates: "Below is an instruction that describes a task, paired with an input …" with `### Instruction:`, `### Input:`, `### Response:`, and a no-input version. The demo uses the no-input template (README, "Data Release").
- **Loss masking.** `train.py` sets the labels of the prompt tokens to IGNORE_INDEX = −100, so loss is computed on response tokens only (`train.py` @761dc5b L26, L122–123).
- **Evaluation.** Blind pairwise human evaluation by the 5 student authors on inputs from the Self-Instruct evaluation set: Alpaca wins 90 versus 89 comparisons against text-davinci-003 (blog, "Preliminary evaluation"). Tie handling is not described.
- **License.** Data and weight diff are CC BY-NC 4.0; research use only (README header). Reasons: LLaMA non-commercial license, OpenAI terms of use for text-davinci-003 outputs, no safety measures (blog, "Overview").

## Findings relevant to generality, negative feedback, distillation
- **Measurement scope.** The only reported evaluation is one evaluation set rated by the 5 student authors; the authors write that the evaluation "may be limited in scale and diversity" and plan HELM evaluation (blog, "Preliminary evaluation", "Future directions").
- **Style inheritance (distillation).** "Alpaca reflects the general style of the instruction-following dataset"; its answers are "typically shorter than ChatGPT, reflecting text-davinci-003's shorter outputs" (blog).
- **Hallucination.** Hallucination "seems to be a common failure mode for Alpaca, even compared to text-davinci-003"; example: Alpaca names Dar es Salaam as the capital of Tanzania (blog, "Known limitations"). Toxicity and stereotypes are also listed.
- **Negatives.** Generated instructions that fail the filters are discarded (negative marginal value); discard counts are not reported, and responses are not scored in the released pipeline. [[alpagasus]] later rated the 52,002 responses with ChatGPT and kept 9,229 at score ≥ 4.5 (arXiv:2307.08701 §2.3).

## Connections
- [[self-instruct]] — the pipeline Alpaca modifies (generator model, prompt, batch decoding, one instance per instruction).
- [[alpagasus]] — filters the Alpaca 52K data with ChatGPT ratings and trains with the Alpaca script.
- [[evol-instruct]] — WizardLM uses the Alpaca data as the initial instructions for evolution (arXiv:2304.12244 §1).
- [[lima]] — uses an Alpaca 65B reproduction trained on the 52,000 Alpaca examples as a baseline (arXiv:2305.11206 §4.1).
- [[cherry-llm]] — selects about 5% of the Alpaca data by IFD score and compares with the official Alpaca model (arXiv:2308.12032 §1).
- External, no card in this library: Gudibande et al., "The False Promise of Imitating Proprietary LLMs" (arXiv:2305.15717, May 2023) names Alpaca as an example of imitation fine-tuning and reports that imitation models "close little to none of the gap" to ChatGPT on tasks "not heavily supported in the imitation data" and mimic "ChatGPT's style but not its factuality" (abstract).
