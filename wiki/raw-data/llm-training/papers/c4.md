# C4: Colossal Clean Crawled Corpus
- **Core Insight:** C4 made heuristic web filtering a mainstream pretraining recipe: aggressive boilerplate removal, bad-word lists, language filtering, and document cleanup can turn a crawl into a usable text corpus fast.
- **Guideline:** If you need a simple baseline crawl pipeline, C4 is the canonical heuristic stack, but document its biases and exclusions because the filters are blunt.
- **Authors:** Colin Raffel, Noam Shazeer, Adam Roberts, Katherine Lee, Sharan Narang, Michael Matena, et al.
- **Year:** 2019
- **URL:** https://arxiv.org/abs/1910.10683
- **Relevant topics:** web filtering, heuristic cleaning, T5, boilerplate removal

## Abstract
C4 is the cleaned web corpus used for T5. It is derived from Common Crawl using a sequence of heuristic filters, including language restrictions, boilerplate cleanup, and content exclusion rules. It became one of the most copied English web-corpus recipes in LLM pretraining.

## Key Contributions
- Popularized a simple, reproducible English crawl-cleaning recipe.
- Showed that high-quality transfer learning can be built on aggressively cleaned web text.
- Became the base corpus for a large amount of later open-source language-model work.

## Technical Details
- Source is Common Crawl.
- Main filters: English-only text, line/document cleanup, de-dup-like cleanup, code and boilerplate suppression, and bad-word / low-quality heuristics.
- The recipe is fast and practical but much less semantically targeted than later classifier-based pipelines.
- Later analysis found important representation biases and unexpected removals from the blocklist-heavy design.

## Connections
- Simpler heuristic cousin of [[ccnet]].
- Later documentation work on C4 influenced the transparency push seen in [[dolma]] and [[fineweb]].
