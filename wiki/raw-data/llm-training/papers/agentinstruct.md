# AgentInstruct: Toward Generative Teaching with Agentic Flows
- **Core Insight:** Fine-tuning Mistral-7b-v0.1 on 25.8M instruction pairs, about 22M of them generated by AgentInstruct flows from raw text and code, gives Orca-3, which scores 56.80 AGIEval, 69.95 MMLU, and 83.09 GSM8K, i.e. +40%, +19%, and +54% relative to Mistral-7B-Instruct (Table 3).
- **Guideline:** When synthetic post-training data must cover many skills without reusing benchmark prompts, seed generation with raw documents and code and run a per-skill transformation → seed-instruction → suggester/editor refinement flow, because adding the ~22M flow-generated pairs to a 3.8M-pair baseline raised Orca-Bench from 7.13 (Orca-2.5) to 9.55 (Orca-3) (Table 2). This comparison changes data volume and content together, so it does not isolate the flow design from data size.

## Abstract
Synthetic data is used across LLM training, but results vary because its quality and diversity vary, and good use usually needs human curation. The paper defines Generative Teaching: a strong model creates data to teach a skill or behavior to another model. AgentInstruct is an extensible agentic framework that creates both prompts and responses using only raw text documents and code files as seeds. The authors create a 25M-pair post-training dataset covering skills such as text editing, creative writing, tool use, coding, and reading comprehension, and fine-tune Mistral-7b on it. The resulting Orca-3 improves over Mistral-7b-Instruct by 40% on AGIEval, 19% on MMLU, 54% on GSM8K, 38% on BBH, and 45% on AlpacaEval, and outperforms LLAMA-8B-instruct and GPT-3.5-turbo on several benchmarks.

## Key Contributions
- The Generative Teaching problem setting: generate diverse, challenging data to teach a skill, starting from raw seeds rather than a prompt set (§1).
- Three flows: Content Transformation, Seed Instruction Generation, Instruction Refinement (§2, Figs. 2-3).
- Flow implementations for 17 skills (Table 1) with a taxonomy of over 100 subcategories (§1).
- Orca-3 trained on ~25.8M pairs, with Orca-2.5 (3.8M non-AgentInstruct pairs) as a control (§3).
- Evaluation on Orca-Bench and 13 public benchmarks (14 metrics), plus reading comprehension, math, format following, summarization hallucination, and RAG (§4, Tables 2-8).

## Technical Details
- **Agent definition.** An LLM with a role-specific system message, optionally with tools such as search APIs, a code interpreter, or a calculator (§2).
- **Flows.** Content Transformation converts a seed into an intermediate form (e.g. argument passage, meeting transcript, API list). Seed Instruction Generation creates diverse tasks from a taxonomy. Refinement uses Suggester-Editor agents: suggesters propose ways to make a task more complex, unsolvable, or tricky; editors rewrite it (§2).
- **17 skills (Table 1).** Reading comprehension, open-domain QA, text modification, web agent, brain teaser, analytical reasoning, multiple-choice questions, data-to-text, Fermi, coding, text extraction, text classification, RAG, tool use, creative content generation, few-shot reasoning, conversation.
- **Reading comprehension flow.** Nine content transformation agents (argument, debate, conversation, meeting transcript, poem, satire, instructional, long text, identity) (§2.1, App. A.1). 43 question types, with agents that target categories (§2.1). Refinement: make the question unanswerable, change the answer, or make question or choices more complex (§2.1).
- **Text modification flow.** 18 task types (App. A.2); one agent per type; a single Suggester-Editor pair for refinement (§2.2).
- **Tool use flow.** Seeds are code snippets or API descriptions from ToolLLM; an API list is built by a retrieval agent or by an LLM hypothesizing the rest of the library. Task types: single API with all, extra, or missing parameters; multiple APIs with all or missing parameters; a needed API not in the list; multiple APIs with some missing. The system message allows API_CALL or STOP with FINAL_ANSWER or FAILED (§2.3).
- **Seeds and data.** KnowledgePile, AutoMathText, a subset of OpenStax, and a subset of Apache-2.0 source code from github-code-clean (§3.1). ~22M AgentInstruct instructions plus ~3.8M pairs from Orca-1, Orca-2, Orca-Math, and public sources (Orca-2.5-dataset) = ~25.8M (§3.1). No benchmark data was used as seeds (§3.1).
- **Teacher.** GPT-4 is named as the generating model in §1 and as "teacher" in §4.1 and §4.6; no version is given for data generation.
- **Orca-Bench.** 100 held-out samples per skill (two ODQA sets). The student answers each user turn given the teacher's history; each response is scored 0-10 against the teacher's response, normalized so GPT-4 = 10 (§4.1). Orca-2.5 7.13, Mistral-Instruct-7B 8.31, ChatGPT 8.13, Orca-3 after epochs 1/2/3: 9.35 / 9.49 / 9.55 (Table 2).
- **Public benchmarks (Table 3), Orca-3 vs Mistral-7B-Instruct.** AGIEval 56.80 vs 40.52; MMLU 69.95 vs 58.61; ARC 92.47 vs 82.72; BBH 61.83 vs 44.71; GPQA 28.12 vs 29.46 (−4%); DROP 71.14 vs 58.12; GSM8K 83.09 vs 54.06; FoFo 84.01 vs 75.3; IFEval 49.54 vs 48.61; MT-Bench 8.20 vs 7.53; AlpacaEval 24.80 vs 17.1; InfoBench 84.30 vs 81. §4.2 names the baseline Mistral-7B-Instruct-v0.3; Table 8 labels it v0.1.
- **Skill evaluations.** Reading comprehension average 76.95 vs 63.63 (+21%); AGIEval LSAT-RC 75.84 vs GPT-4 72.86 (Table 4). The text reports math gains over Mistral-7B-Instruct of +44% to +168% (§4.4); Table 5 also lists +882% on BBH multistep-arithmetic-two (66.80 vs 6.8). Summarization hallucination rate, GPT-4 judge, all (micro): 21.09% vs 30.72% (−31.34%); GPT-4 15.07% (Table 7). MIRAGE with RAG, average: 64.27 vs 46.47 (+38.30%); PubMedQA 58.2 vs 30.2 (+92.71%) (Table 8).

## Findings relevant to generality, negative feedback, agentic training, distillation
- **Generality.** The authors state that raw-document seeds, instead of existing or paraphrased prompts, promote general capabilities over benchmark-specific ones (Interpretation, §1, §3.1). Evidence in their tables: gains on 13 of the 14 Table 3 metrics over Mistral-7B-Instruct; GPQA is lower (28.12 vs 29.46). RAG data used generic, non-medical seeds and was tested on medical MIRAGE (§4.7).
- **Measurement limits.** Orca-Bench is drawn from the same flows as the training data and is scored relative to GPT-4, so it measures in-distribution skill (Interpretation). The authors list dependence on seed quality, bias, validation difficulty, and human effort to build each flow as limitations (§5).
- **Negative samples.** Tool-use tasks include missing APIs and missing parameters, where the target response stops with FAILED and a reason (§2.3); refinement makes some reading questions unanswerable (§2.1). These are negative as content. No ablation isolates them, and no negative-gradient training is used.
- **Agentic training.** "Agentic" refers to the data-generation flows. Tool use and web agent are 2 of 17 skills; no tool-use or web-agent benchmark is reported in Tables 3-8.
- **Distillation.** Orca-3 is trained on GPT-4-generated data and reaches Orca-Bench 9.55 relative to GPT-4 = 10 (Table 2); it remains below GPT-4 on 12 of the 14 Table 3 metrics, e.g. AlpacaEval 24.80 vs 55.
