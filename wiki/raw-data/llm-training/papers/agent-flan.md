# Agent-FLAN: Designing Data and Methods of Effective Agent Tuning for LLMs
- **Core Insight:** Agent SFT is most effective when data is decomposed into **three complementary capabilities** — (1) instruction following, (2) reasoning and decision-making in agent format, (3) generalizing to diverse unseen tools — and trained with **negative examples** that teach the model when NOT to emit hallucinated tool calls; a balanced mix of all three with explicit negatives beats monolithic agent corpora.
- **Guideline:** Build agent SFT mixes with explicit instruction-following data (to preserve chat quality), agent-trajectory data (for tool-use behavior), and negative / hallucination-correction data (to teach refusal); omitting any of the three costs multiple benchmark points.
- **Authors:** Zehui Chen, Kuikun Liu, Qiuchen Wang, Wenwei Zhang, Jiangning Liu, Dahua Lin, Kai Chen, Feng Zhao (Shanghai AI Lab)
- **Year:** 2024
- **URL:** https://arxiv.org/abs/2403.12881
- **Relevant topics:** agent SFT, hallucination mitigation, capability decomposition, AgentBench

## Abstract
Agent-FLAN studies what makes agent fine-tuning work and identifies three bottlenecks in existing approaches (AgentTuning, FireAct): (1) data format mismatch with pretraining distribution, (2) capability imbalance — too much tool-use, too little instruction-following preservation, and (3) hallucination — models fabricate tool calls in irrelevant contexts. Agent-FLAN addresses all three with a decomposition of agent training data into three capability types, explicit negative examples for hallucination correction, and format alignment with pretraining distribution. Llama2-Agent-FLAN-7B surpasses several 70B agent baselines.

## Key Contributions
- **3-capability decomposition** for agent SFT: instruction-following / reasoning-decision / generalization.
- **Negative example synthesis** targeting four hallucination modes: format, action, parameter, relevance.
- **Format alignment** — rewrite agent trajectories to closely match Llama-pretraining distribution, avoiding out-of-distribution tokens.
- Agent-FLAN models outperform many open baselines at 7B and 13B.

## Synthesis pipeline (REQUIRED — concrete, modality-specific)

### Data mix (three capability types)
- **Instruction-following data (preserve chat quality):** ShareGPT, Alpaca, Evol-Instruct — ~50K.
- **Agent reasoning / decision data:** trajectories from AgentTuning + FireAct (filtered) + new internal rollouts — ~20K.
- **Generalization data:** tool-use trajectories on held-out APIs not in the core set — ~10K.

### Negative-example synthesis (hallucination correction)
- **Format hallucination:** examples where base model produces malformed tool calls → gold response is the corrected call or a refusal.
- **Action hallucination:** user query doesn't require a tool → gold is text-only answer, no call.
- **Parameter hallucination:** tool is needed but with different args than the model would fabricate → gold has the correct args.
- **Relevance hallucination:** offered tool list doesn't include a relevant tool → gold is "I cannot help with this tool set" refusal.
- Negative examples generated by prompting GPT-4 with common failure patterns.

### Format-alignment step
- Rewrite agent trajectories to avoid special tokens / delimiters that don't appear in Llama-2 pretraining. Keeps training distribution close to pretraining distribution, reducing catastrophic forgetting.

- **Output shape:** ~85K total training examples; multi-turn avg 6 turns.
- **Teacher model:** GPT-4 (for new generations + negatives).
- **Cost:** ~$15K GPT-4 API.

## Modality-specific technical details (REQUIRED — agentic)
- **Environment:** inherited from AgentTuning + FireAct (ALFWorld, WebShop, HotpotQA, Mind2Web).
- **Action space:** ReAct-style but with hallucination-correction negatives teaching refusal.
- **Trajectory length:** 6–15 turns; total 1K–4K tokens.
- **Success criterion:** env-native + hallucination-absence checks.
- **Data scale:** 85K total — modest but balanced.
- **Hallucination-rate measurement:** Agent-FLAN-7B cuts hallucinated tool calls by 5× vs AgentTuning baseline on AgentBench held-out.

## Quality / diversity evaluation
- Llama2-Agent-FLAN-7B: AgentBench overall 3.92 — beats AgentTuning-13B (2.8) and matches AgentTuning-70B.
- General chat ability (MT-Bench / MMLU) preserved within 0.5 points of Llama2-Chat.
- Ablations: removing any one of the three capability types costs 0.3–0.5 AgentBench points; removing negatives → halluc rate triples.

## Risks + gotchas
- **Still GPT-4-teacher bound.**
- **Narrow env coverage** — same set as AgentTuning (no SWE-Bench, no long-horizon web).
- **Negative-example distribution** is hand-curated; miscoverage leaks hallucinations in novel contexts.
