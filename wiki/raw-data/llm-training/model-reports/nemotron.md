# Nemotron-4 340B Technical Report
- **Core Insight:** A reward model that outputs a vector of attribute scores (helpfulness, correctness, coherence, complexity, verbosity) is a stronger judge than a scalar-only RM, and enables >98% of the alignment data to be synthetic.
- **Guideline:** Train a multi-attribute regression RM on HelpSteer2, then use it both for rejection sampling and for synthetic data filtering.
- **Authors:** NVIDIA (Nemotron team)
- **Year:** 2024
- **URL:** https://arxiv.org/abs/2406.11704
- **Relevant topics:** Multi-attribute reward model, HelpSteer2 (10K human preferences), >98% synthetic alignment data, NeMo-Aligner, open-weight license

## Abstract
Nemotron-4 340B is NVIDIA's open dense 340B-parameter model family — Base, Instruct, and Reward. Pretrained on 9T tokens. Post-training is notable for two facts: (1) the released Reward model is an RMSNorm multi-attribute regression head trained on HelpSteer2 (~10K human preferences) that predicts five attribute scores rather than a single preference logit; (2) >98% of alignment data is synthetically generated — prompts, responses, and preference labels — using earlier Nemotron-4 models themselves. The open-weight license permits redistribution.

## Key Contributions
- HelpSteer2 dataset: 10K high-quality human preferences labeled with five attributes (helpfulness, correctness, coherence, complexity, verbosity).
- Nemotron-4-340B-Reward: multi-attribute regression RM that outputs a 5-vector; preference computed as weighted sum.
- Synthetic data pipeline: >98% of alignment data machine-generated, filtered by the multi-attribute RM.
- Full release of Base + Instruct + Reward under NVIDIA Open Model License.
- NeMo-Aligner codebase released for reproducing alignment pipeline.

## Technical Details — Post-Training Pipeline

### Reward Model
- **Base:** Nemotron-4-340B-Base.
- **Head:** replaced LM head with a regression MLP that outputs 5 floats (one per attribute).
- **Training data:** HelpSteer2 — 10,000 human-labeled preferences with attribute scores.
- **Loss:** per-attribute L2 regression.
- **Aggregation for preference use:** weighted sum of attributes (weights documented in the NeMo-Aligner config).
- **Ranks #1 on RewardBench** at time of release.

### Synthetic data pipeline (>98% of alignment data)
Three synthetic data types:
1. **Synthetic prompts** — generated by Nemotron-4-340B-Instruct itself across tasks.
2. **Synthetic responses** — two responses per prompt from the Instruct model (or earlier checkpoint).
3. **Synthetic preferences** — the multi-attribute RM scores response pairs; the scored pair becomes a preference datum.
The pipeline is self-bootstrapping: each alignment round uses the previous round's Instruct model to generate data for the next round.

### Alignment stages
- **SFT:** on the synthetic instruction-following mix.
- **Preference optimization:** DPO or reward-PPO (NeMo-Aligner supports both). The report documents the full pipeline; specific chosen algo per release disclosed in supplementary configs.

### Scale
- **Parameters:** 340B dense (no MoE).
- **Pretraining tokens:** 9T.
- **Pretraining compute:** not separately disclosed in public report.
- **Alignment data:** single-digit-to-low-double-digit millions of synthetic examples.

### Why this matters
Nemotron-4-340B is the cleanest public disclosure of a *full* reward-model recipe: which human dataset (HelpSteer2), how many examples (10K), what objective (multi-attribute regression), how it's used downstream (synthetic data filtering at scale). It is the canonical reference when asked "what does a production RM look like?"
