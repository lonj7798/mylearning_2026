# Phi-3 Technical Report: A Highly Capable Language Model Locally on Your Phone
- **Core Insight:** Small models (3.8B) can reach 7B/13B parity when pretrained on synthetic "textbook-like" data that packs more information per token than filtered web text.
- **Guideline:** For sub-10B models, reallocate the data budget heavily toward synthetic high-quality data generated by larger teacher models.
- **Authors:** Marah Abdin et al. (Microsoft)
- **Year:** 2024
- **URL:** https://arxiv.org/abs/2404.14219
- **Relevant topics:** Synthetic pretraining data, textbook-like generation, two-phase SFT + DPO, small-model post-training

## Abstract
Phi-3 is Microsoft's small-model family: phi-3-mini (3.8B), phi-3-small (7B), phi-3-medium (14B). The innovation is *entirely in the dataset*: a scaled-up version of phi-2's mixture composed of heavily filtered web data and "textbook-like" synthetic data generated by larger LLMs and reviewed by researchers. Pretraining is two-phase: Phase 1 web-heavy, Phase 2 synthetic-heavy. Post-training is standard SFT + DPO with carefully curated chat-format data.

## Key Contributions
- Demonstration that 3.8B can reach ~Mixtral 8x7B quality on some benchmarks when pretraining data is synthetic-heavy.
- Two-phase pretraining curriculum (web-heavy -> synthetic-heavy) that became a template.
- Open-weights release at 3.8B scale suitable for on-device inference (~2GB at 4-bit quantization).
- Safety-focused DPO slice covering responsible AI topics.

## Technical Details — Post-Training Pipeline

### Pretraining (context)
- **Total tokens:** 3.3T (mini), 4.8T (small), 4.8T (medium).
- **Two-phase curriculum:**
  - **Phase 1:** majority of training tokens; heavily filtered web data.
  - **Phase 2:** primarily synthetic tokens (textbook-like) + small allocation for ultra-filtered reasoning-heavy web data.
- Synthetic data generated by larger LLMs (GPT-3.5 / GPT-4 class) covering math, coding, common-sense reasoning, world knowledge. Human reviewed.

### SFT
- **Purpose:** enhance instruction-following across diverse domains (math, coding, reasoning, conversation, model identity, safety).
- **Data:** curated high-quality synthetic + human-written instruction-response pairs.
- Specific size and mixture not itemized publicly for Phi-3.

### DPO
- **Purpose:** improve model safety and align with human preferences.
- **Data:** chat-format data, reasoning-focused preferences, responsible-AI / safety preferences.
- Specific beta, LR, batch size, and preference pair count not fully disclosed in the public report.

### Safety-specific DPO slice
- Dedicated responsible AI preference data covering harmful content refusal, bias mitigation, privacy scenarios.
- Evaluated via Microsoft's internal safety suite plus external benchmarks.

### Scale context
- **phi-3-mini:** 3.8B parameters, 4K native context (128K variant via LongRope).
- **phi-3-small:** 7B, 8K context.
- **phi-3-medium:** 14B, 4K context.
- Target: competitive with 7B-13B open models at much smaller size; on-device inference.

### What's NOT disclosed
- Exact SFT and DPO data volume.
- DPO beta / learning rate / batch size.
- Teacher model identities for synthetic generation (Microsoft has internal access to GPT-4 class models).
