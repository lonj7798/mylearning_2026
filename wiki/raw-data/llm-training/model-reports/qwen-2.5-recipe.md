# Qwen2.5 Technical Report — Recipe ledger
- **Parent card:** [[qwen-2.5]] (full source card for the same report).
- **Source:** arXiv:2412.15115v2 (v1 2024-12-19; v2 2025-01-03). Released config: huggingface.co/Qwen/Qwen2.5-72B-Instruct `config.json` and `README.md` (main branch, read 2026-09-14).
- **Checked on:** 2026-09-14. The report has no appendix. Loci are sections, tables, and figures of arXiv v2.
- **Scope of checkpoints:** "Qwen2.5 open-weight" means the seven dense sizes 0.5B, 1.5B, 3B, 7B, 14B, 32B, 72B (Abstract, Table 1). Qwen2.5-Turbo and Qwen2.5-Plus are proprietary MoE API models whose sizes are not given (§2). A value is recorded for a size only where the report states the scope; §3.3 and §4.1-4.3 state their settings for all open-weight models.
- **Units:** the report does not state whether "18 trillion tokens" is the unique-token dataset size or tokens seen per model. An online-RL "sample" is one query-response pair (§4.3).

## Starting point for a small general-purpose run
No setting in this report was selected by an ablation, and no value is given for a model below the report's scope. The verified SFT rows (2 epochs, 32,768-token sequences, LR 7 × 10⁻⁶ → 7 × 10⁻⁷, weight decay 0.1, clip 1.0) were used for all seven open-weight sizes (0.5B-72B) on over 1 million examples; batch size and optimizer are not reported, so the configuration is incomplete.
