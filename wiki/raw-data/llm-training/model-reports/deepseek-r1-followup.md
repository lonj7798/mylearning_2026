# DeepSeek R1-0528 / R1-Distill
- **Core Insight:** Rather than release "R2," DeepSeek iterated R1 in place — R1-0528 is the same V3 base + more compute + post-training-only improvements; distilled R1 traces (800K) fine-tuned on Llama / Qwen bases produce the open R1-Distill family.
- **Guideline:** Open reasoning diffusion is cheap — 800K rejection-sampled traces from a strong reasoner are enough to transfer o1-class reasoning into 1.5B–70B bases.

- **Authors / Lab:** DeepSeek-AI
- **Year:** 2025 (R1-0528 May 28, 2025; R1-Distill released alongside original R1 Jan 2025)
- **URL:** https://github.com/deepseek-ai/DeepSeek-R1 — model cards on HF
- **Relevant topics:** R1 update, distillation as post-training, 800K R1 traces, Llama-3.1 / 3.3 and Qwen-2.5 base recipients

## Abstract
R2 was anticipated for May 2025 but did not ship; DeepSeek instead released **R1-0528**, a major post-training refresh built on the same V3 base as R1 but with more compute and updated post-training optimizations. In parallel (and from the original R1 release), the **R1-Distill** family transferred R1's reasoning into open base models: 800K reasoning samples generated by R1 were used to fine-tune Llama 3.1/3.3 and Qwen 2.5 bases into R1-Distill-{1.5B, 7B, 14B, 32B, 70B}. DeepSeek-V3.1 (Aug 2025) subsequently merged V3 and R1 into a single hybrid checkpoint — making R1-0528 likely the final standalone R1 descendant.

## Key Contributions
- **R1-0528:** same V3 base, retrained post-training with more compute; reported significant gains on reasoning and inference-time depth vs the January 2025 R1.
- **R1-Distill family:** open distillation recipe with 800K R1-generated samples applied to 6 open base models (Llama 3.1 8B, Llama 3.1 70B, Llama 3.3 70B, Qwen 2.5 1.5B/7B/14B/32B).
- Demonstrated that pure SFT distillation on 800K R1 traces produces o1-competitive scores on AIME / MATH-500 / GPQA at open-weight small scales.
- Operated as proof point that "distillation-only" post-training is competitive with full RL for transferring reasoning — a key 2025 finding.

## Post-training pipeline
- **R1-0528:**
  - **SFT data:** not publicly itemized — inherits R1's template (reasoning + non-reasoning) with updated mix.
  - **Preference / RL algorithm:** GRPO (inherited from R1); no algorithm change disclosed.
  - **Reward model:** rule-based + model-based as in R1.
  - **Hyperparameters:** not disclosed beyond "more compute."
  - **Innovations vs R1 (Jan):** more RL training compute; updated rule-based reward shaping — exact details not published.
- **R1-Distill family (SFT-only):**
  - **SFT data:** 800K rejection-sampled reasoning samples generated by R1.
  - **Preference / RL algorithm:** **none** — pure SFT. No RL applied to distilled models.
  - **Reward model:** none.
  - **Base models:** Llama 3.1-8B, Llama 3.1-70B, Llama 3.3-70B, Qwen 2.5-1.5B, Qwen 2.5-7B, Qwen 2.5-14B, Qwen 2.5-32B.
  - **Rollout scale:** N/A (offline SFT).
  - **Hyperparameters:** not disclosed; standard HF-SFT LR / batch assumed.
- **Verifiable rewards:** N/A for distill; inherited for R1-0528 (math, code).
- **Self-improvement / iterative:** R1 → R1-Distill is a one-shot teacher-student pass, not iterative; R1-0528 is a single-shot refresh, not a multi-round loop.

## Innovations vs predecessors
vs **R1 (Jan 2025)**:
- R1-0528 is R1-with-more-compute — no stated methodological change; a scaling update.
- V3.1 (Aug 2025) absorbs R1's reasoning into the V3 line — eliminating R1 as a distinct family going forward.

vs 2024 RLHF norms:
- Distillation-only (no RL, no RM, no DPO) reasoning transfer at multiple scales — contrasts with Tülu / Llama 3 which retained RL even at distilled scales.
- 800K trace budget is relatively small; the signal is in trace quality, not volume.
