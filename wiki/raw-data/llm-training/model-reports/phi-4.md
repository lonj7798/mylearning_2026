# Phi-4 / Phi-4-reasoning
- **Core Insight:** Data curation dominates algorithm choice — 1.4M o3-mini-generated reasoning traces for SFT, followed by only ~90 GRPO steps, reach competitive reasoning scores at 14B parameters.
- **Guideline:** Don't run RL long; most of the ceiling is set by SFT data quality. Use RL to squeeze the last 10% with a length-aware reward.

- **Authors / Lab:** Microsoft Research (Marah Abdin et al.)
- **Year:** 2024 (Phi-4 base, Dec 2024) + 2025 (Phi-4-reasoning, Apr 2025)
- **URL:** https://arxiv.org/abs/2412.08905 (Phi-4) — https://www.microsoft.com/en-us/research/publication/phi-4-reasoning-technical-report/
- **Relevant topics:** synthetic data, o3-mini distillation, GRPO, length-aware reward, n-gram repetition penalty, pivotal-token DPO

## Abstract
Phi-4 (14B) established the Microsoft line's "data-first" post-training philosophy: ~400B unweighted tokens of synthetic data across 50 types, combined with rejection sampling and a novel "pivotal-token DPO" where preference pairs are constructed around tokens that matter for final correctness. Phi-4-reasoning extends this with 1.4M curated prompts, o3-mini-generated long-reasoning traces (~16B tokens SFT, ~8.3B unique), and a short GRPO stage that lifts AIME by >10% in only 90 steps.

## Key Contributions
- **Phi-4 base:** 50 categories of synthetic data, ~400B unweighted tokens, injected into both pretraining and post-training. Pivotal-token DPO for preference pairs.
- **Phi-4-reasoning SFT:** 1.4M prompts filtered to the "boundary of base-model capability," with long reasoning traces generated by o3-mini in high-thinking mode at 32K context.
- **Phi-4-reasoning RL:** GRPO with rewards that combine correctness (+1 / −0.5) with a length-aware accuracy bonus and explicit penalties for (a) missing `<eos>`, (b) unclosed `<think>` blocks, (c) n-gram repetition with n=5.
- **RL is cheap:** only 90 GRPO steps produce >10% AIME gain; further steps yield little — SFT ceiling dominates.
- Demonstrates that frontier reasoning is reachable at 14B scale with careful prompt boundary curation.

## Post-training pipeline
- **SFT data:** Phi-4-reasoning — 1.4M prompts; ~16B tokens total, ~8.3B unique. Long CoT traces from o3-mini (high thinking, 32K). Domains: STEM, coding, safety. Prompts filtered to boundary of base-model competence (not too easy, not impossible).
- **Preference / RL algorithm:**
  - Phi-4 base: **Pivotal-token DPO** — pairs constructed at tokens where the probability of final-answer correctness changes most.
  - Phi-4-reasoning: **GRPO** for 90 training steps.
- **Reward model:** Rule-based for reasoning (verifier for math, format checks). No separate trained RM in Phi-4-reasoning RL stage.
- **Reward shape (Phi-4-reasoning GRPO):**
  - +1 for correct answer, −0.5 for incorrect.
  - Length-aware bonus: encourage concise outputs on correct answers; permit more think tokens on incorrect (model learns to "think longer when unsure").
  - Penalty for missing EOS or unclosed `<think>` block.
  - n-gram repetition penalty with n=5 — discourages degenerate loops.
- **KL / entropy handling:** Not disclosed explicitly (standard GRPO KL against reference policy assumed).
- **Rollout scale:** 90 GRPO steps total. Batch size / rollouts per prompt / group size G — not disclosed in publicly available extracts.
- **Hyperparameters:** LR, clip ε, optimizer — not disclosed in search-surfaced summary.
- **Verifiable rewards:** Yes — math verification (correctness of final answer), code not emphasized in phi-4-reasoning.
- **Self-improvement / iterative:** No self-play; distillation from o3-mini is the main signal.

## Innovations vs predecessors
Changes from **Phi-3 → Phi-4 → Phi-4-reasoning**:
- Synthetic data scale (~400B unweighted tokens, 50 categories) — Phi-3 was smaller-scale synthetic.
- **Pivotal-token DPO** — Phi-4's novel preference-pair construction; absent in Phi-3.
- Phi-4-reasoning moves SFT from 10K-level Phi-3 curricula to 1.4M-prompt o3-mini distillation.
- First Phi family entrant with GRPO RL; prior Phi generations stopped at DPO.
- Length-aware reward + n-gram repetition penalty are Phi-4-reasoning-specific.
