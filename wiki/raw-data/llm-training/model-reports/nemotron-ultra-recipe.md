# Nemotron 3 Nano 30B-A3B — Recipe ledger
- **Parent card:** [[nemotron-ultra]] (the Nemotron 3 white paper). Despite the file name, no row describes Llama-Nemotron Ultra or Nemotron 3 Super/Ultra; neither source prints training values for Super or Ultra.
- **Sources:** WP = "NVIDIA Nemotron 3: Efficient and Open Intelligence", arXiv:2512.20856v1 (2025-12-24). NR = "Nemotron 3 Nano: Open, Efficient Mixture-of-Experts Hybrid Mamba-Transformer Model for Agentic Reasoning", arXiv:2512.20848v1 (2025-12-23). Both are the only arXiv versions. Checked 2026-09-14.
- **Base checkpoint caveat:** NR App. A states that alignment started from a "pre-alignment base" checkpoint, and that a separately "improved base model" was released as Nemotron 3 Nano 30B-A3B Base (Table 5 vs Table 2). The pretraining rows below are printed for the released base (§2.4); NR does not say whether the pre-alignment base used the same schedule.
- **Units:** NR does not state whether the Figure 3 and Figure 5 percentages are token shares or sampling weights. Pretraining batch is in sequences, with NR's own conversion to tokens.

## Notes printed in the sources
- **SFT vs RLVR (NR §3.2.3, Figure 8):** RLVR started from SFT1 (about 3 epochs of SFT) matched or exceeded SFT2 (about 5 epochs, trained to full convergence) on GPQA, LiveCodeBench, AIME25, and IFBench (curves only). Result (single study).
- **Negatives in RLHF data (NR App. D):** safety reward-model pairs use unsafe completions as rejected responses for harmful prompts and over-refusals as rejected responses for safe prompts; each pair is sampled from candidates produced by 5 open models.
- No "Starting point" paragraph is given: every value applies to a 31.6B-total MoE hybrid, and the RL learning rate and KL settings are not reported.
