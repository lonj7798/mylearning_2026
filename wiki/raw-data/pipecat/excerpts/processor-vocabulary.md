# The Splice-able Parts — Pipecat's stock processor vocabulary

<!-- slug: processor-vocabulary · type: source · source: src/pipecat/processors/filters/, src/pipecat/processors/{idle_frame_processor,producer_processor,consumer_processor,text_transformer,logger,async_generator}.py, src/pipecat/processors/aggregators/{gated,gated_llm_context,sentence}.py -->

**Core Insight.** The "lego" intuition is literally true and the authors said so in code: the filters package ships both `IdentityFilter` (forwards everything, 2-line body) and `NullFilter` (forwards nothing but `SystemFrame`/`EndFrame`) — the **identity element** and the **absorbing zero** of pipeline composition. Nobody builds a `NullFilter` because they need one: `grep -rn NullFilter src tests examples` returns exactly **one hit, its own class definition** at `null_filter.py:18`. It exists to close the algebra. Everything else in `processors/` is a small single-job brick with one callback seam.

**Guideline.** Before writing a custom `FrameProcessor`, check whether your job is one of six shapes — PASS/BLOCK, TRANSFORM, OBSERVE, TAP/FORK, GATE, BUFFER — each of which already has a stock class. Write custom only when the logic must *coordinate two non-adjacent points* in the pipe, the one shape none of these cover.

## Technical Details

- **No package re-exports.** `processors/filters/__init__.py` is **0 bytes**. Every import is a full module path (`from pipecat.processors.filters.function_filter import FunctionFilter`). The directory listing *is* the API.

**PASS / BLOCK** — decide whether a frame continues.

| Class | File:line | Constructor | One job |
|---|---|---|---|
| `IdentityFilter` | `filters/identity_filter.py:17` | `__init__(self, **kwargs)` | Forward everything unchanged. |
| `NullFilter` | `filters/null_filter.py:18` | `__init__(self, **kwargs)` | Drop everything except `SystemFrame`/`EndFrame`. |
| `FrameFilter` | `filters/frame_filter.py:13` | `__init__(self, types: tuple[type[Frame], ...])` | Allow only listed frame types. |
| `FunctionFilter` | `filters/function_filter.py:21` | `__init__(self, filter: FilterType, direction: FrameDirection \| None = FrameDirection.DOWNSTREAM, filter_system_frames: bool = False, **kwargs)` | Allow by async predicate. |

- **The identity is real, not rhetorical.** `IdentityFilter.process_frame` (L37–45) is `await super().process_frame(...)` then `await self.push_frame(frame, direction)`. Its docstring names composition as the use case: *"useful when testing `ParallelPipeline` to create pipelines that pass through frames (no frames should be repeated)."* Referenced **76 times** across `src/` + `tests/`.
- **The zero is not a true zero — and that is the whole design.** `NullFilter` L47–48 keeps `isinstance(frame, (SystemFrame, EndFrame))` alive; `FrameFilter._should_passthrough_frame` (L36–41) has the identical escape hatch, so `FrameFilter(types=())` **is** `NullFilter()` — and the tests use exactly that spelling (`tests/test_pipeline.py:751,1042,1065`; `tests/test_filters.py:61`). Consequence: you cannot algebraically sever a pipeline. The control plane (`StartFrame`, `EndFrame`, `CancelFrame`, `InterruptionFrame`) survives every filter by construction.
- **`FunctionFilter` calls your predicate even when it will ignore the answer.** L82–85: `passthrough = self._should_passthrough_frame(frame, direction)` / `allowed = await self._filter(frame)` / `if passthrough or allowed:`. The `await self._filter(frame)` is *unconditional*, so a side-effecting predicate sees `StartFrame`/`EndFrame`/`CancelFrame` and every `SystemFrame` it never gates. `FilterType = Callable[[Frame], Awaitable[bool]]` (L18). In-tree consumers: `pipeline/service_switcher.py`, `examples/features/features-switch-{languages,voices}.py`.

**TRANSFORM** — rewrite the payload.

- `StatelessTextTransformer` — `text_transformer.py:15`, `__init__(self, transform_fn: Callable[[str], str] | Callable[[str], Coroutine[None, None, str]])` (L23–25); applies `transform_fn` to `TextFrame.text`. **Two gotchas at L48**: it emits a *brand-new* `TextFrame(text=result)`, so subclass identity dies (a `TranscriptionFrame` comes out a bare `TextFrame`, losing `user_id`/`timestamp`), and `direction` is dropped from the call, so a transformed frame always goes **downstream** even if it arrived upstream. Zero usages in `src/`, `examples/`, `tests/`.
- `WakeCheckFilter` — `filters/wake_check_filter.py:33`, `__init__(self, wake_phrases: list[str], keepalive_timeout: float = 3)` (L78). **DEPRECATED** since 0.0.106 via the PEP-702 `@deprecated` decorator (L29–32); replacement `pipecat.turns.user_start.WakePhraseUserTurnStartStrategy`; removal in 2.0.0. Listed because it is the only stock filter that **mutates a frame in place** (`frame.text = p.accumulator[match.start():]`, L134). Per-speaker state via nested `ParticipantState` (L57) keyed on `frame.user_id`, with `WakeState.IDLE`/`AWAKE` (L46).

**OBSERVE** — see the frame, change nothing, cause a side effect.

- `FrameLogger` — `logger.py:23`, `__init__(self, prefix="Frame", color: str | None = None, ignored_frame_types: tuple[type[Frame], ...] = (BotSpeakingFrame, UserSpeakingFrame, InputAudioRawFrame, OutputAudioRawFrame))` (L31–41). Logs `"> Frame: …"` / `"< Frame: …"` by direction (L65–66). **Trap at L64**: `if self._ignored_frame_types and not isinstance(...)` — passing `ignored_frame_types=()` disables *all* logging rather than logging everything, because the empty tuple is falsy.
- `WakeNotifierFilter` — `filters/wake_notifier_filter.py:16`, `__init__(self, notifier: BaseNotifier, *, types: tuple[type[Frame], ...], filter: Callable[[Frame], Awaitable[bool]], **kwargs)` (L24–31). Despite "Filter" in the name it **never blocks**: L55–58 fires `await self._notifier.notify()` on a type+predicate match, then pushes unconditionally. This is the canonical "tell a non-adjacent processor something happened" brick.
- `IdleFrameProcessor` — `idle_frame_processor.py:16`, `__init__(self, *, callback: Callable[["IdleFrameProcessor"], Awaitable[None]], timeout: float, types: list[type] | None = None, **kwargs)` (L24–31). `_idle_task_handler` (L83–90) is `while True: try: await asyncio.wait_for(self._idle_event.wait(), timeout=self._timeout) … except TimeoutError: await self._callback(self)` — no `break`, so the callback **re-fires every `timeout` seconds** while the pipe stays idle. `self._idle_event` is created only on `StartFrame` (L58–59 → `_create_idle_task` L77–81); a frame arriving before `StartFrame` hits `AttributeError` at L66.

**TAP / FORK** — copy the stream sideways without breaking it.

- `ProducerProcessor` — `producer_processor.py:28`, `__init__(self, *, filter: Callable[[Frame], Awaitable[bool]], transformer: Callable[[Frame], Awaitable[Frame]] = identity_transformer, passthrough: bool = True)` (L37–43). The module's own `async def identity_transformer(frame: Frame)` (L16) is a **second identity element**, this time for the transform slot. `add_consumer(self) -> asyncio.Queue` (L60) hands out one queue per consumer. **Cost note (L92–94)**: `_produce` calls `await self._transformer(frame)` *inside* the per-consumer loop, so N consumers means N transformer invocations and N distinct frame objects.
- `ConsumerProcessor` — `consumer_processor.py:17`, `__init__(self, *, producer: ProducerProcessor, transformer = identity_transformer, direction: FrameDirection = FrameDirection.DOWNSTREAM, **kwargs)` (L25–32). Registers on `StartFrame` (`self._queue = self._producer.add_consumer()`, L68) and re-injects with `await self.queue_frame(new_frame, self._direction)` (L95) — `queue_frame`, **not** `push_frame`, so injected frames serialise with the processor's own inbound queue instead of cutting the line.
- `AsyncGeneratorProcessor` — `async_generator.py:22`, `__init__(self, *, serializer: FrameSerializer, **kwargs)` (L31). Passes frames through *and* serialises a copy into a queue exposed as `async def generator(self) -> AsyncGenerator[Any, None]` (L60); `CancelFrame`/`EndFrame` enqueue a `None` sentinel (L53–54).
- Producer/Consumer have **zero usages** outside their own two files — like `NullFilter`, vocabulary provided *for* you, not machinery the framework runs on itself.

**GATE** — hold frames until an external condition flips.

- `GatedAggregator` — `aggregators/gated.py:20`, `__init__(self, gate_open_fn, gate_close_fn, start_open, direction: FrameDirection = FrameDirection.DOWNSTREAM)` (L29–35). **Anomaly worth naming:** `gate_open_fn`/`gate_close_fn` are the *only* callbacks in this vocabulary that are **untyped and synchronous** — L72/L74 call them bare (`self._gate_close_fn(frame)`), no `await`, no annotation, while every other seam here is `Callable[[Frame], Awaitable[bool]]`. Release order (L80–84): the **gate-opening frame is pushed first**, then the backlog drains, so the trigger arrives before the frames it released. `SystemFrame` bypasses the gate entirely (L61–63), as does any frame travelling against `self._direction` (L66–68).
- `GatedLLMContextAggregator` — `aggregators/gated_llm_context.py:14`, `__init__(self, *, notifier: BaseNotifier, start_open: bool = False, **kwargs)` (L22). Holds `self._last_context_frame` — a buffer of **exactly one**. A second `LLMContextFrame` arriving before the notifier fires **overwrites** the first (L56). Latest-wins, not a queue. Release loop `_gate_task_handler` (L76–82) is `while True: await self._notifier.wait()`.

**BUFFER** — accumulate until a content condition is met.

- `SentenceAggregator` — `aggregators/sentence.py:18`, `__init__(self)` (L32). Concatenates `TextFrame.text` and emits when `match_endofsentence(...)` is true (L55–57); flushes the tail on `EndFrame` (L58–61); silently **drops** `InterimTranscriptionFrame` with a bare `return` (L50–51). `GatedAggregator._accumulator: list[tuple[Frame, FrameDirection]]` (L49) is the unbounded variant — it stores direction alongside the frame, which is why it can replay upstream frames correctly.

- **Migration angle:** map boson-agent's `gateway/layers/` action verbs onto this vocabulary before writing custom code. `ACTION_PRIORITY` (`layers/pipeline.py:42`, `filter > respond > inject > orchestration > pass`) has three verbs with stock homes — **filter** → `FunctionFilter` (async predicate; `direction=DOWNSTREAM` matches a rule that only inspects user-side frames); **inject** → a `ProducerProcessor`/`ConsumerProcessor` pair, using the `queue_frame` idiom (consumer L95) when the injection must not preempt in-flight audio; **pass** → `IdentityFilter` verbatim. **respond** and **orchestration** have no brick — they need `LLMContextFrame` manipulation — and `_resolve_actions` (`layers/pipeline.py:374`) has no counterpart at all (see [[parallel-pipeline]] for why `ParallelPipeline` cannot arbitrate). Two concrete substitutions available *today*: boson's `AgentStatusTracker` SETTLING state (`layers/status.py:29`, `settling_ms: int = 500`) is `IdleFrameProcessor(callback=…, timeout=0.5, types=[…])`; boson's `<system-reminder>` tail-buffer scrubber (`gateway/core.py` L305–389) is **not** `StatelessTextTransformer` — that class destroys frame subclass and direction at L48, so a `TranscriptionFrame` would land downstream as a bare `TextFrame` without `user_id`. Write a custom processor for that one. Untouched here: boson's hook registry and `SharedLayerContext` attribute proxying — see [[bus-and-extensions]].
